# 課題一 旅遊導論

## 旅行、旅遊及旅客的定義

<p class="freq">⭐⭐⭐｜課題一 第2章</p>

| 用語 | 定義 |
|---|---|
| ==旅行== | 所有從一地到另一地的旅程（消閒、工作、居住、學習、過境） |
| ==旅遊== | 暫時離開生活及工作的地方作短期逗留，包括逗留期間的活動；**所有旅遊都包括旅行，但並非所有旅行都屬旅遊** |
| ==旅客==（過夜） | 到居住及工作地點以外，停留**至少 24 小時但不到一年**；不是以居民身份受僱於到訪地 |
| ==短程旅客== | 逗留**少於 24 小時**，沒有在旅館過夜（即日來回） |

**聯合國世界旅遊組織**：離開==慣常生活環境空間==，逗留**少於一年**；目的包括消閒、公幹及其他，**不包括在當地幹活賺錢**。

| 分類 | 意思 | 例子 |
|---|---|---|
| ==國內／本地旅遊== | 居民到本國境內其他地方 | 紐約居民到洛杉磯公幹 |
| ==入境旅遊== | 境外人士到訪當地 | 加拿大人到美國（對美國） |
| ==出境旅遊== | 居民離開原居地跨境旅遊 | 加拿大人到美國（對加拿大） |

- 同一旅程，對==旅客來源地==是出境，對==旅遊目的地==是入境

## 不被視為旅客的人士

<p class="freq">⭐⭐｜課題一 第2章</p>

| 人士 | 原因 |
|---|---|
| ==跨境工人== | 頻繁跨境工作（住深圳、在香港工作） |
| 季節工人及短期工人 | 按短期合約在居住地以外工作 |
| 流浪者及難民 | 逗留地方被視為其慣常生活環境空間 |
| 公共交通工具工作人員 | 機組人員被視為在慣常生活環境空間內 |
| 外交官、駐海外軍隊 | 按==國際收支平衡原則==，沒有進入駐紮國經濟領土 |

**視乎逗留時間**

- 學生：短期課程（不到一年）→ 旅客；一年或以上 → 非旅客
- 病人：住院不到一年 → 旅客；一年或以上 → 非旅客

**旅遊目的（聯合國世界旅遊組織）**

1. 個人：度假娛樂｜探訪親友｜教育培訓｜健康醫療｜宗教朝聖｜購物｜過境｜其他
2. 商業及專業

- 大多數旅客因**多種原因**旅行；調查會問主要及次要目的

## 旅遊的形式（按外遊目的）

<p class="freq">⭐⭐｜課題一 第2章</p>

| 形式 | 要點 |
|---|---|
| ==閒暇／度假式== | **輕鬆式**：風景、陽光、海、沙灘；**觀光式**：探索、增廣見聞、提升自尊感 |
| ==公幹／商務== | 貿易、會議、獎勵旅遊、大型會議、展覽 |
| ==文化旅遊== | 獲取目的地或東道社群的知識及理念 |
| ==環保旅遊== | 減低對環境影響；旅客收益用作保育；導覽員教育旅客 |
| ==學習旅遊== | 海外短期或假期課程、遊學團 |
| ==宗教朝聖== | 需求穩定（麥加、耶路撒冷） |
| ==保健旅遊== | 溫泉醫療旅遊 |
| ==探訪親友== | 多住親友家；仍有超市及家庭消費 |
| ==運動旅遊== | 參與運動或觀看賽事（七人欖球賽） |

## 商務旅客的特色

<p class="freq">⭐⭐⭐｜課題一 第2章｜2026 考評報告點名弱項</p>

1. 常到**大城市或工業中心**（倫敦、紐約、香港；深圳、東莞）
2. 與**旅遊價格沒有必然關係**：減價不會更頻密出行，加價亦不會減少
3. **季節性因素**（氣候、假期）影響不大
4. 行程**短而頻密**
5. 要求不同服務，如**通訊或秘書服務**
6. 時間許可會在工餘進行閒暇觀光
7. 期望**較高質素服務**，願多付費（頭等艙、商務艙、高級酒店）

**會議、獎勵旅遊、大型會議及展覽**

- ==會議==：企業會議
- ==獎勵旅遊==：獎勵業務達標的員工，含會議及休閒元素
- ==大型會議==：協會組織，討論共同議題
- ==展覽==：向潛在顧客或買家展示新產品

!!! trap "易錯"
    須用課本特徵逐點對應資料，不能只寫「有錢」「住好酒店」。

## 高恆（Cohen）的分類模式

<p class="freq">⭐⭐⭐⭐⭐｜課題一 第2章</p>

**分類基礎**：對新體驗的==好奇心== vs 如置身家鄉的==安全感==

**==環境泡泡==**：熟悉的環境氛圍，把環境變化降至可接受水平的「安全網」（酒店：多語員工、不同食物、旅遊櫃台、各國電視頻道）

| 類型 | 類別 | 特徵 |
|---|---|---|
| ==旅行團群體旅客== | ==制度化== | **最不冒險**；路線預先決定；幾乎不能作決定；大部分時間在環境泡泡內 |
| ==個別的群體旅客== | 制度化 | 行程非完全固定，有相當控制；仍預先經旅行社安排主要行程；**仍受環境泡泡限制** |
| ==探險式旅客== | ==非制度化== | 自行安排；去非一般地方但仍求舒適住宿；嘗試融入；**謹慎地**離開環境泡泡 |
| ==漫遊式旅客== | 非制度化 | 斷絕與旅遊機構連繫；無固定行程；與當地人同吃同住，找零工 |

- 非制度化旅客擔當群體旅客的先鋒，對低下階層居民起==示範作用==

!!! trap "易錯"
    個別的群體旅客雖然自由行，但**仍在環境泡泡內**，不等於探險式旅客。

## 蒲樂（Plog）的分類模式

<p class="freq">⭐⭐⭐⭐⭐｜課題一 第2章｜2025 考評報告點名弱項</p>

**分類基礎**：旅客**與生俱來的性格**

| | ==保守型== | ==中庸型== | ==探奇型== |
|---|---|---|---|
| 性格 | 不愛冒險、傾向抑制 | 不抗拒新體驗 | 外向自信、尋求冒險 |
| 目的地 | 熟悉的熱點 | **已發展**但不太多旅客 | 冷門、**未成熟** |
| 活動 | 靜態、娛樂 | 可控環境下了解文化 | 動態、與不同文化交往 |
| 住宿 | 熟悉的**連鎖式**酒店 | 優質酒店、仍求舒適 | 簡單即可 |
| 安排 | **全包旅行團**；重視安全 | 自由行或旅行團 | 自由度高（只包交通住宿） |

- **大部分旅客屬中庸型**；另有==接近保守型==（重複到訪）、==接近探奇型==

!!! trap "易錯"
    **中庸型 ≠ 保守型**：中庸型不抗拒新體驗、可自由行；保守型只去熟悉熱點、全包團、重視安全。

## 旅遊時的風險及特殊需要旅客

<p class="freq">⭐⭐｜課題一 第2章</p>

| 風險 | 降低方法 |
|---|---|
| 發生罪行 | 避免高罪案地區；知道旅遊警察及緊急電話；了解走火通道 |
| 人身安全 | 旅遊保險；經測試的安全設備；不偏離標記山路 |
| 財務風險 | 卡與現金分開；貴重物品放保險箱；證件影印本；向持牌經營者購買 |
| 健康 | 攜藥物、接種疫苗；了解疫區；注意飲食 |

| 特殊需要旅客 | 例子 |
|---|---|
| 高齡 | 直航、輪椅協助、低層近電梯客房、悠閒行程 |
| 宗教信徒 | 祈禱室、聖城方向箭頭、清真食品、不供牛肉予印度教徒 |
| 懷孕 | 28 星期以上或需醫療證明；近醫療設施；短程行程 |
| 兒童及嬰兒 | 嬰兒搖籃、嬰兒床、兒童餐、主題公園 |
| 殘障 | 無障礙客房、視覺警報、斜道、凸字、手語導遊 |

**旅客行為守則**：尊重文化及人權｜保護環境｜尊重文化資源｜購買當地產品、==公平貿易==｜了解目的地法例及習俗

## 影響旅遊動機的因素

<p class="freq">⭐⭐⭐｜課題一 第3章</p>

**==動機==**：激發行動、實現目標、滿足需要的意願

**旅遊動機影響行為的三方面**

1. ==啟動==：想減壓 → 外遊
2. ==規範==：避寒 → 選陽光海灘
3. ==變化==：年長後由冒險轉休閒

| 因素 | 要點 |
|---|---|
| ==個人收入== | 僅夠基本生活便不會產生旅遊動機 |
| ==餘暇時間== | 實現旅遊的重要條件 |
| 性別、年齡、身體狀況 | 年齡與求新動機成反比 |
| ==心理因素== | 興趣、愛好、教育程度 |
| 旅遊業整體發展水平 | 交通、住宿、服務水準 |
| 團體、家庭及社會風氣 | 獎勵旅遊；==仿效的旅遊行為== |
| 世界局勢 | 地緣政治、恐襲、疫症 |
| 文化差異 | 目的地與自身文化是否相同 |

## 馬斯勞的需要層次理論

<p class="freq">⭐⭐⭐⭐⭐｜課題一 第3章</p>

滿足基本需要是滿足更高層次需要的**先決條件**。

| 層次 | 意思 | 旅遊應用 |
|---|---|---|
| 5 ==自我實現需要== | 發揮潛能、求知、審美、成就 | 遊學團；攀登喜馬拉雅山 |
| 4 ==尊重需要== | 受尊重、地位、名譽 | 金銀銅級別會員；特別日子送香檳 |
| 3 ==社交需要==（歸屬感和愛） | 愛與被愛、群體認同 | 常客計劃帶來歸屬感；與志趣相投者同遊；尋根 |
| 2 ==安全需要== | 保護身心、安全環境 | 提供導遊；選用政府認可旅行社 |
| 1 ==生理需要== | 食物、水、睡眠、住所 | 頻密休息點；飲食場所方便；公路旁汽車旅館 |

!!! score "拿分要訣"
    寫出**層次名稱**，再以資料中的產品或行為說明滿足了哪一層需要。

## 推拉理論（丹恩，1977）

<p class="freq">⭐⭐⭐⭐｜課題一 第3章</p>

| | ==推動因素== | ==拉動因素== |
|---|---|---|
| 性質 | 形成旅行慾望的**內部或無形**因素 | 與目的地**屬性及吸引力**相關，決定**去哪裡** |
| 特點 | 可特定或一般；**越具體，可滿足的目的地越少** | 旅客往往有**明確的目的地** |
| 例子 | 逃避日常生活、休息放鬆、增加知識、探訪親友、與家人一起、尋求刺激、挑戰體能 | 旅遊產品及費用、美食、夜生活、交通便利、歷史文化資源、風景天氣、安全、國際大都市 |

**應用（西九文化區）**

- 逃離日常生活 ↔ 海濱長廊日落美景
- 增加知識 ↔ 香港故宮文化博物館
- 與家人更親近 ↔ 交通便利、可達度高
- 好奇心 ↔ 新景點

!!! score "拿分要訣"
    **配對作答**：推動因素 → 對應拉動因素（引資料）→ 解釋兩者如何搭配滿足需要。

## 旅客流量與行程模式

<p class="freq">⭐⭐⭐｜課題一 第3章｜2026 考評報告點名弱項</p>

**==旅客流量==**：某段時間內進出目的地的旅客人數和流向；目的地有**過剩**商品（拉動），來源地**缺乏**（推動）

| 模式 | 特點 | 例子 |
|---|---|---|
| ==雙向往返== | 單一目的地，**同一路線**往返 | 乘火車往返廣州 |
| ==中轉圓形往返== | 以主要目的地為**中轉站**，圓形遊覽區內各地後返回中轉站 | 倫敦→香港→內地圓形遊→香港→倫敦 |
| ==圓形往返== | 多個目的地，**沒有核心目的地**；去程回程**不同路線** | 香港沿海往上海，內陸路線返港 |
| ==輻射往返== | 以主要目的地為**基地**，多次出去過夜再返回 | 抵港→澳門→回港→深圳→回港→返國 |

!!! trap "易錯"
    中轉圓形＝以中轉站為起點終點繞一圈；輻射＝由基地多次「出去再回來」；圓形往返＝沒有核心目的地。

## 影響旅客流量的因素

<p class="freq">⭐⭐｜課題一 第3章</p>

**與旅遊目的地相關（拉動）**

- 天然及人造景點｜氣候
- 政治、文化及商業聯繫（共同語言、宗教）
- ==相對費用==：由生活指數高流向低的地方
- 新的文化體驗｜東道群體的態度｜旅遊潮流
- ==政府管控==：外匯管制、入境簽證
- 交通（無需轉乘）｜位於國際航線上（香港）

**與旅客來源地相關（推動）**

- **收入**：越高，旅行越頻密
- **就業**：工作穩定者較多出國
- **應享有薪假期**：越長去得越遠
- **教育程度**：較願接受新經驗
- 推動因素：逃避日常生活、社交需要、優越感、尋求刺激

## 旅遊產品的六個特性

<p class="freq">⭐⭐⭐｜課題一 第4章</p>

| 特性 | 意思 | 例子 |
|---|---|---|
| ==無形性== | 購買前無法看見觸摸；買的是體驗 | 追求快樂、輕鬆等無形目的 |
| ==生產與消費不可分離性== | 提供與消費同時進行 | 飛機飛行時乘客同時享用 |
| ==差異性== | 質量難統一；受員工及旅客影響 | 不同員工服務不可能完全相同 |
| ==不可保存性== | 不能儲存以備未來出售 | 空置客房永遠失去銷售機會 |
| ==互補性== | 一次外遊需多個機構產品，互相影響 | 溫泉勝地衰落，附近餐館亦受影響 |
| ==不可擁有權== | 交易後只得到經歷 | 乘機後只剩機票 |

- 旅遊產品是一種**服務**；涵蓋交通、住宿、餐飲、會議、景點活動

## 產品生命週期

<p class="freq">⭐⭐⭐｜課題一 第4章</p>

**四階段**：==引入期== → ==成長期== → ==成熟期== → ==衰退期==

**旅遊產品五階段**：在引入期前加入**階段零 ==發展期==**（由概念到成形）

| 影響因素 | 例子 |
|---|---|
| ==內在因素== | 產品老化、管理不善、不合適的市場銷售活動 |
| ==外在因素== | 社會、文化、政治、科技 |

| 個案 | 內在 | 外在 |
|---|---|---|
| 巴黎迪士尼引入期入場下降 | 入場費貴、不能飲酒、不能攜外來食品、員工流失 | 西歐經濟衰退、天氣冷濕、不喜美國文化 |
| 海洋公園 2015–2021 衰退期 | 管理不當、設施老化 | 主題公園競爭、新冠疫情 |

- ==季節性==：日本旅行團旺季（櫻花、大減價）；淡季減價以減少影響
- **作用**：作長遠規劃，作**市場營銷**及**發展決策**的框架

## 旅遊目的地生命週期（Butler）

<p class="freq">⭐⭐⭐⭐⭐｜課題一 第4章</p>

| 階段 | 特性 | 旅客 | 居民情緒 |
|---|---|---|---|
| 1 ==發掘== | 少量旅客，**沒有公眾設施** | 漫遊式、探險式 | 興奮愉快 |
| 2 ==投入== | 居民主動建設施；**當地人仍掌握命運**；季節性出現 | 探奇型取代漫遊式 | 正式化但親切 |
| 3 ==發展== | 旅遊業起飛；**外來企業控制增加**；環保設施跟不上；旺季旅客多於居民 | 人數急升 | 理所當然 |
| 4 ==鞏固== | 增長放緩；**制度化**；設施老化；要求**西式設施** → **資金流失** | 流量穩定 | 煩厭不快 |
| 5 ==停滯== | **人次最高點**但不再時尚；度假點與居民分隔 | 大批旅行團，**環境泡泡** | 敵對感覺 |
| 6 ==衰落／重生== | 增長及投資停止 | — | 得不償失 |

- ==重生==：重新定位（由長者靜態休閒轉為吸引活躍旅客）；==衰落==：投資者視為「搖錢樹」

!!! score "拿分要訣"
    引資料數據（人次趨勢、設施、居民態度）逐點對應階段特性；可結合多克西指標、旅客類型、資金流失。

## 承載力

<p class="freq">⭐⭐⭐⭐｜課題一 第4章｜2026 卷二</p>

**定義**：在不使環境及旅客享樂下降至不能接受程度下，目的地可容納的**最高旅客數目**

| 種類 | 意思／超出時 |
|---|---|
| ==空間承載力== | 可用土地面積；設施容納人數（泊車位、座位）；交通容量（大老山隧道每小時 3,000 輛） |
| ==環境承載力== | 超出 → **無法彌補**的破壞（草地被踐踏、野生生物受滋擾） |
| ==心理承載力== | **旅客**樂趣明顯減弱（擠迫、喧嘩、污染容忍度） |
| ==經濟承載力== | 物業價值上升，居民被逼遷；日常消費品價格上升 |
| ==社會文化承載力== | **居民**對旅客的接納度；超出 → 逆轉性破壞社區（手工藝被機械化生產取代） |

**問題出現的地方**：==旅客來源地==（假期固定）｜==過境路線==（深圳、廣州出現==樽頸現象==）｜==旅客目的地==（長城、紫禁城）

!!! trap "易錯"
    心理承載力是**旅客**感受；社會文化承載力是**居民**接納度。須指出資料中超出的是哪一種並引證據。

## 承載力的管理

<p class="freq">⭐⭐⭐｜課題一 第4章</p>

| 種類 | 提升或管理方法 |
|---|---|
| 空間 | 建更多酒店；改善供水；增加停車場；鋪建遠足徑；增加休息站 |
| 環境 | 改善污水處理；改善路標、關閉損壞小路；修復場地；生態脆弱區環保政策 |
| 心理 | 減少或控制需求；鼓勵淡季或次旺季旅遊；超越承載力時**高價降需求**；淡季**低價增需求** |
| 經濟 | 確保業界工資水平；低稅率鼓勵行業發展 |
| 社會文化 | 鼓勵當地人參與旅遊業；加強新項目公眾諮詢；教育居民及旅客了解彼此期望 |

**理想做法**

- 限制旅遊需求以免超出承載力；或
- 擴大整體承載量以滿足更多旅客

**例**：西貢燒烤場太多人 → 煙霧、垃圾、擠迫、輪候，逃避煩囂的目的被破壞

## 旅遊業整合模式及外在因素

<p class="freq">⭐⭐｜課題一 第1章</p>

**==旅遊業整合模式==**：旅客是**核心** → 第一層==旅遊推廣者==（旅遊局、旅行社、會議策劃者）→ ==旅遊服務供應商==（航空、酒店、郵輪）→ ==外在因素==

| 外在因素 | 推動或阻礙例子 |
|---|---|
| ==社會== | 人口老齡化 → 郵輪、水療需求增加，傳統主題公園減少 |
| ==文化== | 文化旅遊最受歡迎之一；過多旅客威脅文化保育 |
| ==政治== | CEPA「==個人遊==」帶來超過 15 年增長；埃及政局不穩，旅客由 1,150 萬跌至 540 萬 |
| ==經濟== | 經濟好 → 去遠、留長；差 → 去近、縮短；盧布貶值令俄羅斯旅客減 40% |
| ==環境== | 環保意識 → 生態旅遊、綠色酒店 |
| ==科技== | 鐵路、飛機；應用程式、==共享經濟==；高鐵開闢新路線 |

**歷史重點**：中古時期宗教旅遊｜17 世紀==大旅遊==｜工業革命奠定==大眾旅遊==｜1970 年波音 747｜21 世紀==網上旅行社==、碳中和

## 交通模式比較

<p class="freq">⭐⭐｜課題一 第5章｜2024 MC 郵輪</p>

| 模式 | 優點 | 缺點 | 對旅遊業的影響 |
|---|---|---|---|
| 航空 | 快、可達遠程 | 燃料多；安全管制令價高 | 促進大規模國際旅遊 |
| 水路 | 舒適、度假放鬆 | 慢；暈船浪；勞工成本高 | 郵輪自八十年代流行 |
| 汽車 | 彈性大、直達、可帶裝備 | 道路擠塞 | 旅客更有彈性 |
| 鐵路 | 車站在市中心、較環保、載客多 | 固定成本高 | 令偏遠地方發展；觀景鐵路 |

- ==定期航班==：按時間表運作，不論人數；==不定期航班==（包機）：無固定時間表，增補繁忙時段
- ==郵輪==：「==自給自足的目的地==」；多在同一地方開始及結束；全包費用含往返登船地點交通、船上活動、岸上觀光
- 客位：頭等、商務、特選經濟、經濟；==傳統航空公司==與==低成本航空公司==

## 中介機構與分銷途徑

<p class="freq">⭐⭐⭐｜課題一 第5章</p>

==中介機構==：顧客與供應商的中間人（==旅行代理商==、==旅行團經營商==）

| 分銷級別 | 做法 | 好處／壞處 |
|---|---|---|
| ==單向== | 供應商直接賣給消費者 | 無佣金，可給忠誠顧客優惠 |
| ==雙向== | 經一層中介 | 分銷更廣；佣金可達 25% |
| ==多向== | 供應商 → ==旅遊批發商== → 零售商 → 消費者 | 捆綁產品 |

- 中介層級越多，供應商控制越少；須以折扣價供貨給中介

**旅行代理商的三項功能**

1. 提供==一站式==產品：多次購買變一次，打破地區局限
2. 旅遊產品主要的==分銷途徑==
3. 促進旅遊活動：預訂、確認、資訊及專業意見

- 趨勢：==線上旅行社==及供應商應用程式**繞過**傳統中介

## 多克西的旅客情緒指標

<p class="freq">⭐⭐⭐⭐｜課題一 第7章｜2017、2018、2022、2025</p>

| 階段 | 居民情緒 |
|---|---|
| 1 ==興奮愉快== | 熱衷發展旅遊業，歡迎旅客，雙方滿足 |
| 2 ==理所當然== | 旅客淪為賺錢目標；交往形式化 |
| 3 ==煩厭不快== | 接近飽和或設施不足（泊車問題） |
| 4 ==敵對感覺== | 視旅客為所有問題的始作俑者；旅客成為受欺詐的一群 |
| 5 ==得不償失== | 忘記珍愛之物正是吸引旅客的源頭；環境轉變無法復原 |

- **原因**：旅客數量最終超越居民能容忍的限度
- 可配合 Butler 目的地生命週期：發掘（興奮愉快）→ 發展（理所當然）→ 鞏固（煩厭不快）→ 停滯（敵對）→ 衰落（得不償失）

## 旅遊業對經濟的影響

<p class="freq">⭐⭐⭐⭐⭐｜課題一 第7章</p>

| 正面 | 要點 |
|---|---|
| ==製造就業== | 勞工密集；**直接職位**及**間接職位** |
| ==提供稅收== | 直接稅（入息稅、利得稅）；間接稅（銷售稅、離境稅、酒店房間稅） |
| 改善==收支差額== | 入境旅遊是「==無形出口==」，出境是「==無形進口==」 |
| 經濟增長及生活水平 | 賺取外匯；==經濟多元化==；薪酬高於農漁業 |
| ==收入及聯繫效應== | 為其他行業帶來生意 |

| 負面 | 要點 |
|---|---|
| ==高消費價格及高地價== | 資源需求增加 → 通貨膨脹 |
| ==過分依賴旅遊業== | 依賴外在需求；旅客口味善變 |
| ==流失== | 進口貨品服務；外國員工匯款；外資利潤匯走 |

- 發展中國家每 100 美元只約 5 美元留在當地
- **進口貨品流失**（產品未達國際水準）與**出口貨品流失**（外資擁有設施）

## 乘數效應與流失

<p class="freq">⭐⭐⭐⭐｜課題一 第7章｜2026 考評報告點名弱項</p>

| 階段 | 內容 |
|---|---|
| ==第一重效應== | 旅客直接或間接購買產品服務（住宿、食物；經旅行團承辦商訂房） |
| ==第二重效應== | 業界把收入用於購買投入資源，支付工資、利息、利潤 |
| ==第三重效應== | 收款人再消費、儲蓄或繳稅；購買進口品 → 流失 |
| 週期完結 | 每輪有流失，回流越來越少；**累積效應 = ==旅遊業乘數效應==** |

**例**：旅客在餐廳消費 → 東主交稅、向本地供應商購貨、付工資租金 → 收款人再消費 → 連鎖消費遠超最初款額

- **減低乘數**：稅項、儲蓄、購買進口貨品
- **加大乘數**：經濟活動聯繫強、貨品服務多由本地提供
- 淨額貢獻**主要視乎資金流失**

!!! trap "易錯"
    須寫出運作：初始消費 → 多輪再消費 → 每輪流失；不能只寫「帶動經濟」。

## 旅遊業對環境的影響

<p class="freq">⭐⭐⭐⭐⭐｜課題一 第7章</p>

**正面**

1. ==環境的保存及復原==：資助保育古蹟及自然（肯尼雅、坦桑尼亞狩獵保護區）
2. ==環境的改善==：種植花草、控制空氣水質噪音垃圾
3. ==加強環保意識==：政府執行反污染、土地分區

**負面：==環境污染==（非生物）**

- **水質**：船隻油污、度假村污水
- **空氣**：過度使用交通工具
- **土壤**：不可生物降解垃圾
- **噪音**：車輛、飛機、遊樂場
- **視覺**：與本地風格不符的建築、巨型廣告、失修建築

**負面：==擾亂生態==（生物）**

- **植物**：採集、踐踏、砍樹生火
- **野生動物**：失去棲息地；覓食繁殖模式改變

**==環境影響評估==**：及早預防勝於補救；分地理、生物、社會經濟三方面
