# 課題五 趨勢及議題

## 可持續發展的概念

<p class="freq">⭐⭐⭐⭐⭐｜課題五 第1章</p>

**==可持續發展==**：**既滿足當代人的需求，又不損害子孫後代滿足其需求的能力**（布倫特蘭報告《我們共同的未來》）

| 三方面 | 方向 |
|---|---|
| ==經濟可持續性== | 有效管理資源；就業、生產力、縮小貧富差距 |
| ==社會可持續性== | 社會包容、機會平等、人權、文化多元 |
| ==環境可持續性== | 減少污染、再生能源、保護生物多樣性 |

**聯合國世界旅遊組織**：可持續旅遊原則**適用於所有類型目的地的所有形式旅遊**（包括==大眾旅遊==及==利基旅遊==）；須在**環境、經濟、社會文化**三方面取得平衡

| ==生態旅遊== | ==可持續發展旅遊== |
|---|---|
| 旅遊業中**專注環境**的一個環節 | 原則適用於**所有**旅遊活動、營運、機構及項目 |

**旅遊與款待業面臨的議題**：疫情影響｜可持續發展｜科技迅速發展（私隱）｜人力資源（季節性、高流失）｜==目的地競爭==

!!! trap "易錯"
    ==負責任旅遊==不只限於環境，同時考慮**社會、經濟及文化**（2025 MC）。

## 全球化

<p class="freq">⭐⭐⭐｜課題五 第2章｜2026 考評報告點名弱項</p>

**==全球化==**：跨越國界的緊湊關係網絡，把不同國家聚合成**單一、互相依靠的整體**

**旅遊業全球化的特徵**

- 當地文化==商品化==；==美國化==（麥當勞、星巴克）
- ==標準化==：各地機場、酒店大同小異
- 生產轉移至勞工成本低的地方（樹熊玩具在中國生產）
- 小企業被大公司收購；著重大企業及股東利益
- 跨國媒體影響旅遊選擇（「梳化遊客」）

**對發展中國家**：基建負債；居民用不起設施；外資獲==稅項寬減==；進口物資 → ==資金流失==

**推動力**

1. **技術**：==低成本航空公司==；全球網上預訂系統
2. **經濟**：西方可支配收入高、年假多
3. **對自己國家認識提高** → 嚮往新奇遙遠地方

!!! trap "易錯"
    不可混淆「全球化」（國家互相依靠的過程）與「**旅遊業全球化**」的特徵（標準化酒店、跨國連鎖、網上預訂、低成本航空、資金流失）。

## 文化同質化

<p class="freq">⭐⭐｜課題五 第2章</p>

**定義**：強國（尤其美國）的思想、價值及生活方式輸送至其他國家（麥加開設星巴克）

**為何是問題**

1. 多樣性減少（文化多樣性如生物多樣性般必不可少）
2. 目的地與原籍國相似 → **失去旅遊興趣**

**成因**

1. ==示範效應==：當地人模仿遊客，與上一代衝突
2. 旅遊勝地引入西方產品滿足遊客，當地人生活方式隨之改變
3. 跨國公司擴展全球

**反對觀點**：全球文化變得**更多元化**（高雲：古巴音樂、波斯地氈）；全球化**非單向**（瑜伽、壽司傳遍世界）

**==大眾化旅遊==**：二戰後全包式旅行團；大量旅客**同一時間同一地點** → 環境壓力（肯尼亞海洋生態、阿爾卑斯山纜車、西班牙海岸視覺污染、威尼斯擠擁）；質素下降遊客便轉往他國

## 剝削與公平貿易

<p class="freq">⭐⭐⭐｜課題五 第2章｜2016、2018、2021</p>

| 剝削的原因 | 內容 |
|---|---|
| ==稅項寬減== | 首五年免稅；東加勒比稅收損失佔 GDP 9.5%–16% |
| ==低薪職位== | 當地人缺資格；高薪職位由外國經理擔任 |
| ==苛索自然資源== | 談判籌碼有限，在珊瑚礁、潟湖建度假村 |
| ==經濟流失== | 全方位組合產品由國際公司收費；進口消費品；每 100 美元只約 5 美元留在當地 |

**==公平貿易==**：以對話、透明及尊重為基礎的貿易夥伴關係；確保發展中國家被邊緣化生產者和工人的權利

| 六個目標 | |
|---|---|
| ==公平比例== | 按貢獻分享收入 |
| ==自由度== | 僱員參與決定 |
| ==尊重== | 人權、文化、環境 |
| ==可靠性== | 服務穩定、保障安全 |
| ==透明度== | 業權及盈利透明 |
| ==可持續性== | 本地採購就業，**減少漏損** |

**好處**：滿意的客人（無內疚）｜高質素產品｜良好信譽

## 經濟趨勢與低成本航空

<p class="freq">⭐⭐⭐｜課題五 第3章</p>

- 旅遊業與**經濟週期**密切相關；經濟好 → 淨得收入用於旅遊
- 疫後：中東唯一超越疫前；歐洲旅客最多；亞太復甦較慢
- **經濟不景 → 短途行程主導**（2009 年長途跌 10%、短途升 1%）

**==低成本航空公司==**

- 便宜機票大幅減低預算；衰退期**及之後**需求依然強勁（追求物有所值）
- 主要提供短途航線；款待業須應付大量旅客住宿需求

**目的地之間的競爭**

- 新興經濟體（中國、俄羅斯、巴西）出境增長最快
- 2013 年中國成**全球第一旅遊消費國**（GDP 增長、中產擴張）
- 目的地可用 GDP 及旅遊開支**預測未來客源**、找出競爭對手
- 亞太相對增長最高，正趕上歐洲

**2024 趨勢**：養生旅遊｜生態旅遊｜個性化｜文化旅遊｜==商務休閒旅遊==｜虛擬現實｜太空旅遊｜==無障礙旅遊==

## 精選服務酒店

<p class="freq">⭐⭐⭐⭐｜課題五 第3章｜2026 卷二考評報告點名弱項</p>

| | ==有限服務== | ==精選服務== | ==全服務== |
|---|---|---|---|
| 定義 | 最初**無餐廳及宴會設施** | 兩者之間的**混合** | 提供團體**餐飲服務** |
| 設施 | 簡單；不提供膳食 | 不設多類型餐廳；**客房設施接近全服務** | 水療、宴會廳、禮賓、客房餐飲 |
| 價格 | 較低 | **保持低價** | 較高 |

- 酒店房間需求增長與 **GDP 增長呈正相關**；每間可銷售房收入與 GDP 並行

**精選服務酒店增長的原因（多角度）**

- **經濟**：經濟不景後預算緊縮；不想付多餘服務，追求**物有所值**
- **社會文化**：內地旅客多時間在景點購物，對客房要求不多
- **香港**：地小人多，細小或單棟式酒店增加（工廈、古蹟改建）
- **低成本航空**：大量旅客尋找低成本但時尚的住宿

!!! trap "易錯"
    須從**經濟、社會文化、環境、科技**多角度分析，不能只寫「便宜」。

## 餐飲業全球化

<p class="freq">⭐⭐｜課題五 第3章</p>

**利好因素**：==貿易自由化==｜交通通訊成本下降｜人口自由流動（外國廚師受聘）

- ==麥當勞化==：各地套用麥當勞經營原理；被視為==文化帝國主義==

**本地餐廳的回應（未被趕出市場）**

1. **學習西方管理效率**：大家樂仿效麥當勞自助模式、設**中央食品處理工場**；榮華雞仿效肯德基
2. **運用==特許經營==擴張**：大娘水餃九年 150 家加盟店；小肥羊、馬蘭拉麵

**全球化餐廳須==融入當地社會==**

- 麥當勞：粟米湯、春節中國佈置
- 肯德基：榨菜肉絲湯、老北京雞肉卷
- 西方的泰菜、中菜亦改良（齋春卷、甜酸雞柳）

**結論**：將菜式風格融入當地文化，同時**保持原有基本經營原則**

## 四個世代

<p class="freq">⭐⭐｜課題五 第4章</p>

| 世代 | 特點 | 住宿及飲食偏好 |
|---|---|---|
| ==老一輩== | 務實保守；重視**安全**；忠誠 | 先考慮安全保安；重複光顧；==通用設計==；家庭式餐館、小份量 |
| ==嬰兒潮==（1946–64） | 富有；要求詳盡資料；開始退休 | 舒適、質素、品牌形象；**醫療健康旅遊**；高級餐飲、品酒 |
| ==X 世代==（1965–79） | 物質；**工作與生活平衡** | 休閒花費最高；時尚雅致；未必重複光顧；追求物有所值 |
| ==Y 世代==（1980–2000） | 擅長科技、缺乏耐性、引領潮流 | **品牌忠誠度最低**；上網、平面電視；**互聯網推廣最有效**；快餐及健康食品 |

## 氣候變化與旅遊業

<p class="freq">⭐⭐⭐｜課題五 第5章</p>

| 旅遊是==載體== | 旅遊是==受害者== |
|---|---|
| 明確且上升的==碳足印==；**航空運輸**是主因；營運大量耗水耗能、破壞臭氧層物質 | 《達沃斯宣言》：氣候是旅遊資源；極端天氣、缺水；冬季活動減少、海灘侵蝕；高山、島嶼、沿海最敏感 |

| 氣候變化 | 影響 |
|---|---|
| 升溫減雪 | 滑雪季縮短 |
| 升溫減雨 | 遊客避開酷熱缺水地區；珊瑚**白化** |
| 海平面上升 | 低窪島嶼及海灘被淹 |
| 極端天氣 | 颶風（新奧爾良）、超強颱風（菲律賓） |

**減排趨勢**

- ==綠色飛機==：節省燃料引擎、較輕機身
- 更多**不停站直航**
- **替代燃料**（液化氫、生物燃料）
- 政府：提高離境稅；提高公眾對飛行環境成本的關注

## 負責任旅遊

<p class="freq">⭐⭐⭐｜課題五 第5章</p>

**負責任**：減少環境負面影響、為當地社區帶來經濟效益、保存文化及自然資源

| 類型 | 要點 |
|---|---|
| ==生態旅遊== | 尊重大自然，保育環境，改善居民福祉 |
| ==地質旅遊== | 維持或提升地點的地理特色 |
| ==負責任旅遊== | 以**當地社區利益**為前提 |
| ==可持續發展旅遊== | 考慮現在及未來經濟、社會、環境影響 |
| ==道德旅遊== | 以社會不公、人權、動物福利等道德議題為動力 |

**==良心旅客==**驅動需求

- 嬰兒潮：退休、富有、關注環保
- X 世代：環保消費主義
- Y 世代：熱衷環境及社會公義

- 旅遊業既是載體亦是受害者 → **比其他行業更需要保護環境**

## 環保酒店

<p class="freq">⭐⭐⭐｜課題五 第5章</p>

**==環保酒店==**（綠色酒店、可持續發展酒店）：推行**節約用水、節約能源、減少固體廢物**計劃以節省金錢及保護地球

| 酒店服務 | 主要環境影響 |
|---|---|
| 行政 | 紙張、碳粉盒 |
| 技術服務 | 能源及水；廢水；農藥 |
| 餐廳廚房 | 包裝廢棄物；廢油；有機廢物 |
| 客房 | 能源、水；有害清潔物品 |
| 洗衣 | 能源、水；廢水 |

- 認證**未有統一標準**；共同標準：減碳排、減能源、減用水、減廢物
- 「環保」包括可持續發展及**企業社會責任**：政策、員工培訓、環境管理、採購、社區、目的地保護

**三個好處**

1. 符合==注重生態意識==客人期望，提升形象
2. 為下一代保護環境
3. **節約成本、改善盈利**

## 飲食業的環保趨勢

<p class="freq">⭐⭐⭐｜課題五 第5章</p>

| 趨勢 | 要點 |
|---|---|
| **減少紅肉** | 牲畜排放約佔人為溫室氣體 14.5%；牛肉最多；餐單多提供**白肉** |
| ==採購本地食品== | 減少運輸排放；保存農地；有利土地、水及野生動物 |
| ==可持續採購== | 考慮社會及環境因素；==海鮮選擇指引==防止過度捕撈 |
| **節能守則** | 能源星級設備、適當大小、定期保養、關閉不必要設備、教導員工 |

**廚餘**：香港每天約 3,600 公噸，佔都市固體廢物約 40%；**食用階段**是飲食業主要來源（任食自助餐、文化態度、非選擇性餐單份量過多）

| 程序 | 減少廚餘 |
|---|---|
| 採購 | 適量；認可供應商 |
| 貯存 | 檢查品質；**先入先出**；溫度控制 |
| 烹調 | 每日生產計劃；善用剩食；捐贈剩料（半島酒店） |
| 食用 | 提醒勿過量點菜；**小份量**；環保外賣容器 |

## 旅遊業科技與全球分銷系統

<p class="freq">⭐⭐⭐｜課題五 第6章</p>

| 對企業 | 對顧客 |
|---|---|
| **改善成本效益**（減文件工作，多時間服務顧客） | **方便購買**（直接與中介交易） |
| **加強預報**（營收管理、市場數據） | **加快購買決定**（一站式） |
| **整合分散的產品**（CRS／GDS 一站式） | **提供更多產品訊息** |

**==全球分銷系統==（GDS）**

- 前身是航空公司的==電腦預訂系統==（CRS），後集合多間航空公司資訊
- 連繫航空、酒店、旅行社、租車、郵輪；四大：AMADEUS、GALILEO、Sabre、Worldspan
- 效用：任何時候訪問｜每秒處理 17,000 訊息｜可最後一刻更改｜自動計算票價｜比較價格存量｜安全儲存旅客資料

**==酒店資產管理系統==**是營運**核心／資訊樞紐**：訂房（超額警告）｜登記退房｜顧客記帳｜客房狀況（OD → VD 自動更新）

| 顧客界面應用 | 好處 |
|---|---|
| ==通話計算系統== | 自動計費、杜絕濫用 |
| ==電子門鎖系統== | 遺失即失效；記錄出入；RFID |

| ==顧客配套服務== | 自動來電喚醒、語音訊息 |

| 好處 | 擔憂 |
|---|---|
| **企業**：降低成本、減輕工作量、提高效率、增加收入、分享資訊、優化管理 | **企業**：高層知識不足、巨額投資、員工壓力 |
| **顧客**：方便、服務水平穩定、改善體驗、更多選擇 | **顧客**：==科技焦慮症==、==社交焦慮症==、私隱、失去個人化服務 |

**建議**：方便使用｜直接惠及用家｜提供更多選擇｜培訓及技術支援

## 自助式服務科技與餐飲科技

<p class="freq">⭐⭐⭐｜課題五 第6章｜2025 卷二電子餐牌</p>

**==自助式服務科技==**：客人在服務過程中成為**生產者**，無需員工協助（ATM）

| 形態 | 例子 |
|---|---|
| 終端機 | 自助入住、旅遊資訊終端機 |
| 互聯網 | 網上預訂、虛擬導覽 |
| 流動裝置 | 預先登記、電子菜單點餐 |

- 客人在**不犧牲個人化服務**前提下，喜歡 SST 作**額外選擇**；長者或不習慣
- **科技是支援，而非取代人性化服務**

| 餐飲系統 | 功能 |
|---|---|
| ==電子銷售點系統== | 落單直達廚房；管理報告；電子餐牌 |
| ==食譜成本計算系統== | 自動更新成本，控制邊際利潤 |
| ==宴會管理== | 預訂房間、設備、套餐 |
| ==飲料控制系統== | 流量計對比銷售，找出浪費欺騙 |

**消費模式影響**：食品 24 小時運送全球（加工食物、碳足跡）｜外賣預訂（不健康、宅男）｜名廚效應、評論網站（可能失實）

!!! score "拿分要訣"
    科技題要**兩面**：好處（成本、效率、方便）＋擔憂（投資、焦慮症、私隱、失去人情味），以「科技作支援」作結。
