# 課題四 客務關係及服務

## 顧客服務的性質

<p class="freq">⭐⭐⭐｜課題四 第1章｜2026 DBQ</p>

**==顧客服務==**：一系列旨在增加顧客滿意程度的活動

| 範疇 | 要點 |
|---|---|
| ==綜合性== | 旅遊前（諮詢、預訂）及旅途中（交通、餐飲、住宿、觀光） |
| ==直接性== | 直接、及時、隨時提供 |
| ==情緒性== | 精神需求（認同、受尊重），重視態度 |
| ==時間性== | ==關鍵時刻==：交流留下良好印象或不滿 |
| ==應變性== | 不同顧客對滿意度理解不同 |

| 實物商品 | 服務 | 意義 |
|---|---|---|
| 有形 | ==無形== | 購買前難以感知 |
| 生產使用分開 | ==同時進行== | 員工、顧客及其他顧客都是體驗一部分 |
| 標準化 | ==多變性== | 質素缺乏一致性 |
| 可保存 | ==不可保存== | 不能作存貨 |

**重要性**：以服務為中心的公司價格可高 **9%**；找新顧客時間是保留舊客的**五倍**；不滿顧客告訴最少 **9 人**

## RATER 五個服務特點（Parasuraman）

<p class="freq">⭐⭐⭐⭐｜課題四 第1章</p>

| 特點 | 意思 | 例子 |
|---|---|---|
| ==可靠性== | 每次準確提供**承諾**的服務；**最重要** | 遵守明確及隱性承諾 |
| ==可信性== | 員工知識及禮貌，贏取信任；**其次重要** | 熟悉產品、專業 |
| ==有形性== | 設施、設備、員工外表與服務種類**相符** | 傳統大堂放摩登傢俬顯得格格不入 |
| ==關懷性== | 關心、理解、個人化服務 | 認得常客；協助丟失行李者 |
| ==反應性== | 及時、高效率、禮貌 | 電視壞了不應等數日 |

| 承諾 | 例子 |
|---|---|
| ==明確承諾==（供應商保證） | 薄餅 30 分鐘送到，否則折扣 |
| ==隱性承諾==（顧客推斷） | 酒店客房最少有一張床 |

- 別稱：可信性＝確實性；有形性＝實體性；關懷性＝同理心；反應性＝反應能力

## 員工的個人特質

<p class="freq">⭐⭐｜課題四 第1章</p>

| 特質（旅發局） | 要點 |
|---|---|
| ==儀表== | 大方得體、和藹笑容、整齊 |
| ==品格== | 喜歡與人接觸、成熟開朗、幽默、樂於助人、有耐性、誠懇 |
| ==學歷及技能== | 專業訓練、流利英語、了解本港時事及中國文化、外語 |
| ==其他== | 體格健全、思考敏捷、決斷力、適應力、願意長時間工作、忠誠 |

**為何重要**

- 服務的提供與消費**同時進行** → 員工行為態度直接影響體驗
- 儀表是優質服務的**表徵**
- 個人素質有助建立良好客戶關係 → 達至優質服務

**達至顧客期望的方法**：重視顧客｜禮貌待人｜把握時間｜服務熱情｜全心投入

## 需要、期望、認知與滿意度

<p class="freq">⭐⭐⭐｜課題四 第2章</p>

| 概念 | 定義 |
|---|---|
| ==需要== | 維持生命的基本所需；一生持久不變 |
| ==願望== | 因人而異、隨時間改變的慾望 |
| ==需求== | 擁有==購買力==時願望轉化為需求 |
| ==期望== | 滿足需要及願望時希望獲得的利益 |
| ==認知== | 對產品服務的感受；受過往經驗、口碑、廣告影響 |
| ==滿意度== | 認知符合或超過期望 |

**==滿意度 = 認知 − 期望==**（認知 ≥ 期望 → 滿意）

| 馬斯勞層次 | 款待業例子 |
|---|---|
| 生理 | 用膳填飽肚子 |
| 安全 | 入住酒店 |
| 歸屬感及關愛 | 酒吧、俱樂部 |
| 受尊敬 | 高檔時尚地方 |
| 實現自我 | 假期、宴會 |

**卓越服務**：多次稱呼顧客名字；總結確認所聽內容；主動代召的士

## 顧客忠誠度計劃

<p class="freq">⭐⭐⭐⭐｜課題四 第2章｜2026 考評報告點名弱項</p>

- ==顧客終身價值==：現有價值＋將來繼續光顧的流轉現金
- ==顧客忠誠度==：重複購買並向別人介紹
- 吸引新顧客開支高**五至十倍**

| 對企業 | 對顧客 |
|---|---|
| 留客成本低；每人推薦 **12 人**；反映意見；少關注價錢，多花 **67%**；==顧客數據庫== | 消除疑慮；覺得精明；累積好處；增值；級別帶來尊重 |

| 類型 | 運作 | 特點 |
|---|---|---|
| ==簡單計分計劃== | 積分換折扣贈品（買 5 送 1） | 最常見；鼓勵**短時間經常購買**；短期價值 |
| ==級別計劃== | 忠誠度越高獎賞越大 | **長期價值**；適合航空公司、酒店 |
| ==夥伴計劃== | 與**非競爭企業**合作互換積分 | 航空公司與信用卡 |

- 科技：RFID、==流動條碼==（綠色、低成本、提高品牌知名度）

!!! trap "易錯"
    分清問「對**企業**」還是「對**顧客**」的好處；以資料的運作特徵辨識類型。

## 關鍵時刻

<p class="freq">⭐⭐⭐｜課題四 第2章</p>

**==關鍵時刻==**：顧客與員工交流所產生的影響，留下**良好印象或不滿**；單一關鍵時刻已可改變整個服務體驗

**==餐廳服務周期==的 12 個接觸點**

1. 初步接觸
2. 餐廳入口
3. 接待員
4. 調酒師
5. 餐桌狀況
6. 見習侍應
7. 餐廳服務員
8. 餐廳經理
9. 食物
10. 洗手間
11. 結賬
12. 告別

- 每個接觸點都可能出現關鍵時刻
- **前線員工**如何處理交流影響顧客對整個過程的看法 → 在防止==服務失誤==上扮演重要角色
- 例：初步接觸時電話態度惡劣 → 影響對餐廳**可靠性**的看法
- 全面優質服務策略之一：把每個關鍵時刻（包括危機）轉化為有利時刻

## 服務品質差距模式

<p class="freq">⭐⭐⭐⭐⭐｜課題四 第2章｜2015–2025 幾乎每年</p>

Parasuraman、Zeithaml、Berry（1985）：找出服務接觸前後的問題，發展==服務提升==及==服務補救==

| 差距 | 名稱 | 公式 | 意思 |
|---|---|---|---|
| 一 | ==認識差距== | 顧客期望 − 管理層對顧客期望的認知 | 管理層**不了解**顧客期望 |
| 二 | ==服務設計及標準差距== | 管理層的認知 − 服務質素規範 | **知道**但**訂不出**合適標準 |
| 三 | ==服務表現差距== | 服務質素規範 − 實際提供的服務 | **有標準**但員工**做不到** |
| 四 | ==溝通差距== | 實際提供的服務 − 對外溝通 | 宣傳**誇大**或隱藏收費 |
| 五 | ==顧客差距== | 顧客期望 − 顧客認知 | **決定滿意度** |

- 差距五（顧客差距）受差距一至四（==服務提供者差距==）影響
- 顧客期望來自：口碑、個人需要、過往經驗

!!! score "拿分要訣"
    **四步**：指出差距（名稱＋編號）→ 引資料原句 → 以課本成因解釋 → 針對成因提出改善。

## 服務品質差距的成因

<p class="freq">⭐⭐⭐⭐⭐｜課題四 第2章</p>

| 差距 | 成因 |
|---|---|
| **一 認識** | ==市場調查==不足或不全面｜缺乏==對上溝通==（多層之隔、員工不報負面消息）｜著重交易多於建立關係｜不足的服務補救（視投訴為麻煩） |
| **二 設計及標準** | 差劣的==服務環境==（人力物力未配合崗位；受成本限制未能更新）｜欠缺==以顧客為驅動的標準==（為減成本降低水平；追隨同業標準） |
| **三 表現** | ==人力資源政策==不足（員工質素、==角色模糊與衝突==、科技未配合、評估獎勵不當）｜顧客未盡本分（不知下午六時政策；互相滋擾）｜==中介服務==（外判洗衣）｜==季節性==（旺季） |
| **四 溝通** | 無效能的==顧客期望管理==（不知 10% 服務費）｜誇大的宣傳及個人銷售承諾｜缺乏==橫向溝通==（部門之間、分店政策不同） |

!!! trap "易錯"
    差距一是**不知道**，差距二是**訂不出**；差距三是**做不到**，差距四是**宣傳不符**；差距五是**顧客**的差距。

## 以顧客為中心及服務承諾

<p class="freq">⭐⭐｜課題四 第3章</p>

**==以顧客為中心==三步驟**：了解需要 → 轉化為產品服務 → 在**消費前、時、後**提供卓越服務

| 酒店 | 使命宣言 |
|---|---|
| 香格里拉 | 每時每刻令客人喜出望外 |
| 文華東方 | 令顧客稱心如意 |
| 麗嘉 | 一羣樂於服務紳士淑女的紳士淑女 |

- 公式：**顧客滿意度 = 一流服務 + 卓越品質 + 創新 + 合理價格**；但忽略**員工**、**顧客認知**及如何量度品質

**服務標準及承諾**

- 問題源於系統或人為，**系統問題最易解決**
- 簡化：流程標準化、合理用技術、內部培訓、衡量成績、投入資源
- 公司須有：出色選拔培訓、明確工作指令、溝通渠道、充份==授權==

**建立提升滿意度的文化**：積極而非只在投訴時關注；**持續過程**；全體參與

## 全面優質服務（TQS）

<p class="freq">⭐⭐⭐｜課題四 第3章｜2025 MC 易錯</p>

**定義**：確保**以顧客為中心**、有**明確服務標準**及**獎勵出色表現**的承諾

**七項策略**

1. **珍惜顧客**：一句「謝謝！」
2. **尋找並解決問題**：不滿顧客只有 **4%** 投訴；在投訴前解決
3. **展示競爭優勢**：讓顧客深信選擇正確
4. **負責解決顧客的問題**
5. **感謝購買過程的每個人**（秘書、委員會）
6. **提高顧客的要求**：令對手顯得不及
7. **把握==關鍵時刻==**

!!! trap "易錯"
    餐廳率先回收廚餘加工成飼料，以環保效益提升品牌差異化 → 屬「**展示競爭優勢**」。

## 服務失誤、服務金三角與補救

<p class="freq">⭐⭐⭐⭐｜課題四 第3章｜2025 DBQ</p>

- ==服務失誤==：服務低於預期；==服務補救==：令顧客滿意的回應
- ==服務金三角==：**顧客、公司、服務（員工）**相互關係；須支援及培訓員工
- 沒有補救：顧客覺得不被重視、流失忠誠顧客、負面口碑（滿意告 5–6 人，不滿告最少 9 人）

| ==服務接觸==三要素 | 例子 |
|---|---|
| ==服務目標== | 安全送交行李 |
| ==服務的提供== | 航班按時抵達 |
| ==服務標準== | 確認機票最短時間 |

**補救措施**：分析問題本質（產品、員工、系統）｜搜集資料追查｜培訓處理憤怒顧客｜**方便投訴渠道**｜清楚權限

- ==全面品質管理==：動員全公司及供應鏈
- 不滿不投訴只 **9%** 再光顧；投訴快速解決 **82%** 再光顧；麗嘉授權員工 **2,000 美元**

!!! trap "易錯"
    酒店網頁三維虛擬導覽屬**外部行銷**（公司對顧客），不是互動行銷。

## 招待不易取悅的顧客

<p class="freq">⭐⭐｜課題四 第4章</p>

| 顧客 | 處理方法 |
|---|---|
| ==憤怒== | 說「能做甚麼」；了解原因；使客人放心；保持客觀；積極聆聽 |
| ==不滿意== | 用**正面詞句**；保持積極；微笑介紹自己；**不找藉口** |
| ==猶豫不決== | 耐心；開放式問題；**引導**而非代決定 |
| ==苛刻專橫== | 保持專業；尊重（稱呼姓名）；說明能力範圍 |
| ==粗魯== | 冷靜堅定：「處理完這位客人後立刻幫您」 |
| ==喋喋不休== | 真誠簡短；用==封閉式問題==控制；主導結束 |

- 認知感受：**觀察、聆聽、查詢**；用==開放式問題==（誰、甚麼、哪裡、何時、怎樣）
- **避免問「為甚麼」**：令顧客覺得被責怪

**投訴是特別的問題**：糾正難以發現的問題｜建立關係｜改進服務

## 處理投訴的原則

<p class="freq">⭐⭐⭐｜課題四 第4章</p>

1. **保持冷靜**
2. **保持禮貌**：使用顧客名字
3. **正面態度**：不忽略、不認為針對個人、不偏激
4. **表示關心**：介紹自己、聆聽、回應、提供幫助
5. **澄清確認**：用自己的語言**複述**問題
6. **評估投訴**：親自處理、尋求援助或評估是否合理
7. **作出決定並提出建議**：達成妥協
8. **跟進問題**：確保落實，有變告知

**投訴程序（操作標準）包括**：誰負責｜步驟｜個人權限｜記錄結果

- 例：親身投訴 15 分鐘內處理；書面投訴當天發確認函
- ==授權==員工自行解決（迪士尼演藝人員）
- 積極回應網上評論、承認錯誤，可增加可靠性

## 與顧客溝通

<p class="freq">⭐｜課題四 第5章</p>

- **取悅顧客**：滿足 → 滿意；**預測及超越** → 取悅
- 有效溝通：訊息被接收**並理解**；「==噪音==」干擾

| 積極聆聽 | 提問類型 |
|---|---|
| 專注、認同（「我明白」）、複述內容及感受、觀察及使用身體語言 | ==開放式==、==封閉式==（是／否）、==反應型==、==探索式== |

**書寫 ==5C==**：簡潔｜正確｜清晰｜完整｜有禮

| 面對面溝通 | 電話溝通 |
|---|---|
| 個人化、互動、結合技巧、即時 | 無法用身體語言；說出名字公司、備紙筆、不飲食、保持微笑 |

- 表達：談吐清晰、音量適中；避免聲調過高、單調、過快或過慢
- 溝通障礙：承認困難、解釋、尋求協助
- ==非言語溝通==因文化背景而異（雙手交叉 → 戒心；手指輕敲 → 不耐煩）
