## 時區與經緯度

<p class="freq">⭐⭐⭐｜課題三 第1章</p>

| 概念 | 要點 |
|---|---|
| ==本初子午線== | 1884 年訂立；經度 0 度，穿越格林威治 |
| ==格林威治時間==（GMT） | 以本初子午線為標準 |
| ==協調世界時==（UTC） | **1986 年取代 GMT**；採用**原子時** |
| ==國際日期變更線== | 距本初子午線 **180 度**；會調整避免穿越國家 |
| ==時區== | 24 個；**以東比 GMT 快、以西慢** |
| ==飛行時差== | 穿越多個時區後疲憊 |

**時差計算**：香港 UTC+8、法國 UTC+1 → 香港快 7 小時

| | ==緯線== | ==經線== |
|---|---|---|
| 方向 | 與赤道**平行** | 連接兩極，**不平行** |
| 量度 | 赤道以北／南 0–90° | 本初子午線以東／西 0–180° |

- 先緯度後經度；1 度 = 60 分；香港 22°20′N 114°11′E

## 旅遊景點與目的地

<p class="freq">⭐⭐｜課題三 第2章</p>

**==景點==**：任何吸引旅客前往的資源、設施或活動

| ==旅遊景點== | ==目的地== |
|---|---|
| **單一主要特色**的獨立地點 | 包含**多個景點**並有**支援服務**的較大區域 |

**發展過程**

1. 單一景點
2. 目的地形成初期（增加服務）
3. 已發展但只有單一市場（新增景點迎合同一市場）
4. ==多元化目的地==（設新景點吸引新市場）

- 例：奧蘭多 — 迪士尼世界；盧克索 — 金字塔；北京 — 長城
- 景點組合吸引力更大，**延長目的地產品生命週期**
- 須注意==可達度==及運輸設施

## 景點的作用及特性

<p class="freq">⭐⭐｜課題三 第2章｜2025 考評報告點名弱項</p>

| 作用範疇 | 內容 |
|---|---|
| **目的地** | 演變成目的地的主要元素；目的地地標 |
| **運輸** | 促使新交通服務（迪士尼支線）；交通工具本身成景點（天星小輪） |
| **旅遊營運** | 經營商包裝成套餐；特殊興趣旅遊（品酒團） |

| 特性 | 意思 |
|---|---|
| ==高品質== | 整潔美觀、以客為本、資源保護、友善款待 |
| ==真實性== | 營造「==地方感==」，反映社區的自然、文化、經濟遺產 |
| ==獨特性== | 在 150–300 英里市場範圍內與別不同 |
| ==吸引性== | 旅客從多遠到訪、會否重遊 |
| ==活動選擇== | 多樣化、不斷推陳出新 |

## 景點的類型

<p class="freq">⭐⭐⭐｜課題三 第2章</p>

**Swarbrooke 四類**：==自然環境==｜==「人工」但非為吸引旅客而建==｜==「人工」並為吸引旅客而建==｜==特別活動==（唯一**短暫性**類型）

| Goeldner 等五類 | 例子 |
|---|---|
| ==文化景點== | 歷史景點（長城、金字塔）；傳統、藝術、手工藝、食品、音樂舞蹈、生活方式；宗教（麥加） |
| ==自然景點== | 氣候；地形（山地、海岸、瀑布、溫泉、溶洞）；動植物 |
| ==活動項目== | 盛事（奧運）、社區活動、運動、商貿、藝術文化 |
| ==消閒康樂== | 日光浴、滑雪、打獵釣魚 |
| ==娛樂演出== | 主題公園、賭場、購物、夜總會、動物園、水族館 |

**被文化景點吸引**：尋根｜欣賞藝術建築｜歷史意義｜觀察他鄉生活

**被自然景點吸引**：欣賞自然奇趣｜利用地形進行活動｜體驗鄉村｜觀看野生動物｜欣賞美景

## 首選／次選景點及擁有權

<p class="freq">⭐⭐｜課題三 第2章</p>

|---|---|

## 主題公園的特色及類型

<p class="freq">⭐⭐｜課題三 補充教材</p>

**與其他娛樂景點不同**

1. **一次入場費**任玩（遊樂場按次收費）
2. 設施大多**人工製造**
3. **高昂資本投資**
4. 結合娛樂、餐飲、商店

**定義**：「逃避的地方」；園內環境與門外真實環境截然不同

| 類型 | 特色 |
|---|---|
| ==冒險== | 刺激、驚慄、神秘 |
| ==未來世界== | 科技、機械人、科幻 |
| ==國際== | 地球村、微型複製品 |
| ==大自然== | 動物、海洋生物、園藝 |
| ==幻想世界== | 卡通、童話、魔術 |
| ==歷史與文化== | 文化遺產、文化村落 |
| ==電影== | 特技表演、西部牛仔 |

- 主題在規劃階段選定；現時多數公園有**多種主題**

## 產品三層次（Kotler、Swarbrooke）

<p class="freq">⭐⭐⭐｜課題三 補充教材｜2019、2021、2022</p>

| 層次 | 意思 | 例子 |
|---|---|---|
| ==核心產品== | 遊客實質購買的**無形**特質 | 興奮刺激、氣氛、有趣、物有所值、親朋歡聚 |
| ==支援（有形）產品== | 把核心產品**轉變為有形**，並與對手區分 | 機動遊戲、表演、餐飲、紀念品店、整潔安全環境、訓練有素團隊 |
| ==促成（延伸）產品== | 使用核心產品時**必須有的服務設施** | 穿梭巴士、無障礙設施、貯物櫃、停車場、提早入場、選址 |

| 景點 | 核心 | 有形 | 延伸 |
|---|---|---|---|
| 迪士尼 | 家庭娛樂、幻想 | 機動遊戲、戲服演員 | 手推車、年票、快速通行 |
| 山頂 | 天際線景色 | 觀景台、蠟像館 | 望遠鏡、摩天套票 |

- **有形及延伸產品必須配合核心產品**，否則景點失敗

## 主題公園成功的因素

<p class="freq">⭐⭐｜課題三 補充教材</p>

**整體吸引力及遊客體驗**

- ==獨特而有趣的主題==（創新、投入感官、互動、啟發）
- ==物有所值==、不同種類活動、餐飲
- ==整潔和舒適的環境==
- ==積極及訓練有素的團隊==（員工與遊客不可分割）
- ==選址恰當==：四通八達，解決**不可保存**的特色
- ==服務和設施質素及一致性==；應急方案

**適應市場轉變**

- ==年長客群==：低耗量活動、休息地方
- ==整體環保設計==：綠色建築、可再生能源
- ==教育與娛樂==（海洋公園）
- ==互動體驗==：==虛擬實境==、==擴增實境==、5D 電影

**管理**：積極管理層｜大量財務資源及持續投資｜強大市場推廣（多種門票）｜監測管理（安全計劃、符合法例）
