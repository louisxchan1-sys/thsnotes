# 課題二 款待導論

## 款待業的特點及與旅遊業的關係

<p class="freq">⭐⭐｜課題二 第1章｜2025 MC 易錯</p>

**==款待業==**：為「離家在外」的人提供食物、飲品及／或住宿的公司或組織

| 特點 | 要點 |
|---|---|
| ==產品服務組合== | 有形（牛扒、裝潢）＋無形（舒適環境、友善態度）；有形易被模仿 → 以服務區分 |
| ==雙向溝通== | 顧客與員工雙方投入；部門之間互動 |
| ==建立關係== | 倚賴**回頭客**：收入穩定、減季節性影響、正面口碑 |
| ==文化多樣性== | 接觸不同地區顧客及同事，持開放態度 |
| ==勞工密集== | 高級酒店員工對顧客比率高；重視「關心」元素 |

- **住宿和餐飲服務是款待業的核心**；款待業同時服務**遊客及非遊客**
- 管理人員三個目標：賓至如歸｜稱心如意｜持續服務並符合預算

!!! trap "易錯"
    **航空服務只屬旅遊業**（滿足交通需求），不同屬款待業。

|---|---|
| ==市中心酒店== | 市中心；可屬商務、套房或豪華 |
| ==機場酒店== | 為航機乘客；往返機場交通 |
| ==公路酒店／汽車旅館== | 駕車旅客隔夜；房間直通停車場 |

| ==商務酒店== | 鬧市；會議空間較會議酒店小 |
| ==度假酒店== | 風景優美但偏遠；停留較長；全面康樂設施 |
| ==水療酒店== | 療程、營養師、治療師 |
| ==賭場酒店== | 博彩為主要收入 |
| ==全套房酒店== | 起居室與臥室分開 |
| ==精品酒店== | 個性化，「設計酒店」「生活品味酒店」 |
| ==分時度假== | 購買每年某時段使用權，可繼承 |
| ==民宿旅館== | 家族擁有，東主住附近，包早餐 |
| ==賓館==／==旅舍== | 小型、設施有限／宿舍式、非常廉價 |
| ==長期住宅式酒店== | 長住；齊備廚房、有限管家服務 |

- **分類因素**：功能、位置、價格、市場定位、職員與客房比例、規模、設計、評級、物業特性

## 酒店的管理模式

<p class="freq">⭐⭐⭐｜課題二 第3章</p>

| 模式 | 意思 |
|---|---|
| ==獨立擁有及經營== | 擁有人自行管理 |
| ==管理合約== | 管理企業經營他人物業 |
| ==特許經營== | 付費使用品牌及營運模式 |

| 管理合約 | 好處 | 壞處 |
|---|---|---|
| 擁有人 | 專業知識減風險；著名品牌提升知名度；無需參與營運 | **失去控管權**；負擔所有成本損失 |
| 管理企業 | 不論業績收管理費；少前期投資 | 倚賴擁有人資金；不能干預產權 |

| 特許經營 | 好處 | 壞處 |
|---|---|---|
| 特許經營者 | 營運知識、==中央訂房系統==、著名品牌；**保留控制權** | 須遵守標準；加盟費及持續費；或不獲續約 |
| 特許權擁有者 | 收取費用 | 加盟者不守標準損品牌；披露機密 |

- 產權：私人｜本地集團｜國際集團

## 前堂部

<p class="freq">⭐⭐⭐｜課題二 第3章</p>

**酒店的==中樞神經==**，給予顧客**第一個及最後一個印象**

**三個主要功能**：銷售客房｜更新顧客帳戶｜提供服務及資訊

| 崗位 | 職責 |
|---|---|
| ==前堂經理== | 監察訂房、預測入住率、房價政策、款待 VIP |
| ==大堂副經理== | 代表管理層；處理**投訴**；歡迎 VIP |
| ==電話房== | 來電喚醒；保障私隱；緊急事件**通訊中心** |
| ==訂房部== | 確認單；要求核實訂房；決定停止接受或==超額預訂== |
| ==款接部== | 登記入住、結帳退房、保險箱、外幣兌換 |
| ==禮賓部== | 禮賓司、機場接待員、門僮、行李服務員 |
| ==行政樓層== | 特快登記、酒廊免費茶點、商務中心 |

- ==保證訂房==：預繳，不出現亦不退款，隔夜保留
- ==未獲核實訂房==：保留至抵埗日**下午 6 時**
- **顧客流程**：抵埗前 → 抵埗 → 入住 → 離開

## 入住登記及結帳退房程序

<p class="freq">⭐⭐｜課題二 第3章</p>

**入住登記（下午 2 時後）**

1. 迎接顧客
2. 核實身份（護照、訂房憑證）
3. 提供入住登記表格
4. 確認付款方式（信用卡或預先支付按金）
5. 在==酒店資產管理系統==更新帳戶、分配客房
6. 分發鎖匙並提供資訊
7. 陪同前往客房

- 團體：事先登記、團體入住櫃檯由領隊辦理

**結帳退房（中午 12 時前）**

1. 問候顧客
2. 核對資料
3. 核對**延遲退房費用**
4. 核對**漏帳**（早餐、迷你酒吧）
5. 請顧客核對費用
6. 結清：==總帳戶==（房間早餐）與==雜項費用帳戶==（個人開支）
7. 提供協助（行李、交通、預訂姊妹酒店）
8. 更新客房狀況（OD → VD）及顧客歷史

## 超額預訂

<p class="freq">⭐⭐｜課題二 第3章</p>

**原因**：減少顧客不出現及臨時取消的損失，提高客滿機會

**問題**：損害商譽、顧客不滿、投訴增加；**轉送顧客屬違約**

**預防**：檢查 OOO 房能否修好、雙重訂房；按優先次序分配（VIP、保證訂房、常客）；預先聯繫姊妹或附近酒店

**==轉送顧客==程序**（由經驗豐富員工處理）

1. **向顧客致歉**（酒店本身的過錯，不找藉口）
2. **提供其他選擇及賠償**：替代酒店首晚免房租、免費交通、長途電話、果盤、將來免費升級、餐飲折扣券；可邀請之後回來入住
3. **提供行李服務和交通**
4. **跟進服務**：致電替代酒店特別照顧；經理親自致電顧客

## 銷售指標

<p class="freq">⭐⭐⭐｜課題二 第3章</p>

| 指標 | 公式 | 意義 |
|---|---|---|
| ==入住率== | 已售房間 ÷ 房間總數 × 100% | 業務「數量」 |
| ==每入住房顧客人數== | 入住人數 ÷ 入住房數 | 估計用品消耗 |
| ==每日平均房價== | 客房收入 ÷ 入住房數 | 業務「質素」 |
| ==每間可銷售房收入== | 客房收入 ÷ 房間總數 | 利用所有客房賺取收入的能力；通常**小於**平均房價 |

**例**：310 間房，405 人入住 265 間，客房收入 424,500 港元

- 入住率 = 265 ÷ 310 = **85.48%**
- 每入住房顧客人數 = 405 ÷ 265 = **1.53**
- 每日平均房價 = 424,500 ÷ 265 = **1,601.89**
- 每間可銷售房收入 = 424,500 ÷ 310 = **1,369.35**

- 香港酒店收入：房間約 61%、餐飲約 32%

## 管家部及客房清潔

<p class="freq">⭐⭐｜課題二 第3章｜2025 MC 崗位職責</p>

- **潔淨是顧客挑選酒店的首要因素**；管家部往往是**最大**部門，屬支援中心

| 崗位 | 職責 |
|---|---|
| ==行政管家== | 招聘培訓、工作程序、輪值、訂購布草、管理鎖匙 |
| ==樓層主管== | 檢查客房及員工；與款接部聯絡抵離 |
| ==房務員== | 清潔客房浴室；==開床服務==；報告故障 |
| 公共地方主管／清潔員 | 大堂、走廊、辦公室 |

**清潔次序**：① 要求優先服務 → ② 禁止來賓進入的已退房客房 → ③ 已退房客房 → ④ 有顧客入住的客房

**清潔程序**：敲門告知三次 → 初次檢查設備 → 鋪床 → 清垃圾 → 清潔浴室補用品 → 由內至外吸塵 → 最後檢查、回復待售

- ==失物認領處==：記錄於記錄簿，保管**三個月**
- 鎖匙：上鎖櫃、簽入簽走、不可帶出酒店

| ==其他公營部門市場== | 監獄、軍校（非牟利，減成本） |

| 營運模式 | 特點 |
|---|---|
| ==獨立經營== | 家族經營，絕對控制權；**結業率最高** |
| ==連鎖經營== | ==單一概念==（麥當勞）／==多元概念==（美心）；品牌知名度高、品質一貫 |
| 以盈利／非以盈利為宗旨 | 一般餐廳／公司、學校、醫院飯堂 |

## 餐廳類型比較

<p class="freq">⭐⭐⭐⭐｜課題二 第4章｜2026 卷二</p>

| | ==高級餐廳== | ==休閒餐廳== | ==快餐店== | ==酒吧== |
|---|---|---|---|---|
| 餐單 | ==自選餐==；酒類多；==即點即煮==；定價高 | 選擇多；價格適中；或有套餐 | 選擇少；中央廚房半加工；便宜 | 酒精飲品為主；小食 |
| 服務 | ==職員對顧客比率高==；==翻檯率低==；全套餐桌服務；10% 服務費 | 職員比率較低；簡單擺設 | 比率**極低**；**自助**；不收服務費；無需等待 | 晚上營業；18 歲以上 |
| 主題 | 講究裝潢；寬敞私隱；高貴典雅 | 輕鬆 | 現代、豔麗、品牌形象 | 吧檯；燈光暗 |

**延伸**：==咖啡室==（飲品為主、自助、鼓勵逗留）｜==特色餐廳==（單一食物或地方菜）｜==自助食堂==（櫃檯式、自由流動式、超級市場式）

## 餐單規劃與定價

<p class="freq">⭐⭐⭐｜課題二 第5章</p>

**餐單**是餐飲運作的**基本文件**：廚房的工作文件＋顧客的菜餚資訊

| 考慮因素 | 內容 |
|---|---|
| 與顧客有關 | 顧客類型、消費能力、用餐次序、特別要求（宗教） |
| 與食物有關 | 成本及價格、供應（季節性）、營養價值、選擇數目、衞生安全 |
| 與營運有關 | 廚房大小設施、位置、營業時間、員工技能 |
| 與市場有關 | 同行做法、餐廳裝潢、推廣工具、使用語言 |

| 定價方法 | 內容 |
|---|---|
| ==成本法== | **食物成本百分比 = 食物成本 ÷ 售價 × 100%**；一般 20%–30%；飲料成本低、利潤高 |
| ==主觀法== | 高級食府定價高營造奢華；快餐店低於市價吸引顧客 |

**餐牌設計**：窗口摺疊式先看**中間**；書本摺疊式先看**右下方**；防污耐用、字體易讀、描述如實

## 餐桌擺設、環境氣氛及廚房佈局

<p class="freq">⭐⭐｜課題二 第5章</p>

**餐桌擺設**：左旁碟（牛油刀刀鋒向左）→ 中托碟 → 主刀右、主叉左 → 湯匙在主刀右 → 沙律刀叉在外 → 甜品匙叉在上 → 水杯右上 → 餐巾中間

**環境氣氛**：燈光、音樂、氣味；裝修風格；員工制服；**五感**（視、觸、聽、嗅、溫度）

**==主題餐廳==**：概念凌駕一切，主題比食物重要；六類：電影｜運動｜懷舊｜音樂電視｜旅遊交通｜生態

**用餐區佈局**：可拆分餐桌、卡位、獨立房間（最低消費）；==銷售點系統==；款接員控制==翻檯率==

**廚房設計原則**

- 流程暢通（原材料 → 製成品）；**生熟分開**
- 冷盤區 → 熱食區 → 甜品區（按用餐次序）
- **員工安全是首要條件**；減少走動路線交錯
- 考慮：餐單範圍、員工數目技能、服務方式、儲存區

## 消防安全

<p class="freq">⭐⭐⭐｜課題二 第5章｜5 次</p>

**==燃燒三元素==**：可燃物｜氧｜熱能 → 移除任何一種即可滅火

| 火的類別 | 燃燒物 |
|---|---|
| A | 固體有機物 |
| B | 液體或可熔化固體 |
| C | 氣體 |
| D | 金屬 |
| E | 帶電物質 |

| 滅火用具 | 原理 | 適用／禁止 |
|---|---|---|
| ==二氧化碳== | 排擠空氣 | 電火、易燃液體；用後到空曠處 |
| ==水式== | **降溫** | 木、紙、布；**禁**電火、液體、金屬 |
| ==乾粉式== | 吸熱、阻隔 | **大多數**火警；減能見度 |
| ==淨劑== | 不留殘餘 | 電火、電子儀器 |
| ==泡沫式== | 隔絕液面 | 易燃液體；**禁**電火 |
| ==滅火氈== | 隔絕 | 廚房小火 |
| ==沙桶== | — | 小火、金屬 |

!!! trap "易錯"
    電火可用二氧化碳、乾粉、淨劑；**不可**用水及泡沫。課本是 A–E 類。

## 食物污染

<p class="freq">⭐⭐⭐｜課題二 第6章</p>

- ==食物中毒==：進食受污染食物的**急性疾病**
- ==食物污染==：**非故意**加入食物的有害物質

| 類別 | 例子 |
|---|---|
| ==生物性== | 細菌、病毒（==諾如病毒==）、寄生物 |
| ==化學性== | 添加劑（==二氧化硫==、==蘇丹紅==）、殘餘農藥獸藥（==孔雀石綠==）、**清潔劑**、生化毒素（雪卡毒、==組胺==） |
| ==物理性== | 玻璃碎、毛髮、釘書釘、竹籤 |

| 細菌 | 源頭 | 特性 |
|---|---|---|
| ==沙門氏菌== | 生肉、未熟蛋 | 70°C 死亡 |
| ==金黃葡萄球菌== | 皮膚、鼻腔、傷口 | 毒素耐高溫 |
| ==副溶血性弧菌== | **海產、介貝類** | 煮 10 分鐘死亡 |
| ==李斯特菌== | 軟芝士、即食肉類 | **0°C 也可生長** |
| ==臘樣芽孢桿菌== | 剩飯、炒飯 | 孢子抵受高溫 |

!!! trap "易錯"
    清潔劑屬**化學性**；高溫**不能**去除耐熱毒素（雪卡毒、組胺）；膠布用**非肉色**。

## 細菌生長條件及溫度控制

<p class="freq">⭐⭐⭐⭐｜課題二 第6章</p>

| 條件 | 要點 |
|---|---|
| **食物** | 水份蛋白質豐富的==高風險食物==（肉類、海產、奶類） |
| **水** | 少量水份即活躍 |
| **溫度** | ==危險溫度範圍 4°C–60°C==；最適 37°C |
| **時間** | 10–20 分鐘倍增；不應在危險區**超過 2 小時** |

| 情況 | 溫度 |
|---|---|
| 冷凍（短期） | **4°C 或以下** |
| 冷藏（長期） | **−18°C 或以下**（雪糕 −23°C） |
| 熱存 | **60°C 或以上** |
| 烹煮中心溫度 | **75°C 至少 15 秒** |
| 翻熱 | 75°C 以上，2 小時內；不可再冷卻翻熱 |
| 解凍 | 雪櫃 **8°C 或以下**、流動凍水、微波爐；**切勿室溫解凍** |

- 溫度計：玻璃溫度計**不宜**；紅外線只量**表面**；冰點法 0°C、沸點法 100°C，誤差 >1°C 須調校

## 食物安全五要點及安全處理操守

<p class="freq">⭐⭐⭐⭐⭐｜課題二 第6章｜幾乎每年 MC</p>

1. ==精明選擇==：安全的原材料
2. ==保持清潔==：雙手及用具
3. ==生熟分開==
4. ==煮熟食物==：徹底煮熟
5. ==安全溫度==：**4°C 或以下，或 60°C 或以上**

| 工序 | 要點 |
|---|---|
| 選購 | 持牌可靠供應商；適量 |
| 收貨 | 檢查保質期、溫度；不合格分隔 |
| 貯存 | **離地 300 毫米**；生熟分開；==先入先出==；標籤日期 |
| 配製 | **不同顏色**用具分生熟；即棄手套；試味用具每次消毒 |
| 冷卻 | 分小份、淺容器、切小塊、留空間 |
| 端送 | 不用手拿冰；握餐具柄；剩食不得再給他人 |
| 陳列／自助餐 | 防噴嚏護罩；小量展示、整盤更換 |

!!! score "拿分要訣"
    先**辨識違反哪一要點**（引資料），再以細菌生長條件或溫度數字解釋，最後提出改善。

## 飲食從業員的個人衞生

<p class="freq">⭐⭐⭐｜課題二 第6章</p>

| 範疇 | 要點 |
|---|---|
| 儀容 | 不留長髮長指甲、不塗甲油、不戴飾物、避免濃香水 |
| 習慣 | 不在配製區吸煙、吐痰、試味用手指；**不同時處理現金和食物**；打噴嚏轉身遮掩後洗手 |
| 健康 | 腹瀉、嘔吐、咽喉痛須報告停工；腸道傳染病康復或停徵 **48 小時** |
| 傷口 | 防水手套或**非肉色**膠布；不能覆蓋須停工 |
| 工作服 | 淺色清潔、無鈕扣、髮網、口罩、密頭鞋 |

**洗手步驟**

1. 溫水弄濕雙手
2. 塗梘液
3. 搓擦 **20 秒**（前臂、手背、指縫、指甲）
4. 徹底沖洗
5. 抹手紙或乾手機弄乾
6. 以抹手紙包水龍頭關掉

**必須洗手**：開工前｜處理食物前｜如廁後｜處理生食後｜咳嗽打噴嚏後｜處理垃圾或金錢後

- 良好食物衞生效益：符合法例、商譽、士氣、延長保貯期
