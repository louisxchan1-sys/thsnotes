# 3. 公司的顧客服務政策

## 3.1 公司在優質服務上的使命

### ==以顧客為中心==

- 待客方法能建立顧客忠誠度、刺激再消費；不僅涉及前線員工，亦包括主任、管理人員、其他部門、公司架構、營運體系及==公司文化==
- **三個步驟**：了解顧客的需要 → 將需要轉化為產品及服務 → 在顧客**消費前、消費時及消費後**均提供卓越服務
- 宣言要點（例：喜達屋）：產品與服務設計以顧客為中心｜不斷研究顧客需要與期望｜提供合適產品以維持競爭優勢

### ==使命宣言==例子

| 酒店 | 使命 |
|---|---|
| 香格里拉 | 「每時每刻令客人喜出望外」；亞洲式殷勤好客；「自豪而不驕矜」 |
| 文華東方 | 「令顧客稱心如意是我們的使命」 |
| 麗嘉 | 一羣樂於服務紳士淑女的紳士淑女 |
| 四季 | 只提供非凡的優質體驗 |
| 半島 | 無與倫比的客戶服務、豪華環境、一流設施及佳餚 |

- 公式：**顧客滿意度 = 一流的顧客服務 + 卓越的品質 + 創新 + 合理的價格**；但忽略了**員工**的重要性、**顧客認知**，亦沒有考慮如何量度品質

## 3.2 服務標準及承諾

- 全體員工（包括高級管理層）須對服務品質作出承諾：顧客、優質產品、員工、禮貌、物有所值
- 問題源於**系統設計**或**人為**，系統問題最容易解決；系統越簡潔、程序越清晰越易運作

**簡化程序**：任務及流程標準化｜合理運用技術｜內部培訓｜制訂達到顧客期望的目標｜正式途徑衡量評估成績｜投入資源｜質量方案保持靈活

**公司必須具備**：出色的選拔及培訓程序｜簡單明確的工作指令｜有效溝通渠道｜人際溝通培訓｜適當資源、靈活性和充份的==授權==（員工無需頻頻尋求批准即可決策）

### ==全面優質服務==（TQS）

公司確保**以顧客為中心**、有**明確服務標準**及**獎勵出色表現**的承諾。挽留顧客的策略：

1. **珍惜顧客**：一句「謝謝！」效果顯著
2. **尋找並解決問題**：不滿顧客只有 **4%** 會投訴；目標是在顧客投訴前解決問題
3. **展示競爭優勢**：讓顧客深信選擇正確（如向已離開顧客發電郵致謝及優惠）
4. **負責解決顧客的問題**
5. **感謝參與購買過程的「每個人」**（私人助理、秘書、委員會）
6. **提高顧客的要求**：令顧客認為對手不及你的水準
7. **把握「==關鍵時刻==」**：把每個關鍵時刻（即使是危機）轉化為有利時刻

!!! trap "易錯"
    2025 MC 有 63% 考生答錯：全面優質服務的「**展示競爭優勢**」可包括環保做法，例如餐廳率先回收廚餘加工成牲畜飼料，以正面環保效益提升品牌差異化。

## 3.3 建立提昇顧客滿意度的文化

- 只在接到投訴時才關注顧客服務，問題最初的不滿感覺仍會存在 → 應以**積極**角度看待顧客服務
- 顧客服務是**持續的過程**，須不斷更新規劃及評估
- 需要管理層、主任、前線員工及支援部門携手合作；承諾以顧客為中心、讓全體員工參與決策、不斷完善
- 例：華特‧迪士尼的標準：對嘉賓的責任、質量、客人的安全（絕不因經濟目標而損害）

## 3.4 服務失誤及補救

- ==服務失誤==：顧客投訴服務低於預期；影響利潤、聲譽、忠誠顧客流失及未來業務
- ==服務補救==：就服務失誤作出令顧客滿意的回應

### ==服務金三角==

顯示**顧客、公司及服務（員工）**之間相互關係的重要性；服務出問題時顧客一方較少需要妥協，故向員工提供支援、科技及培訓極為重要。

!!! trap "易錯"
    2025 MC 有 48% 考生答錯：服務金三角中，**酒店網頁提供三維虛擬導覽**屬「公司對顧客」的**外部行銷**，不是員工與顧客之間的**互動行銷**。

### 控制品質成本

- 改善質素從**外部顧客／市場需要**及**內部顧客／營運需要**著手
- 將投訴分類：評估內部系統｜改變工作流程｜消除投訴根源；定期顧客滿意度調查
- ==全面品質管理==：動員全公司、整個供應鏈及所有產品服務，確保顧客滿意度維持高水平

### 沒有服務補救計劃的後果

顧客認為公司不重視產品服務｜不重視他們｜流失忠誠顧客｜負面口碑損害聲譽｜流失潛在回頭客

- 滿意的顧客向 **5–6 人**介紹；不滿的顧客向最少 **9 人**描述，並繼續傳播
- 服務補救計劃可包括：額外服務（補償饋贈）、減價、任何能挽留顧客的方法；容易見效、物有所值

### ==服務接觸==

某一方（侍應、接線生、旅行社）向另一方（顧客）提供服務或商品的互動過程。三個要素：

| 要素 | 例子 |
|---|---|
| ==服務目標== | 安全地送交行李 → 愉快旅遊體驗 |
| ==服務的提供==（服務系統） | 航班按時抵達 → 顧客滿意 |
| ==服務標準== | 旅行社確認機票的最短時間 → 讓員工及顧客了解期望 |

忽略任何一方面都會影響服務品質及服務接觸。

### 補救措施

- 先準確分析問題本質：產品、服務、質料、員工、系統或流程？
- 搜集資料：衡量各方面表現｜追蹤缺失特點｜追查地點／時間／人員｜留意質料設備人員變化
- 培訓員工處理憤怒顧客；**主動提供方便投訴的渠道**（機場專門櫃檯、客務關係主任、意見咭）：「如果你對我們滿意，請告訴你的朋友；如果不滿意，請告訴我們」
- 問題有時來自顧客 → 系統須有靈活性；員工須有固定程序、清楚權力範圍及何時尋求支援

!!! score "拿分要訣"
    服務補救題要針對失誤**即時、具體**地補救：道歉 → 解釋 → 盡快重新提供合乎標準的服務（如兩分鐘內送上重新烹製的熱菜，而非翻熱）→ 適當補償 → **跟進**了解滿意程度。2025 考評報告指出考生較能回應服務補救題，但不少只**複述資料**，未能篩選資料並結合例證說明。
