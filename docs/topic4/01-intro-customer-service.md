## 1.1 顧客服務的性質

- ==顧客服務==：一系列旨在增加顧客滿意程度的活動，即顧客感到產品或服務符合其期望

### 顧客服務性質的五個範疇

| 範疇 | 要點 |
|---|---|
| ==綜合性== | 旅遊前（諮詢、預訂）及旅途中（交通、餐飲、住宿、娛樂觀光）的綜合服務 |
| ==直接性== | 通過直接、及時、隨時的服務提供給客人（旅行社、服務員、導遊） |
| ==情緒性== | 遊客除物質需求外，還有精神需求（認同、受尊重），更重視服務態度和質素 |
| ==時間性== | 「==關鍵時刻==」：顧客與員工交流的影響，留下良好印象或令其不滿 |
| ==應變性== | 不同顧客對滿意度理解差異很大，員工須隨時準備滿足不同需要 |

### 實物商品與服務的主要分別

| 實物商品 | 服務 | 對提供顧客服務的意義 |
|---|---|---|
| 有形 | ==無形== | 購買前難有概念或以五官感知 |
| 生產與使用分開 | ==生產與使用同時進行== | 服務提供者、顧客本身及在場其他顧客都成為服務體驗的一部分 |
| 標準化 | ==多變性== | 質素因提供者、地點、時間而改變（缺乏一致性） |
| 可保存 | ==不可保存== | 不能作為存貨供未來銷售 |

- 旅遊及款待設施**同時具有有形及無形的服務**（例：麥當勞的漢堡是有形，快捷服務及環境是無形）；有形程度由糖、飲品（有形為主）至教學、銀行（無形為主）

## 1.2 顧客服務的重要性

- 以顧客服務為中心的公司，價格可較對手高 **9%**，增長速度是一般公司**兩倍**
- 尋找新顧客的時間是保存現有顧客的**五倍**
- 惡劣體驗的顧客會告知最少 **9 人**（13% 告知超過 20 人）；極滿意的顧客只告知 3 至 4 人
- 選擇多、競爭大 → 須具備「==競爭優勢==」，最佳途徑是提供最高水準服務
- 機構內每個人都在：**直接幫助顧客**或**協助他人直接幫助顧客**

## 1.3 Parasuraman 的五個顧客服務特點：==RATER==

| 特點 | 意思 | 例子 |
|---|---|---|
| ==可靠性==（Reliability） | 每次可靠而準確地提供**承諾**的服務；**最重要** | 及時提供服務；遵守明確及隱性承諾 |
| ==可信性==（Assurance） | 員工的知識及禮貌，贏取顧客信任與信心的能力；**其次重要** | 員工經驗、專業水平、熟悉產品 |
| ==有形性==（Tangibles） | 有形設施、設備、員工外表、顧客行為與環境氣氛須與服務種類相符 | 傳統大堂放摩登傢俬顯得格格不入；寧靜咖啡店內喧嘩的顧客 |
| ==關懷性==（Empathy） | 公司對顧客的關心、理解及個人化服務 | 認得常客；為丟失行李的顧客迅速解決問題 |
| ==反應性==（Responsiveness） | 願意提供及時和高效率服務；速度、效率、禮貌 | 電視壞了不應等數日修理 |

- 其他可用詞彙：可信性 ＝ 確實性、保證性；有形性 ＝ 實體性；關懷性 ＝ 同理心；反應性 ＝ 反應能力、回應性

| 產品／服務 | 隱性承諾（顧客推斷） | 明確承諾（供應商保證） |
|---|---|---|
| 一瓶葡萄酒 | 可飲用、正確地呈上 | 符合酒牌描述（產地、年份、價格） |
| 薄餅速遞 | 按準確訂單送達 | 30 分鐘內送到，否則折扣 10 元 |
| 酒店客房 | 最少一張床 | 符合宣傳冊或網頁描述 |

## 1.4 旅遊及款待服務員工的個人特質

| 特質（香港旅遊發展局） | 要點 |
|---|---|
| ==儀表== | 大方得體，和藹可親的笑容；頭髮衣飾整齊 |
| ==品格== | 喜歡與人接觸、成熟開朗、幽默、樂於助人、有耐性、誠懇有禮 |
| ==學歷及技能== | 專業訓練；流利英語；了解本港時事及中國文化；其他外語 |
| ==其他== | 體格健全、思考敏捷、有決斷力、適應力強、願意長時間及不定時工作、忠誠可靠 |

**重要性**：服務的提供與消費**同時進行** → 前線員工的行為和態度直接影響消費體驗；儀表是優質服務的表徵；個人素質有助建立良好客戶關係 → 優質服務很大程度上取決於員工的個人特質
