## 2.1 甚麼是景點？

- ==景點==：任何能吸引旅客前往該地的資源、設施或活動
- 較廣泛定義：一個地區特色（地方、場地或焦點活動），設立目的是吸納旅客並作相應管理；提供有趣愉快的體驗；開發以體現潛力；管理以令客人滿意；提供適當設施及服務；會或不會收取入場費

### 旅遊景點與目的地（Swarbrooke）

| ==旅遊景點== | ==目的地== |
|---|---|
| 有**單一主要特色**的個體、獨立地點或細小易劃分的地理區域 | 包含**多個景點**並設有旅客所需**支援服務**的較大區域 |

- 受歡迎景點會發展成目的地，酒店、餐廳、商店集中在附近（例：奧蘭多—迪士尼世界；盧克索—金字塔；北京—萬里長城）
- 發展階段：1 單一景點 → 2 目的地形成初期（增加服務）→ 3 已發展但只有單一市場（新增景點迎合同一市場）→ 4 ==多元化目的地==（設新景點吸引新市場）
- 景點組合對旅客吸引力更大，**延長目的地的產品生命週期**；須注意==可達度==及運輸設施

## 2.2 景點的作用與特性

### 景點在旅遊業的作用

| 範疇 | 作用 | 例子 |
|---|---|---|
| **目的地** | 演變成目的地的主要元素；擔當目的地地標 | — |
| **運輸** | 促使新公共交通服務發展；交通工具本身可成為景點 | 港鐵迪士尼支線；天星小輪 |
| **旅遊營運** | 旅遊經營商把景點包裝成旅行套餐；主題景點帶來特殊興趣旅遊產品 | 葡萄園品酒之旅、劇院旅行團 |

### 景點的五個特性

| 特性 | 意思 |
|---|---|
| ==高品質== | 整潔美觀、以客戶為中心的運作、資源保護、友善款待 |
| ==真實性== | 提供真實畫面，營造「==地方感==」，反映社區的自然、文化和經濟遺產 |
| ==獨特性== | 景點的「優勢」，有別於 150–300 英里市場範圍內的競爭者 |
| ==吸引性== | 以旅客從特定距離到訪的數量及會否重複到訪計算 |
| ==活動選擇== | 提供多樣化、不斷推陳出新的活動 |

## 2.3 景點的類型

### Swarbrooke 的四種主要類型

| 類型 | 例子 |
|---|---|
| ==自然環境== | 氣候、自然現象、風景 |
| ==「人工」但非為吸引旅客而建== | 教堂、歷史建築 |
| ==「人工」並為吸引旅客而建== | 主題公園 |
| ==特別活動== | **唯一短暫性**、壽命有限的類型 |

### Goeldner、Ritchie 及 McIntosh 的五種主要類型

| 類型 | 細分及例子 |
|---|---|
| ==文化景點== | **歷史景點**（萬里長城、兵馬俑、故宮、金字塔、羅浮宮）｜**文化與風俗**：傳統、藝術、手工藝品（紀念、向親友展示異國風情提升優越感）、食品、音樂與舞蹈、生活方式｜**宗教神聖事物風貌**（麥加、羅馬） |
| ==自然景點== | **氣候**（逃避不快氣候；或尋找極端氣候，如渥太華 Winterlude）｜**地形**：山地、海岸線、湖泊瀑布、火山溫泉、溶洞｜**動植物**（亞馬遜生態旅遊、東非草原觀賞動物、米埔觀鳥） |
| ==活動項目== | 按規模：**盛事活動／大型活動**（奧運、世界盃）、**社區活動**（社區擁有、使用志願服務及公共場所）｜按內容：**運動項目**、**商貿項目**（會議展覽、慕尼黑啤酒節）、**藝術和文化項目**（康城電影節、長洲太平清醮） |
| ==消閒康樂== | 日光浴、滑雪（過去 30 年增長最快）、打獵及釣魚（須牌照） |
| ==娛樂演出== | 主題公園及遊樂場、賭場（拉斯維加斯、澳門）、購物設施、夜總會、動物園（娛樂、教育、保護野生動物）、水族館、科學館 |

**旅客被文化景點吸引的原因**：與自身文化背景相同（尋根）｜欣賞藝術品及建築｜歷史或文化意義（如武昌起義之地）｜觀察他鄉人士的生活

**旅客被自然景點吸引的原因**：欣賞自然奇趣｜利用自然地形或資源進行活動｜探訪鄉村抒發城市壓力｜在自然棲息地觀看野生動物｜欣賞美景

### 按等級：首選與次選景點

| ==首選景點== | ==次選景點== |
|---|---|
| 休閒旅遊的主要理由；花最多時間；往往入場費較高（海灘、主題公園） | 往返首選景點途中到訪；打斷漫長旅程、用膳、增添新意；可安撫團體中不想去首選景點的成員 |

- 每個旅客的首選及次選景點因喜好、態度及興趣而不同

### 按擁有權、收入和利潤取向

| 類別 | 例子 |
|---|---|
| ==牟利企業== | 家庭式經營主題公園 |
| ==帶收入的非牟利企業== | 政府機構（上加拿大村）；非牟利組織（華人廟宇委員會）；宗教團體（黃大仙祠）；慈善信託基金（海洋公園保育基金）；香港海洋公園由法定機構經營，非牟利但期望有盈餘 |
| ==不帶收入的企業== | 山頂觀景台 |

## 2.4 旅遊業各方面的資源與目的地形象

- ==目的地形象==：個人或團體對特定地方的認知、印象、偏見和感想；是**主觀**看法；形象越正面，到訪可能越大

| 影響目的地形象的九類因素 | 例子 |
|---|---|
| 自然資源 | 天氣、海灘、野外資源、動植物 |
| 一般基礎設施 | 公路、機場、港口、衛生服務、電子通訊 |
| 旅遊基礎設施 | 住宿、餐廳、酒吧、易達度、遊客中心 |
| 遊客消閒及康樂 | 主題公園、體育活動、賭場、夜生活、購物 |
| 文化、歷史和藝術 | 博物館、節日、手工藝、美食、宗教 |
| 政治和經濟因素 | 政治穩定性、經濟發展、安全（犯罪率、恐襲）、價格 |
| 自然生態環境 | 美麗景色、衛生、過度擁擠、污染、交通擠塞 |
| 社會環境 | 居民熱情友善、生活質素、語言障礙 |
| 地方氣氛 | 豪華、時髦、家庭為主、異國情懷、放鬆 |

- 與==拉動因素==相似，都影響旅客的認知、體驗及旅遊意向
