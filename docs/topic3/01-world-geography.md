## 1.1 半球、大陸和海洋

### 半球

- ==北半球==／==南半球==：以==赤道==劃分
- ==西半球==：==本初子午線==（穿過倫敦格林威治）以西，包括美洲和格陵蘭
- ==東半球==：本初子午線以東至西經 180 度，包括歐洲、非洲、中東、亞洲、澳大利西亞和大洋洲

### 七大洲

| 大洲 | 旅遊要點 |
|---|---|
| ==北美洲==（加拿大、美國、墨西哥） | 遊客佔全球 9.7%，收益 16.9%；美國城市（紐約、拉斯維加斯）及國家公園（大峽谷、優勝美地、黃石）；加拿大原始天然地域；墨西哥阿茲特克及瑪雅文化遺址、坎昆海濱；北美國家間**駕車**周遊為主 |

## 1.2 名勝的氣候帶及季節性

- ==氣候==：特定地域內氣溫、濕度、降雨量等的**長期現象**；受緯度、地形、冰雪覆蓋、鄰近海洋及洋流影響

| 氣候帶 | 例子 | 特點 |
|---|---|---|
| 炎熱—赤道 | 新加坡 | 長年潮濕，全年大致恆溫（約 27°C） |
| 炎熱—熱帶 | 澳洲北部沿海 | 雨季短暫，大致溫暖乾燥 |
| 炎熱—荒漠 | 撒哈拉 | 降雨極少；日夜溫差極大 |
| 溫和—暖溫帶／地中海 | 羅馬 | 四季分明；冬約 7°C、夏約 25°C |
| 溫和—涼溫帶 | 愛丁堡 | 四季分明；夏約 14.5°C |
| 寒冷 | 芬蘭 | 冬季漫長，夏季短暫 |
| 北極／極地 | 南極內陸 | 冬天幾乎黑夜，夏天白晝 |

### 季節性

- 人們會避開不理想的天氣：美國北部及加拿大人冬季到佛羅里達；北歐人到西班牙、希臘、馬爾代夫過冬

| 目的地 | 最佳月份 | 避免 | 原因 |
|---|---|---|---|
| 加勒比海 | 1–4 月 | 7 月至 12 月初 | ==颶風季節== |
| 澳洲悉尼 | 9–11 月 | 12–2 月 | 最熱，2 月雨水最多 |
| 日本札幌 | 12–3 月 | 2 月 | 降雪高峰期 |
| 肯尼亞 | 1–3 月 | 4–6 月及 10–12 月 | 雨季及洪水 |

- ==氣候變化==：低海拔滑雪度假村因降雪不足關閉；海平面上升淹沒南太平洋及印度洋低窪島嶼

## 1.3 時間及時區

| 概念 | 要點 |
|---|---|
| ==本初子午線== | 1884 年國際子午線會議訂立；穿越倫敦**格林威治**天文台；經度 0 度，東西各計 180 度 |
| ==格林威治時間==（GMT） | 以本初子午線為標準時區 |
| ==協調世界時==（UTC） | **1986 年取代 GMT** 成為世界標準時間；採用**原子時**，不以地球自轉量度；又稱祖魯時；仍以格林威治為標準時區 |
| ==國際日期變更線== | 連接南北兩極的假想線，距本初子午線 **180 度**；會作調整以免穿越國家 |
| ==時區== | 共 24 個；中央時區東西各 12 個；相鄰時區多相差一小時；**以東比 GMT 快，以西比 GMT 慢** |
| ==飛行時差== | 乘飛機穿越若干時區後感到疲憊 |

!!! note "時差計算"
    兩地時差 = 兩地 UTC 差值。例：香港 UTC+8、法國 UTC+1 → 香港快 7 小時；香港中午 12 時 = 巴黎上午 5 時。

## 1.4 經緯度

| | ==緯線== | ==經線==（子午線） |
|---|---|---|
| 方向 | 與赤道**平行**，間距相等 | 連接兩極，**不平行**，在赤道最寬 |
| 量度 | 赤道以北／以南的距離 | 本初子午線以東／以西的距離 |
| 範圍 | 0°（赤道）至 90°（兩極）；N／S | 0° 至 180°；E／W |

- 先說緯度、後說經度；1 度 = 60 分（′），1 分 = 60 秒（″）
- 例：香港 22°20′N 114°11′E；格拉斯哥 55°52′N 4°15′W；內羅畢 1°25′S 36°55′E
