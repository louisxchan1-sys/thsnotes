## 4.1 主題公園的基本概念

**與其他娛樂景點不同的特色**

1. 只需支付**一次入場費**便能任玩（遊樂場多按每次活動收費）
2. 設施大多是**人工製造**
3. **高昂的資本投資額**
4. 結合娛樂（表演、機動遊戲、互動活動）、餐飲、商店為一體

**定義**：國際遊樂園和景點協會——具有主題景點的遊樂場；弗萊克——一個**逃避的地方**，擺脫日常生活負擔；學術界——龐大資本投資、高度開發、遊客為本、人工化的娛樂環境，園內環境與門外真實環境截然不同。共同特色：以主題提供與日常生活不同的有趣體驗。

### 主題公園的七種類型

| 類型 | 特色 |
|---|---|
| ==冒險== | 興奮刺激、驚慄、神秘、刺激機動遊戲 |
| ==未來世界== | 科技發展、探索、機械人、科幻 |
| ==國際== | 各國特色、地球村、微型複製品、世界博覽 |
| ==大自然== | 動物、花卉園藝、海洋生物、野生生物 |
| ==幻想世界== | 動畫、卡通人物、童話、魔術、神話 |
| ==歷史與文化== | 土著、文化遺產、文化村落、淘金熱 |
| ==電影== | 西部牛仔表演、喜劇、特技表演 |

- 主題在規劃階段已選定，是設計、發展及運作的焦點；現時大多數主題公園提供**多種主題**（如海洋公園：大自然、野生動物、海洋生物）

## 4.2 主題公園的特質：==產品三層次==（Kotler、Swarbrooke）

| 層次 | 意思 | 例子 |
|---|---|---|
| 第一層 ==核心產品== | 遊客實質購買的**無形**特質 | 興奮刺激、氣氛、有趣、物有所值、親朋歡聚 |
| 第二層 ==支援（實際／有形）產品== | 把核心產品的無形特質**轉變為有形產品**，並為核心產品增值、與競爭對手區分 | 機動遊戲、表演節目、餐飲設施、紀念品店；整潔舒適安全的環境（方便位置的洗手間、易懂指示標誌、有蓋行人道及排隊區、冷暖風機）；訓練有素的團隊；環保設計 |
| 第三層 ==促成（延伸）產品== | 不是實際購買的核心產品，但是使用核心產品時**必須有的服務和設施**，提高滿意度 | 穿梭巴士、無障礙設施、貯物櫃、停車場；特別開放時間（提早入場分流，紓緩承載力）；天氣狀況；選址恰當 |

| 景點 | 核心產品 | 有形產品 | 延伸產品 |
|---|---|---|---|
| 香港迪士尼樂園 | 家庭娛樂、刺激、幻想、再現青春 | 機動遊戲、穿戲服的演員、餐飲、零售 | 兒童手推車、殘疾人士服務、多語告示牌、年票、快速通行計劃 |
| 山頂瞭望台 | 天際線景色、休閒、家庭出遊 | 觀景台、餐飲、杜莎夫人蠟像館 | 望遠鏡、多語告示牌、摩天套票 |
| 世界地質公園 | 荒野體驗、了解地質 | 地質旅遊團、舢舨觀光 | 多語告示牌、導遊及自助步道、指南 |

- **有形及延伸產品必須配合核心產品**，否則景點定必失敗；了解不同核心需要才可找到獨有定位

!!! score "拿分要訣"
    分析景點的產品三層次時，先寫出核心產品（遊客追求的無形體驗），再說明有形產品如何把它實現，延伸產品如何支援，並指出三者是否配合。

## 4.3 有助主題公園成功的因素

### 整體吸引力及遊客體驗

| 因素 | 要點 |
|---|---|
| ==獨特而有趣的主題== | 創新（虛擬、擴增、混合實境）｜投入（視覺、聲音、觸覺加深體驗）｜互動｜啟發（教育與娛樂） |
| ==物有所值／不同種類的活動== | 興奮新奇體驗；巡遊、煙花、節慶活動吸引重遊；良好服務設施；安全環境；餐飲是整體體驗及收入的重要部分 |
| ==整潔和舒適的環境== | 首要條件（香港迪士尼有蓋地方較其他迪士尼多，因亞熱帶多雨） |
| ==擁有積極及訓練有素的團隊== | 服務生產過程中員工與遊客**不可分割**；熱誠、「發自內心」的服務 |
| ==選址恰當== | 位於四通八達的熱門目的地，受惠入境市場及短途不過夜遊客；**解決旅遊產品不可保存的特色** |
| ==服務和設施的質素及其一致性== | 預先規劃人潮及物品流動；應急方案；為傷健遊客提供設施 |

### 適應市場轉變

| 趨勢 | 要點 |
|---|---|
| ==年長客群== | 可支配收入及閒暇時間多；要求低耗量活動：室內表演、專用通道、美食、水療、園林景色、輕鬆機動遊戲、休息地方 |
| ==整體環保設計== | 環保建築及綠色認證；環保車輛；處理廢物污水；可再生能源（Six Flags 新澤西全太陽能發電） |
| ==教育與娛樂== | 海洋公園熱帶激流 + 生物多樣性教育；學生工作坊 |
| ==互動體驗== | 餵飼動物、與吉祥物拍照；5D 電影；哈利波特互動魔杖；==虛擬實境==（穿戴裝置置身另一處境）、==擴增實境==（數碼內容疊置於現實世界）、==混合實境== |

### 管理

| 因素 | 要點 |
|---|---|
| ==積極的管理層== | 比對手更快回應政治、環境、社會、技術變革（海洋公園以教育及保育為策略骨幹；迪士尼引入最強品牌） |
| ==大量財務資源和持續投資== | 定期建新景點、提升或更換設施，否則遊客覺得毫無新意 |
| ==強大的市場推廣團隊== | 識別潛在市場群組（1 日、2 日、全年入場證）；規劃長遠市場策略 |
| ==監測管理== | 保養及安全；安全計劃大綱：清除危險、遵守安全程序、符合法例（機電、消防、建築、運輸）、醫療服務、保安、惡劣天氣程序；《職業安全及健康條例》保障僱員；《公眾衞生及市政條例》保障遊客 |
