## 6.1 食物污染的種類

- ==食物中毒==：進食受污染食物或飲品引致的**急性疾病**；潛伏期數小時至數日；症狀如肚痛、嘔吐、腹瀉，對嬰兒、孕婦、長者及病患者影響較嚴重；分細菌性及非細菌性
- ==食物污染==：任何**並非故意**加入食物內的有害物質（天然、環境污染或加工過程產生）

### 一、==生物性污染==（細菌、病毒、寄生物）

| 細菌 | 源頭／受污染食物 | 特性 |
|---|---|---|
| ==沙門氏菌== | 生的肉類、未煮熟的蛋 | 不能形成孢子；70°C 死亡 |
| ==金黃葡萄球菌== | 人的皮膚、毛髮、鼻腔、咽喉、傷口 | 毒素可抵抗高溫 |
| ==副溶血性弧菌== | **海產、介貝類** | 高溫煮 10 分鐘死亡 |
| ==李斯特菌== | 軟芝士、蔬菜、即食肉類、沙律 | 可在 **0°C 低溫生長**；70°C 死亡；可致孕婦流產 |
| ==臘樣芽孢桿菌== | 剩飯、炒飯、肉類製品 | 可形成孢子抵受高溫 |
| 肉毒梭狀芽孢桿菌 | — | 視線不清、言語困難、麻痺 |

- **經食物傳播的疾病**：甲型肝炎、霍亂、桿菌性痢疾、傷寒與副傷寒（多經受糞便污染的食物、食水、介貝類）
- **常見原因**：配製（來源不安全、未徹底煮熟、未徹底解凍、過早配製、翻熱不足）｜貯存（熟食遭污染、長時間存放在 **4°C 至 60°C**）｜從業員（不注重個人衞生、患腸道傳染病）及進食生食
- **預防三原則**：避免食物受污染｜防止細菌繁殖｜消滅食物中的細菌
- **病毒**：很少數目便可致病（10–100 個粒子）；例：==諾如病毒==（非細菌性腸胃炎主要致病原；經食物、人與人接觸、氣霧化嘔吐物傳播）、甲型肝炎病毒；患者痊癒後至少兩日才可處理食物
- **寄生物**：原蟲及蠕蟲（吸蟲、蛔蟲），見於肉類、海產、生的農作物

### 二、==化學性污染==

| 類別 | 例子 |
|---|---|
| 食物添加劑 | ==二氧化硫==（防腐劑，或令肉類異常鮮紅，可致氣喘）；人造染色料（==蘇丹紅==，見於瓜子、臘腸、辣椒製品） |
| 殘餘農藥、獸藥 | 蔬菜須清水洗淨及浸泡；==孔雀石綠==（養殖水產）；人造激素 |
| 化學清潔劑 | 清潔劑、消毒劑殘留 |
| 容器材料 | 塑膠容器釋出化學物；即棄餐盤墊紙 |
| 生化毒素 | 藻類毒素（雪卡毒素等，非常耐熱、無解毒劑）；細菌毒素：==組胺==（魚類貯存溫度不當產生，致鯖魚中毒；冰鮮魚貯存 4°C 或以下，冷藏魚 −18°C 或以下） |
| 其他天然毒素 | ==河豚毒素==（耐熱）；植物性毒素（發芽馬鈴薯、北杏、竹筍；可浸泡、切小塊、徹底煮熟消除） |

### 三、==物理性污染==

非化學性雜物（利器、竹籤、玻璃碎片、毛髮、釘書釘、油漆碎）；可傷害顧客及嚴重影響感官和印象。

- **污染途徑**：活動媒體（手、設備、衣服）；固定媒體（與食物及雙手接觸的表面）

!!! trap "易錯"
    - 清潔劑屬**化學性**污染，不是物理性
    - 高溫可消滅細菌，但**不能**去除雪卡毒素、貝類毒素、組胺等耐熱毒素
    - 覆蓋傷口最好用**非肉色**膠布，脫落時易察覺

## 6.2 食物安全

- ==食物安全==：食物中沒有存在任何造成危害的東西
- ==食物衞生==：保持設備、工作場地清潔及員工個人衞生；遵守防止污染、減低細菌繁殖、徹底消滅細菌的守則

| | 良好食物衞生的效益 | 惡劣食物衞生的代價 |
|---|---|---|
| 規例 | 符合法例及持牌條件；減少食物中毒 | 違法及受檢控；罰款；民事訴訟 |
| 業務 | 商譽提高；生產力提高 | 喪失商譽；生產力減低；或會倒閉 |
| 員工 | 士氣提高；流失率減少 | 損失工作天；流失率增加；失業 |
| 食物 | 延長保貯期；保障質素 | 浪費食物 |

## 6.3 食物安全的處理程序

### ==細菌的生長條件==

| 條件 | 要點 |
|---|---|
| **食物** | 水份及蛋白質豐富的==高風險食物==（禽畜肉類、介貝類海產、奶類製品） |
| **水** | 乾的食物中細菌休息；少量水份即回復活潑 |
| **溫度** | ==危險溫度範圍：4°C 至 60°C==；最適合約 37°C（人體溫度） |
| **時間** | 一般 10 至 20 分鐘增加一倍；1,000 個細菌在 1 小時 40 分鐘內達 1,000,000 個 |

- 本港食物中毒約 7–8 成是細菌性；**溫度控制不當**是常見原因
- 食物不應放在危險溫度區**超過 2 小時**

### 溫度控制

| 情況 | 溫度 |
|---|---|
| 冷凍（短期貯存：冰鮮、速涼） | **4°C 或以下**（減緩繁殖，不能殺菌） |
| 奶類或奶類飲品 | 10°C 以下 |
| 冷藏（長期貯存：急凍） | **−18°C 或以下**（雪糕 −23°C 或以下） |
| 熱存 | **60°C 或以上** |
| 烹煮生肉中心溫度 | **75°C 至少 15 秒**（或 65°C 10 分鐘、70°C 2 分鐘） |
| 翻熱 | **75°C 或以上**，不超過 2 小時；不可再冷卻及重新翻熱 |
| 解凍 | 雪櫃或解凍櫃 **8°C 或以下**；流動凍自來水；微波爐（解凍後立即烹煮）；**切勿**室溫解凍或重複解凍冷藏 |

### 食物溫度計

| 溫度計 | 用途 |
|---|---|
| 雙金屬棒狀溫度計 | 量度厚身食物中心溫度；20 秒至 2 分鐘 |
| 熱電偶／熱敏電阻溫度計（數字食物溫度計） | 10 秒內有結果 |
| 紅外線溫度計 | 只量度**表面**溫度，無須接觸 |
| 玻璃溫度計 | 內有水銀或酒精，**不宜**量度食物 |

- 校準：每年至少一次由製造商校準；每三個月自行檢查——**冰點法**（應為 0°C）或**沸點法**（應為 100°C），誤差超過 1°C 須調校
- 使用：先清洗消毒（探頭放入 77°C 以上熱水 6 秒或用酒精抹淨）；插入食物中心或最厚部分；不觸及容器；等 10 秒讀數並記錄

### ==食物安全五要點==（世界衞生組織）

1. ==精明選擇==：選擇安全的原材料
2. ==保持清潔==：保持雙手及用具清潔
3. ==生熟分開==：分開生熟食物
4. ==煮熟食物==：徹底煮熟食物
5. ==安全溫度==：把食物存放於 **4°C 或以下，或 60°C 或以上**

- 食物安全中心「==食物處理工序流程圖==」把五要點應用於每個步驟：選購 → 收貨 → 貯存 → 解凍／配製／處理 → 烹煮 → 熱存 → 冷卻 → 冷存 → 翻熱 → 端送／運送 → 陳列

### 安全的食物處理操守

| 工序 | 要點 |
|---|---|
| **選購** | 認可可靠及持牌供應商；訂購適量；要求單據或衞生證明書 |
| **收貨** | 檢查保質期、包裝、狀況、冷藏溫度；不合格貨品分隔；小心開包；盡快貯存；燒味、家禽、肉類等記錄保留至少 60 天 |
| **貯存** | 清潔、蓋好、適當溫度濕度；**離地面 300 毫米或以上**；不用報紙或有色膠袋包裹；生熟分開；==先入先出==；標籤收貨日期及食用期限 |
| **配製** | 限食物處理人員進入；避免用手接觸即食食物；戴即棄手套及口罩；以**不同顏色**用具區分生熟；試味用具每次清潔消毒 |
| **處理** | 蔬果用可飲用水徹底清洗；燒味區遠離魚缸及劏洗區；魚生在指定區域處理；避免過早處理；化學品與食物區分開 |
| **冷卻** | 分小份、用淺而傳熱快的容器、切小塊、留空間讓冷氣流通、放凍水或冰盤 |
| **端送** | 經常洗手；不用手拿冰粒；手指不碰杯碟邊緣；握餐具柄；不用口吹碎屑；有裂紋的碟丟掉；顧客剩餘食物不得再給他人 |
| **陳列／自助餐** | 冷食 4°C 或以下、熱食 60°C 或以上；食物護罩（防噴嚏護罩）；生熟分開並各有調配用具；小量展示、整盤更換 |
| **運送** | 有蓋容器或密封車輛；食物與非食物分隔；冷凍車輛運送高危食物 |
| **棄置** | 不安全食物退回或標記隔離，盡速棄置 |

!!! score "拿分要訣"
    DBQ 食物安全事故題：先**辨識**違反了五要點中哪一項（引資料行為），再以**細菌生長條件**或溫度數字解釋風險，最後提出對應的處理操守作改善。

## 6.4 飲食從業員的個人衞生

| 範疇 | 要點 |
|---|---|
| **儀容** | 不宜留長頭髮；不留長指甲、不塗指甲油；不戴飾物；避免濃妝及濃烈香水 |
| **個人習慣** | 配製區內不可存放私人物品、吸煙、吐痰、在食物上咳嗽打噴嚏、坐卧在接觸食物的表面、用手指試味、觸摸頭髮鼻眼；**不得同時處理現金和食物**；打噴嚏時轉身背離食物、遮掩口鼻、立即洗手 |
| **健康狀況** | 有腹瀉、嘔吐、咽喉痛須報告並停止處理食物；被衞生主任勒令停工者須獲書面批准才可復工 |
| **損傷** | 傷口戴防水手套或用非肉色膠布；不能妥為覆蓋的流血流膿傷口須停工 |
| **健康管理** | 新入職健康檢查及問卷；在職員工患傳染性肝炎、腹瀉、嘔吐、發燒、喉嚨發炎、皮膚傷患、耳眼鼻有排出物須報告停工；腸道傳染病須醫生證明康復或病徵停止 48 小時 |
| **工作服** | 淺色、清潔；避免有鈕扣；戴工作帽或髮網；即棄手套；口罩；密頭鞋 |

### 必須洗手的時候

開始工作前｜處理食物前｜如廁後｜處理未煮食物後｜處理弄污設備後｜咳嗽、打噴嚏、吸煙、飲食後｜處理動物或廢物後｜觸摸身體部位後｜處理金錢或清潔後

### 洗手步驟

1. 用水（最好溫水）弄濕雙手
2. 塗上梘液
3. 雙手互相搓擦 **20 秒**（前臂、手腕、手掌、手背、手指、指甲縫）
4. 徹底沖洗
5. 用抹手紙、卷軸式抹手布或乾手機弄乾
6. 以抹手紙包裹水龍頭關掉
