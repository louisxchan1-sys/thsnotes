| 非商業 | 商業 |
|---|---|
| 私人（私人住宅）、非牟利（收容中心）、機構（大學） | 酒店、服務式住宅 |

## 2.2 酒店及其分類方法

- **《酒店東主條例》（第 158 章）**：酒店指任何場所，其東主顯示該場所是向到臨的任何人提供住宿的地方，而該人看似有能力並願意繳付合理款項，且在宜於接待的狀況
- 具體而言：提供**住宿、餐飲及其他顧客服務**的商業機構
- 2023 年全港 321 間酒店，超過九萬間房間

**酒店分類因素**：==功能==（會議）｜==位置==（市中心、鄉郊）｜==價格==（廉價、豪華）｜==市場定位==（休閒旅客）｜==職員與客房數目比例==｜==酒店規模==（客房數量）｜==設計==｜==評級==｜==物業特性==（全套房酒店）

- 分類能突顯酒店特色，讓遊客訂房前比較（例：富豪機場酒店位於機場附近，服務過境旅客、商務旅客及機組人員，五星級，超過 1,100 間客房）

## 2.3 住宿類型

| 類型 | 特點 |
|---|---|
| ==市中心酒店== | 位於市中心；性質可屬商務、套房、住宅式、實惠或豪華 |
| ==近郊酒店== | 面積較小，通常提供全面服務 |
| ==機場酒店== | 為航機乘客而設；多提供往返機場交通 |
| ==公路酒店或汽車旅館== | 為駕車旅客提供隔夜停留；最基本設施；房間直通露天停車場；位於市鎮外圍 |
| ==會議酒店== | 大量房間及大量會議活動空間；宴會場地；自設洗衣、商務中心、機場穿梭車、24 小時客房餐飲；鄰近會議中心 |
| ==商務酒店== | 多位於鬧市；較會議酒店小，會議及宴會空間較少 |
| ==度假酒店== | 風景如畫但較偏遠；顧客停留較長；全面優質康樂設施及多種餐飲設施 |
| ==水療酒店== | 提供水療服務、療程、飲食及住宿；員工包括營養師、治療師、按摩師，甚至醫生 |
| ==賭場酒店== | 以博彩為主要收入來源；即時娛樂、豪華設施、購物 |
| ==全套房酒店== | 客房較大，分工作、就寢及鬆弛範圍；起居室獨立於臥室，或設廚房 |
| ==精品酒店== | 個性化住宿及服務，亦稱「設計酒店」「生活品味酒店」；更親密、突出獨有個性；設施視乎主題（或不設 Wi-Fi） |
| ==分時度假或假期擁有權== | 分享擁有權：買家購買物業每年某時段的使用權，可由後人繼承 |
| ==舊式建築改建酒店== | 具歷史意義的建築改建，保留歷史特色 |
| ==長期住宅式酒店／酒店式服務住宅== | 適合長住；齊備廚房、購物及商業服務、有限管家服務 |
| ==民宿旅館== | 家族擁有的私人居所，東主住在旅館或附近；包早餐；提供當地資訊；多位於郊外 |
| ==賓館== | 似大城市中的小酒店；設施有限但多有空調及獨立浴室 |
| ==旅舍== | 非常廉價；宿舍形式，或有自助煮食 |
| ==客艙== | 船隻或火車上的臥室 |
| ==別墅或度假屋== | 私人平房，自助煮食，多設於滑雪及海灘度假村 |

**世界各地的特色酒店**：==膠囊酒店==（日本；約 2 × 1 × 1.25 米，為不能歸家需廉價住宿者而設；共用洗手間）｜==冰酒店==（瑞典首創；臨時建築，每季重建）｜==洞穴酒店==（土耳其；深入體驗文化、環保）｜==樹屋酒店==（森林中，體驗在於觀光活動）｜==水底酒店==（美國佛羅里達，須持潛水牌照）

!!! trap "易錯"
    2025、2026 考評報告指出考生對**住宿類型**的發展掌握不足；2025 MC 有 40% 考生未能判斷酒店位置是否在主要景點步行距離內。辨識住宿類型時，要抓住**位置、目標客群、主要設施**三方面的特徵。

## 2.4 酒店評級系統

| 類別 | 設立者 | 例子 |
|---|---|---|
| ==官方評級系統== | 政府部門 | 香港旅遊發展局酒店分類制度 |
| ==商業評級系統== | 協會或私人企業 | 福布斯旅遊指南（前美孚旅遊指南）==星級==；美國汽車協會==鑽石級== |

### ==香港旅遊發展局酒店分類制度==

| 指標 | 比重 | 評分 |
|---|---|---|
| 設施 | 0.25 | 飲食、電訊、商務、康樂及其他設施數目 |
| 地點 | 0.20 | 尖沙咀、中環、金鐘、銅鑼灣、國際主題公園 5 分 → 其他新界及離島 1 分 |
| 職員與客房的比例 | 0.20 | ≥0.60：3 分；0.40–0.60：2 分；<0.40：1 分 |
| 實際房租 | 0.20 | ≥1,480：3 分；900–1,480：2 分；<900：1 分 |
| 商務組合 | 0.15 | 商務旅客 ≥16%：2 分；<16%：1 分 |

**綜合分數** = 設施 × 0.25 + 地點 × 0.20 + 職員與客房比例 × 0.20 + 實際房租 × 0.20 + 商務組合 × 0.15

| 酒店類別 | 綜合分數 |
|---|---|
| ==甲級高價酒店== | 3.00–3.99 |
| ==乙級高價酒店== | 2.00–2.99 |
| ==中價酒店== | 1.00–1.99 |
| ==旅客賓館== | 不適用（按民政事務總署名單分類） |

- 旅發局**只通知個別酒店**其級別，**不公開**分數或類別名單（私人評級系統則公開供旅客參考）
- 商業評級由行內專家及旅行常客組成的==神秘顧客==評分；世界各地旅客較熟悉私人評級系統

!!! trap "易錯"
    旅發局分類制度是**四個級別**（甲級高價、乙級高價、中價、旅客賓館），**不是**五星制；「星級」是福布斯旅遊指南，「鑽石級」是美國汽車協會。

## 2.5 住宿產品

住宿是酒店最大收入來源之一；==住宿產品==指客房及顧客入住期間消費的其他相關產品或服務。

### 客房等級

| 等級 | 景觀 | 陳設 | 額外服務 |
|---|---|---|---|
| ==標準客房== | 普通（園景、停車場景） | 基本（松木傢俬、毛氈、紙拖鞋） | 無 |
| ==特級客房== | 上乘（城市景、海景） | 上級（花梨木傢俬、棉被、布拖鞋） | 免費報章、早餐 |
| ==豪華客房== | 迷人（高層海景、名勝） | 豪華（古董傢俬、羽絨被、皮拖鞋） | 行政樓層休息室、特快登記、歡迎飲品、免費接送 |

### 常見客房類型

| 類型 | 說明 |
|---|---|
| 單人房 | 一人；單人床、雙人床或大床 |
| 雙人房（兩張床） | 二人；兩張單人床 |
| 雙人房（一張床） | 二人；雙人床或大床 |
| 三人房／四人房 | 三人／二至四人 |
| ==荷里活式雙人房== | 兩張單人床以共用床頭板連接；中價及經濟型酒店較多 |
| ==工作室房／摺疊床房== | 梳化床或摺疊床，夜作臥室、日作客廳 |
| 套房 | 一個或多個臥室及起居室 |
| ==總統套房== | 最昂貴，通常只有一間；奢華裝修，度身訂造服務（私人管家） |
| 別墅 | 度假酒店的獨立房子；私人泳池；適合情侶、家庭 |
| ==無障礙客房== | 法律規定須提供；扶手、緊急按鈕、火警顯示燈、向外開的浴室門；位於低樓層近升降機；亦適合長者 |
| ==行政客房== | 位於行政樓層，可使用行政休息室；或設==女性行政樓層== |
| 長期住宅式客房 | 對象為長住顧客（外派僱員）；開放式廚房，定期管家服務 |
| 吸煙／不吸煙客房 | 吸煙客房設於特定樓層 |
| ==相鄰房== | 相隔較近或隔著走廊，但**並非相連** |
| ==相連房== | 相連但**沒有**相通房門 |
| ==相通房== | 相連且**有**相通房門 |

### 睡床類型

| 睡床 | 代號 | 尺碼 | 說明 |
|---|---|---|---|
| 單人床／兩張單人床 | S / T | 39″×75″ | 「twin」指兩張床 |
| 雙人床（一張床） | D | 54″×75″ | 易與 twin 中文譯名混淆 |
| 大床 | Q | 60″×80″ | 比雙人床更長更寬 |
| 特大床 | K | 78″×80″ | 比大床更寬 |
| 荷里活式床 | T | 78″×75″ | 兩張單人床並排共用床頭板 |
| 梳化床 | H | 48″×75″ | 工作室房，方便商務旅客在房內開會 |
| 摺疊床 | M | — | 可隱藏於牆壁或壁櫥 |
| 加床 | — | — | 臨時加設，額外收費 |
| 幼兒床 | — | — | 預訂時要求 |

### 房價

**影響房價的因素**：房間類型、大小、佈置及位置｜餐膳安排｜季節及季節性事件｜顧客類別｜住宿長短及入住日子

| 房價種類 | 對象 |
|---|---|
| ==正價== | 只就客房收取的標準價格 |
| ==公司價== | 屬常客的公司僱員；按合約反映業務量 |
| ==商務價== | 並非頻密入住的企業行政人員 |
| ==航空公司價== | 按酒店從航空公司獲得的業務量協定（機組人員） |
| ==團體價== | 旅行代理商或專業機構大量訂房 |
| ==小童價== | 小童與父母同房，設年齡限制 |
| ==套票價== | 包括用品、服務及房租，**淡季**吸引顧客 |
| ==免費房== | 旅遊董事、當地顯要、總辦事處行政人員 |

| 餐膳計價 | 包括 |
|---|---|
| ==歐式計價==（EP） | 只包房間 |
| ==歐陸式計價==（CP） | 房間＋早餐 |
| ==修正美式計價==（MAP） | 房間＋兩餐（通常早餐及晚餐） |
| ==美式計價==（AP） | 房間＋三餐（部分包下午茶） |

- 房價通常已包括：來電喚醒、保險箱、Wi-Fi、清潔房間、開床服務、泳池、健身室、行李服務、房內茶包咖啡等
- ==常客優惠計劃==：建立顧客檔案記錄喜好，提供度身訂做服務；最重要特點是客房升級及飛行里數

## 2.6 酒店顧客的類別

**分類準則**：行程目的（休閒／商務）｜人數（個人／團體）｜原居地（本地／海外）

| 類別 | 特點 |
|---|---|
| ==休閒旅客== | 個人旅客；休閒、娛樂、探親、體育或文化活動 |
| ==公司商務旅客== | 個人旅客；由公司以較低房價頻密訂房 |
| ==散客== | 又稱「自助遊旅客」；自行購買住宿及安排旅程的國際遊客 |
| ==團體旅客== | 參加旅行團，經旅行代理商預訂；花費較少，有預算 |
| ==本地旅客== | 為特別事件及活動住酒店的本地居民 |
| ==參加會議人士== | 客房由本人、企業或主辦單位預訂 |
| ==重要人物==（VIP） | 名流、常客、入住昂貴客房者、具保安風險者、高級行政人員 |
| ==匿名住客== | 隱藏身份入住 |

### 顧客需求的種類

| 顧客 | 需求 |
|---|---|
| 有特別需要的顧客 | 輪椅、傷殘人士設施 |
| 商務旅客 | 寬頻、國際直撥、報章、洗衣泊車、擦鞋、商務中心、行政樓層、會議設施 |
| 消閒及度假旅客 | 摺疊床或幼兒床、相連客房、收費電影、運動設施、水療、保姆服務 |
| 其他 | 客房餐飲、醫生、禁煙客房、改衣縫補、維修保養 |
