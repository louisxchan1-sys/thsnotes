## 5.1 餐單的基本知識

### 五大食物種類（營養均衡，每類最少一種）

澱粉質食物（提供能量）｜水果和蔬菜（維他命）｜肉類、魚類及其他非乳類蛋白質食物（蛋白質）｜牛奶、雞蛋和乳製食物（鈣）｜含脂肪及含糖份的食物

### 餐單種類

| 餐單 | 特點 | 選擇性 |
|---|---|---|
| ==自選餐餐單== | 所有食物**獨立定價**，按顧客需要準備及烹調 | 高 |
| ==套餐餐單== | 特定數目菜餚，每組選擇有限，**固定價格** | 低，甚至沒有 |
| ==是日精選餐單== | 餐廳當日推介，固定價格、每天更新；卡紙、黑板或口述 | 低，甚至沒有 |
| ==兒童餐單== | 自選餐或套餐；印有謎語圖畫；製作快、份量少、便宜 | 極低 |
| ==宴會餐單== | 套餐的一種，一群人同時用膳，菜餚逐一呈上（婚宴） | 沒有，或須預先訂餐 |
| ==雞尾酒會餐單== | 手指食物（不超過兩口），托盤招呼站立顧客；通常無餐牌卡 | 沒有（預先確定） |
| ==周期餐單== | 一系列輪流替換的套餐餐單，周期一至三星期；用於工業型餐飲、自助食堂、醫院、監獄、大學 | 低至中 |

- 周期長短取決於：管理政策、季節、可用食物、準備成本
- **周期餐單的好處**：減少規劃時間｜簡化採購｜食品生產系統化｜增加服務效率

| 非選擇性餐單的好處 | 選擇性餐單的好處 |
|---|---|
| 無須額外員工；採購簡單易監控；食物種類有限減少開支；易控制份量 | 可用廉價食物平衡貴價材料節省成本；選擇多則份量不需太大；可因應潮流及季節改變菜餚刺激消費 |

### 餐單的目標

滿足顧客及賺取盈利｜確定食物飲品種類及份量｜確定採購數量及質量｜影響餐廳形象｜作有效的市場推廣工具

### 餐單的規劃

- 餐單是餐飲運作的**基本文件**，主導業務組織管理及餐廳設計；兩大用途：後勤（廚房）的**工作文件**及為顧客提供菜餚資訊
- 影響管理層決定：平衡盈利能力與受歡迎程度｜設施用途、空間及設備｜製作方式｜食物來源及供應商

| 考慮因素 | 內容 |
|---|---|
| **與顧客有關** | 顧客類型（長者 → 健康食物）｜消費能力｜用餐次序（前菜 → 主菜 → 甜品）｜特別要求（宗教） |
| **與食物有關** | 食材成本及價格｜食材供應（季節性食材放季節性餐單）｜營養價值（低脂、高纖、素食）｜選擇種類和數目｜食物衞生及安全（避開高風險食材） |
| **與營運有關** | 廚房大小及設施｜餐廳位置（商業區選製作簡便項目）｜營業時間（早午晚餐不同）｜廚房員工技能 |
| **與市場有關** | 同行做法｜餐廳裝潢（配合統一）｜餐單設計作市場推廣工具｜使用語言 |

### 釐定餐單價格

| 方法 | 內容 |
|---|---|
| ==成本法==（最常用） | 以產品成本為基礎再標高；**食物成本百分比 = 食物成本 ÷ 售價 × 100%**；一般 20%–30%（牛扒海鮮較高）；飲料成本較低，邊際利潤較高；另須計員工及間接成本 |
| ==主觀法== | 不以成本為基礎：高級食府定價高於對手營造奢華形象；快餐店把部分項目定價低於市價甚至成本，吸引顧客同時購買其他項目，增加市場份額 |

### 餐牌設計

- 餐牌是與顧客溝通、推廣產品的工具，塑造餐廳形象，影響顧客期望
- 封面反映餐廳特質及主題；用高品質、耐用、防污防油紙張；設計獨特簡單；字體易讀；善用顏色
- ==窗口摺疊式餐牌==：顧客先看**中間內頁** → 放最想推銷的項目；==書本摺疊式餐牌==：先看**右下方** → 再到左上方
- 夾式及插入式附頁推廣每日精選；菜式描述須準確如實

## 5.2 餐飲服務的基本知識

### 餐桌擺設程序（一個座位）

1. 決定鋪桌布或桌墊
2. 左面放旁碟（牛油碟），牛油刀置其右，刀鋒向左
3. 托碟放中心
4. 主菜刀放托碟右側（刀鋒向左），主菜叉放左側
5. 湯匙放主菜刀右側
6. 沙律刀放湯匙右側（刀鋒向左）
7. 沙律叉放主菜叉左側
8. 甜品匙放托碟上方（匙口向左），甜品叉放甜品匙與旁碟之間（叉頭向右）
9. 玻璃水杯放右上角
10. 餐巾放托碟中間

- 中心裝飾品不可過大；餐具離桌邊約一英寸；酒杯按使用次序擺放
- 自選餐擺設：大型刀叉；套餐擺設按菜數（兩至三道菜，有否甜品）

## 5.3 餐廳的佈局及環境氣氛

### 佈局的功能考慮

- 影響因素：主題、服務風格、菜式、職員對顧客比率、舖面面積
- **用餐區**分多個區域，方便管理及分配人手：可拆分的彈性餐桌｜有隔板的固定卡位（私隱）｜獨立房間（聚會、會議、VIP，設最低消費）
- **水吧區**：提供一切飲料，設單人座位
- **其他**：==銷售點系統==（輸入訂單、處理付款）與服務台相鄰；收銀員（酒店餐廳把住客消費計入住宿帳目）；款接員控制客流量及==翻檯率==，平均分配顧客；經理室設於用餐區與廚房之間

### 環境氣氛

- ==氣氛==：餐廳給人的整體感覺，及在顧客、餐牌、服務類型方面留下的印象
- 燈光（柔和 → 親密浪漫；明亮 → 歡樂）｜音樂｜氣味（即磨咖啡、新鮮烘焙麵包）
- **裝修風格**（傳統、古典、現代）｜**員工制服**（建立品牌及標準形象）
- **感官**：視覺（燈光、裝飾、色彩）｜觸覺（餐檯、餐具、座位）｜聽覺（對話、音樂、廚房及設備聲響）｜嗅覺（烹調香味、通風）｜溫度

**==主題餐廳==**：餐廳概念凌駕一切，影響建築、食物、音樂及整體感覺；強調娛樂及幻想，食品吸引程度較主題為次要。六類（Pegler）：荷里活及電影｜運動及體育賽事｜時間－懷舊｜唱片、電台及電視｜旅遊－火車、飛機及輪船｜生態及圍繞我們的世界

## 5.4 不同餐飲服務的廚房佈局

### 有規劃的廚房必須具備

良好設計方便管理｜管理人員可隨時進入及監察｜產品由原材料到製成品**流程暢通**｜員工運作流程暢順｜器具分類放於所屬備餐區｜儲物區清潔、溫度監控、靠近製作區

- 生、熟、乾淨及未洗淨食物**分開處理**，降低感染風險

### 影響廚房設計的因素

員工能力及工作方式｜用餐區大小｜員工數目及技能｜運作模式（早午晚餐）｜化學品、易變質及不易變質食物的儲存區｜**員工安全**｜**走動**（減少路線交錯）｜餐廳定位｜設備｜餐單範圍及大小｜服務方式（提供服務或自助）

### 廚房工作流程

- **食物製作區**：按餐單及用餐次序 冷盤區 → 熱食區 → 甜品區；取菜區 → 托盤台；用過碗碟送洗碗碟區（大型酒店設==管事部==）
- **食物貯存區**：收貨及準備區 → 飲料、一般、乾貨、冷藏貯存（中大型餐廳才分開存放及設總廚室）
- **工作安全是廚房佈局的先要條件**

## 5.5 消防安全

- 食肆用明火、電爐、油炸爐，油煙槽油漬積聚大增火警風險

### 滅火原理：==燃燒三元素==

**可燃物、氧（空氣）、熱能（溫度）**；移除任何一種即可滅火。

**消防設施**：滅火筒｜滅火氈｜沙桶｜滅火喉｜消防花灑系統｜應急照明系統｜視象警報系統

### 火的類別

| 類別 | 燃燒物 |
|---|---|
| ==A 類火== | 固體有機物質（形成熾熱餘燼） |
| ==B 類火== | 液體或可熔化固體 |
| ==C 類火== | 氣體 |
| ==D 類火== | 金屬 |
| ==E 類火== | 帶電物質 |

### 滅火用具

| 用具 | 原理 | 適用 | 注意 |
|---|---|---|---|
| ==二氧化碳氣體式滅火筒== | 排擠空氣，令火**失去氧氣** | 電火、易燃液體、電子儀器、文件 | 可令人窒息，用後到空曠地方 |
| ==水式滅火筒== | 對燃料表面**降溫** | 木料、膠料、紡織品、紙張 | **切勿**用於電火、易燃液體、金屬 |
| ==乾粉式滅火筒== | 化學品吸收熱力或阻隔熱力傳送 | **大多數火警**，包括電火及易燃液體 | 減低能見度；對金屬有腐蝕性 |
| ==淨劑滅火筒== | 不留殘餘 | 電火、易燃液體、電子儀器、文件 | 用後到空曠地方 |
| ==泡沫式滅火筒== | 浮在液體上**隔絕**燃燒表面 | 易燃液體 | **切勿**用於電火 |
| ==滅火氈== | 隔絕 | 易燃液體小火（廚房） | — |
| ==沙桶== | — | 小火、燃燒中的金屬；清理濺落的易燃液體 | — |

!!! trap "易錯"
    - 電火可用：二氧化碳、乾粉、淨劑；**不可**用水式及泡沫式
    - 課本火的類別是 A 至 E 類；燃燒必須元素是可燃物、氧、熱能，「火」本身不是元素
