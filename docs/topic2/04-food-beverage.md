## 4.1 餐飲部的運作（酒店）

- 除客房銷售外，餐飲服務是酒店另一項**主要收入來源**
- ==餐飲==：款待業對活動、宴會或到會所需食物及飲品的統稱

| 範疇 | 要點 |
|---|---|
| ==廚房== | 儲存及準備食物；有效利用員工、設備及物料，準時製作足夠份量的優質食物；分製作廚房、宴會廚房、自選餐廚房、扒房廚房、糕餅廚房、備餐區 |
| ==餐廳== | 大型連鎖酒店通常有一所特色或高級餐廳及一所咖啡店式餐廳；服務住客及公眾；或讓名牌餐廳在酒店內經營以減低成本 |
| ==宴會及到會== | 以議定價格在特定時間地點為特定顧客提供餐飲；商務活動（會議、工作早餐）及社交活動（婚禮）；**按需要提供、須預訂**；員工需求不穩定，多聘臨時員工；多選套餐，全日活動或用自助餐 |
| ==客房餐飲服務== | 送餐到房；高度私隱及個人化；設於廚房及員工升降機附近；部分 24 小時；熱食放餐車保溫櫃；與管家部溝通回收碗碟 |
| ==酒吧管理== | 策劃、組織、員工調配、領導及監控；訂購儲存酒類、編製餐酒清單、控制成本、協助顧客選酒 |
| ==管事部== | 防止病菌散播及==交叉感染==：清潔食物準備區、烹飪用具、玻璃器具、瓷器餐具；管理化學品；保養洗碗機；滅蟲 |
| ==員工餐廳== | 由餐飲部或外判承辦商管理；成本計入**人力資源部** |

**自助餐形式**：任食自助餐｜侍應分發食物（減少浪費）｜瑞典傳統自助餐｜餐櫃、自助食堂（托盤沿餐櫃選食物付款）｜托盤線

### 餐廳組織架構

經理 → 助理經理 → 接待主管、出納員、調酒員、==部長==（分部侍應總管）→ ==分部侍應== → ==服務生==（剛入行學徒）

| 崗位 | 主要職責 |
|---|---|
| ==餐飲部經理== | 全權負責日常運作；控制預算、定價與採購；招聘培訓；制定季節推廣及新菜式；確保盈利達標；遵守健康安全條例 |
| ==餐廳經理==（maître d'） | 分配餐桌、劃分服務區域；接受訂位；處理投訴；確保侍應完成任務 |
| 分部侍應總管 | 管理一個分部（特定數目餐桌）的員工 |

### 廚房組織架構

主廚／==行政總廚== → ==助理總廚==（主廚的「左右手」）→ 部門主廚（廚房的「支柱」）→ 助理廚師 → 學廚

| 部門主廚 | 負責 |
|---|---|
| 醬汁廚師 | 煎炒及大部分醬汁 |
| 烤烘廚師 | 燒烤或烤烘食物 |
| 魚類廚師 | 魚類及貝殼類海產 |
| 蔬菜廚師 | 熱食頭盤、湯、蔬菜、澱粉及麵食 |
| 冷盤廚師 | 冷食頭盤、小點、沙律 |
| 糕餅師 | 烘焙食品及甜品 |
| 換班廚師 | 替班，填補任何崗位 |

- 行政總廚（大型餐廳主要負責行政）：安排工作、編寫菜單、採購原材料、訂定利潤目標、監督廚房、確保食品質量
- 分組系統由 ==Auguste Escoffier== 於 19 世紀末制定

### 餐飲部與其他部門的關係

客務部（電話房接客房餐飲訂單；管家部回收餐具；行政樓層酒廊小吃）｜工程部（廚房設備維修保養）｜保安部（大型宴會保安措施）｜人力資源部（旺季及宴會招聘臨時員工）｜營業及市場推廣部（提供菜單制定推廣策略）｜採購部（訂購食材）｜會計部（預算、成本控制目標）

## 4.2 餐飲服務的分類

### 按市場／顧客類別

| 市場 | 例子 |
|---|---|
| ==酒店市場== | 酒店物業內的餐廳，為住客服務及賺取額外收入 |
| ==閒暇市場== | 旅遊景點、主題公園、高爾夫球會、海灘小食店 |
| ==商業及工業市場== | 商業或工業大廈內為員工而設 |
| ==學生市場== | 學校或大學的自助食堂 |
| ==零售市場== | 百貨公司美食廣場、便利店、自助售賣機 |
| ==交通市場== | 飛機、鐵路、郵輪上及機場、碼頭的餐廳 |
| ==醫護市場== | 醫院及療養院；著重食品控制 |
| ==其他公營部門市場== | 監獄、警局、軍校；多獲政府資助，屬非牟利，目標是將成本降至最低 |

### 按營運模式

| 模式 | 特點 |
|---|---|
| ==獨立經營== | 多由家族經營，東主有絕對控制權；**結業率最高**；依靠附近顧客 |
| ==連鎖經營== | ==單一概念連鎖==（麥當勞、肯德基）；==多元概念連鎖==（美心經營快餐店及高級食肆）；品牌知名度高，銷售額一定百分比撥作廣告；品質一貫，不勇於嘗試的遊客常光顧 |
| ==以盈利為宗旨== | 一般餐廳、酒店餐廳、快餐店、酒吧、會所餐廳 |
| ==非以盈利為宗旨== | 資助或福利性質，盡量減低成本；公司、學校、醫院飯堂 |

### 常見餐飲服務的比較（必背）

| | ==高級餐廳== | ==休閒餐廳== | ==快餐店== | ==酒吧== |
|---|---|---|---|---|
| **餐單** | ==自選餐==餐單；飲品餐單分開，酒類繁多；==即點即煮==；高質新鮮食材；定價高 | 自選餐、自助餐、健康食品；特定時段套餐；價格適中；菜式選擇較多 | 選擇很有限；製作簡易、方便帶走；營養價值較低；便宜；圖片燈牌點餐；食材在中央廚房半加工 | 主要提供酒精飲品；食物次要（零食、手指食物）；歡樂時光優惠 |
| **服務** | ==職員對顧客比率高==；==翻檯率低==；或有衣著要求；全套餐桌服務、正式擺設；收 10% 服務費；或須訂檯 | 職員比率較高級餐廳低；無嚴謹衣著要求；全套餐桌服務、簡單擺設；多收服務費 | 職員比率**極低**；**自助形式**；自由選座；無餐桌擺設；不收服務費；互動少；幾乎無需等待；營業時間長 | 多於晚上營業；只招待 18 歲以上；調酒員有專業知識 |
| **主題** | 講究裝潢；間隔寬敞、保障私隱；安靜舒適；高貴典雅 | 裝修不如高級餐廳正規；輕鬆氣氛 | 現代風格；豔麗色彩及標誌建立品牌；制服醒目 | 吧檯；燈光較暗；按娛樂定主題（的士高、運動酒吧） |

**休閒餐廳的延伸類別**

| | ==咖啡室== | ==特色餐廳== | ==自助食堂== |
|---|---|---|---|
| 餐單 | 簡單，主要提供飲品及小食；可外賣 | 以單一食物或一種地方菜作主打；以小眾市場為目標 | 選擇有限；圖片餐牌 |
| 服務 | 自助點餐取餐；自由選座；普遍不收服務費 | 由低職員比率至全套餐桌服務皆可 | 職員比率極低；翻檯率高；櫃檯式、自由流動式、超級市場式 |
| 主題 | 座位舒適，鼓勵逗留社交；暖調燈光；開放式廚房 | 盡量發揮餐飲概念的獨特之處 | 裝潢簡約；間隔狹窄，私隱度低 |
