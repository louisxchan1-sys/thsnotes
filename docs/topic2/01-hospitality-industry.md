# 1. 款待業

<p class="freq">出題頻率：款待業的特點 ⭐⭐（課本第14章歷屆極少考）｜款待業與旅遊業的關係 ⭐⭐（2025 MC 易錯）</p>

---

## 1.1 款待業的性質

- ==款待==：歡迎顧客或外來人士、照顧其基本需要的善意行為，主要涉及**飲食與住宿**；現指客人與主人之間的**關係過程**
- ==款待業==：為「離家在外」的人提供食物及／或飲品及／或住宿的公司或組織
- 無論哪類遊客，旅遊過程中都需要住宿及飲食，故款待業是旅遊業的主要領域之一

---

## 1.2 款待業的特點

| 特點 | 要點 |
|---|---|
| ==產品服務組合== | 顧客消費的是產品**及**服務的組合：**有形特質**（牛扒、餐酒、員工打扮、裝潢）＋**無形特質**（舒適環境、友善態度）；員工質素及提供服務的方法往往比有形產品更直接影響體驗；有形產品易被模仿 → 以提高服務水準作區分策略 |
| ==雙向溝通== | 提供優質服務最重要的一環；需顧客與員工雙方投入；員工之間、部門之間的互動亦重要 |
| ==建立關係== | 非常倚賴**回頭客**：收入穩定、減低季節性影響、正面口碑建立品牌；會員計劃；前線員工以關心備至及度身訂做的服務建立「友好關係」 |
| ==文化多樣性== | 員工接觸不同地區顧客及不同背景同事；應持開放態度（例：為素食者提供素食；不在回教徒同事面前吃豬肉） |
| ==勞工密集== | 以服務為主導，高級餐廳及五星級酒店員工與顧客比率高；科技取代簡單工序，但重視「關心」的顧客仍期望人與人接觸及個人化服務 |

---

## 1.3 款待業與旅遊業之間的關係

| 款待及旅遊業 | 例子 |
|---|---|
| 旅行 | 郵輪、航空公司、鐵路 |
| 住宿 | 酒店、汽車酒店、服務式住宅 |
| 餐飲服務 | 餐廳、咖啡室、酒吧 |
| 娛樂 | 景點、公園、博彩設施 |

- **住宿和餐飲服務是款待業範疇的核心部分**
- 款待業可滿足**遊客及非遊客**（本地顧客）的需要；並非所有款待業務都屬牟利性質
- 兩大業務範圍：==住宿==（為離家在外的人提供住宿，通常連帶飲食）；==餐飲==（為本地、短途往返、過境顧客及遊客提供餐飲）
- **款待業管理人員的三個目標**：令顧客感到賓至如歸｜令顧客感到一切稱心如意｜確保業務能持續為顧客提供服務並符合其預算

!!! trap "易錯"
    2025 MC 有 51% 考生答錯：**航空服務只屬旅遊業**（滿足交通需求），不同屬旅遊業與款待業。款待業的核心是**住宿及餐飲**。

## 1.4 款待業就業前景

| 正面觀點 | 負面觀點 |
|---|---|
| **職業選擇豐富**：新酒店及餐廳落成，國際連鎖集團提供海外機會；前線至後勤職位 | **工作時間長且不規律**：輪班、通宵（夜間核數員）、無公眾假期、旺季加班 |
| **接觸不同背景人士**：前線如旅遊大使，工作有成就感 | **於壓力下工作**：須迅速及優質服務；處理投訴及憤怒顧客 |
| **長期職業發展**：以經驗及表現晉升，房務員可升至總經理 | **起薪低**：低技能工種多 |
| **員工附帶福利**：員工膳食、員工價訂房（全球同品牌酒店） | **職業地位低微的觀念** |

**畢業生職位**：住宿業（款接員、房務員、電話接線生、訂房部、禮賓部、門僮、商務中心）｜餐飲服務業（侍應、接待主管、出納員、傳菜員、調酒員、學廚、助理廚師、宴會服務員）｜其他（導遊、領隊、旅行代理商、主題公園、會議宴會銷售員）
