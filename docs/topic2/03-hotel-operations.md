# 3. 酒店運作簡介

<p class="freq">出題頻率：酒店管理模式 ⭐⭐⭐（2012、2014、2016、2021、2023、2024）｜客房狀況代碼 ⭐⭐⭐⭐（7 次）｜酒店部門職能 ⭐⭐⭐（2025 MC：管家部崗位職責；2025 DBQ：部門職能）｜銷售指標 ⭐⭐⭐｜超額預訂 ⭐⭐</p>

## 3.1 酒店的產權

| 產權 | 例子 |
|---|---|
| ==私人== | 個人、合伙人或私人企業擁有的獨立酒店（新樂酒店） |
| ==本地集團== | 一家本地企業擁有幾家酒店（海逸國際酒店集團） |
| ==國際集團== | 跨國連鎖酒店集團成員（香港 JW 萬豪酒店） |

## 3.2 ==酒店的管理模式==

| 模式 | 意思 |
|---|---|
| ==獨立擁有及經營== | 沒有聯營機構，由物業擁有人管理 |
| ==管理合約== | 由酒店管理企業經營屬於其他企業的物業 |
| ==特許經營== | 投資者（特許經營者）付費使用特許經營權擁有者的品牌及營運模式 |

### 管理合約

| | 好處 | 壞處 |
|---|---|---|
| **酒店擁有人** | 獲得專業知識，減少失敗風險、提升服務水準；著名管理企業提升知名度；無需參與營運 | 失去控管營運的權力；須負擔所有成本、費用及損失；若只收定額管理費而無分紅，管理企業士氣或較低 |
| **管理企業** | 不論業績均收取管理費；很少或無需前期融資或投股；合約可長達 5、10 或 20 年 | 倚賴擁有人提供營運資金；不能干預產權決定（如轉讓）；無獎賞制度則生意好也無額外賞金 |

### 特許經營

| | 好處 | 壞處 |
|---|---|---|
| **特許經營者** | 取得營運專業知識（選址、規劃、開業前培訓、經營手冊、==中央訂房系統==、品質控制、採購、營銷）；使用著名品牌；對營運有絕對控制權 | 須遵循標準，不容修改；須付加盟費及持續經營費用；有被終止或不獲續約的風險 |
| **特許經營權擁有者** | 收取加盟費及持續經營費用 | 加盟者不遵循標準影響服務質素；不稱職加盟者損害品牌；須披露機密信息 |

- 延伸：==轉介聯盟==（如 Leading Hotels of the World）以較低成本提供類似特許經營的得益：共用中央訂房系統、標誌、廣告，但仍獨立經營

## 3.3 酒店部門

### 部門分類

| 分類 | 意思 | 例子 |
|---|---|---|
| ==收入中心== | 向顧客提供商品及服務，**直接**產生收益 | 款接部、餐廳、客房餐飲服務、禮品店、商務中心 |
| ==成本中心==（支援中心） | 協助收入中心運作，不直接產生收益 | 人力資源部、採購部、會計部、工程部 |
| ==前線== | 顧客可接觸及看見，屬服務接觸點 | 款接部櫃檯、餐廳、禮賓部、行李服務 |
| ==後勤== | 員工極少與顧客互動 | 廚房、管家部、人力資源部、工程部（房務員雖或遇見顧客，主要職責是清潔，故屬後勤） |

### 主要行政人員及部門職能

| 職位／部門 | 職能 |
|---|---|
| ==總經理== | 領導管理團隊；協調所有部門；參與制訂政策及策略；對酒店整體表現承擔全部責任 |
| ==駐店經理== | 制訂及執行計劃；查核經營狀況；編製統計報告交總經理；負責日常經營 |
| ==工程部== | 電力、水管、空調、升降機等實質設備及機械 |
| ==保安部== | 保障顧客、訪客、僱員及酒店安全；監察設備、巡視、警報系統 |
| ==人力資源部== | 招聘、迎新、培訓、工資福利、勞資及僱員關係 |
| ==餐飲部== | 酒廊、酒吧、咖啡店、餐廳、宴會、客房餐飲服務、糕餅店 |
| ==營業及市場推廣部== | 發展新業務、廣告、銷售推廣及公關 |
| ==會計部== | 財務總監領導；應收應付帳款、薪酬、成本控制、損益報表、處理帳單查詢 |
| ==客務部== | 管理核心產品「客房」；由**前堂部**及**管家部**組成（或另設訂房部、電話房、禮賓部）；客務部總監統領可解決兩部門矛盾 |

## 3.4 前堂部

**定位**：酒店的==中樞神經==，給予顧客**第一個及最後一個印象**。

**三個主要功能**：銷售客房｜確保顧客帳戶資料不斷更新｜為顧客提供服務及資訊

| 崗位 | 主要職責 |
|---|---|
| ==前堂經理== | 監察訂房、預測入住率、確定房價架構、審核入住情況及平均房價、按抵離情況調配員工、款待 VIP |
| ==大堂副經理== | 代表管理層處理日常運作；歡迎 VIP；處理查詢及**投訴**；確保各部門運作暢順 |
| ==客戶關係主任== | 迎接個人顧客；提供當地資訊；推廣酒店設施 |
| ==電話房== | 提供資訊；國際電話及==來電喚醒==；內部傳呼；保障顧客私隱；緊急事件時作**通訊中心**；部分酒店設「一站式服務」 |
| ==訂房部== | 處理訂房、編製確認單；要求顧客核實（保證）訂房；編製 VIP 名單；更新顧客歷史檔案；經理決定停止接受訂房或批准==超額預訂== |
| ==款接部== | 確保入住率及收入最高；督導分配房間、處理團體及轉房；款接員負責登記入住、結帳退房、保險箱、外幣兌換 |
| ==禮賓部== | 禮賓司（資訊建議、確認航班、預訂餐廳及門票、安排轎車）、機場接待員、司機、泊車服務員、門僮、行李部組長、行李服務員 |
| ==行政樓層== | 位於頂層；特快登記及退房、酒廊免費早餐及茶點、免費使用會議室等；商務中心 |

### 訂房

- 渠道：直接（電話、電郵、互聯網）、訂房網絡、旅行代理商、旅行團經營商、會議籌辦人、==自來客人==
- ==已確認（保證）訂房==：顧客已預繳，即使不出現亦不獲退款；酒店隔夜保留房間
- ==未獲核實的訂房==：保留至取消時間（一般為抵埗日**下午 6 時**），不出現便重新銷售

### 入住登記程序（下午 2 時後）

1. 迎接顧客
2. 核實顧客身份（護照、訂房憑證）
3. 提供入住登記表格
4. 確認付款方式（信用卡或==預先支付==現金按金）
5. 在==酒店資產管理系統==核對及更新帳戶、分配客房
6. 分發客房鎖匙並提供資訊
7. 陪同顧客前往客房

- **團體登記**：事先登記（按客房分配名單預備鎖匙咭）；團體入住登記櫃檯，由領隊辦理
- 自來客人：先收大額按金或信用卡預扣

### 結帳退房程序（中午 12 時前）

1. 問候顧客
2. 核對顧客資料
3. 核對需否收取**延遲結帳退房費用**（例：下午 6 時前加收 50%，6 時後收全日房價）
4. 核對**漏帳**（早餐、迷你酒吧）
5. 請顧客再次核對費用
6. 結清帳戶：==總帳戶==（客房及早餐，由公司或旅行社支付）與==雜項費用帳戶==（個人開支）
7. 提供協助（行李、交通、預訂姊妹酒店）
8. 更新客房狀況（OD → VD）及顧客歷史記錄

### 處理超額預訂

- 原因：減少顧客不出現及臨時取消的損失，提高客滿機會；問題：損害商譽、顧客不滿及投訴
- 先在酒店內找房（OOO 房能否修好、有否雙重訂房）；按優先次序分配（VIP、保證預訂、常客）；聯繫姊妹或附近酒店
- ==轉送顧客==程序（屬違約，由經驗豐富員工處理）：
    1. 向顧客致歉
    2. 提供其他選擇及賠償（替代酒店首晚免房租、免費交通、長途電話、果盤、將來免費升級、餐飲折扣券）
    3. 提供行李服務和交通
    4. 跟進服務

### ==顧客流程==

抵埗前（訂房）→ 抵埗（登記、分配房間、分發門匙、搬運行李）→ 入住（郵件訊息、保險箱、兌換貨幣、來電喚醒、更新帳戶）→ 離開（結帳退房、結清帳單）

### 前堂部與其他部門的關係

| 部門 | 關係 |
|---|---|
| 管家部 | 前堂提供入住、退房資料及特別要求；管家部提供實際客房狀況 |
| 工程部 | 維護前堂設施（如升降機） |
| 保安部 | 緊急情況提供顧客資料；處理財物遺失 |
| 人力資源部 | 培訓、招聘、儀表及紀律標準 |
| 餐飲部 | 提供特別需要清單（歡迎果籃）、團體餐膳安排 |
| 營業及市場推廣部 | 團體訂房；提供客房分配名單 |
| 會計部 | 轉交按金及收款資料；核准賒帳企業名單 |

### 客房銷售收入及==銷售指標==

- 香港酒店收入：**房間銷售約 61%**，餐飲約 32%；賭場酒店主要來自博彩，會議酒店宴會收入較多

| 指標 | 公式 | 意義 |
|---|---|---|
| ==入住率== | 已售出房間數目 ÷ 酒店房間總數 × 100% | 利用客房資源的程度（業務「數量」） |
| ==每入住房顧客人數== | 酒店入住顧客人數 ÷ 入住房數目 | 管家部估計用品消耗 |
| ==每日平均房價== | 客房收入 ÷ 入住房數目 | 業務「質素」 |
| ==每間可銷售房收入== | 客房收入 ÷ 酒店客房總數 | 包括所有可供出售房間；通常**小於**平均房價；反映利用所有客房賺取收入的能力 |

!!! note "例：310 間房，405 人入住 265 間房，客房收入 424,500 港元"
    入住率 = 265 ÷ 310 = 85.48%｜每入住房顧客人數 = 405 ÷ 265 = 1.53｜每日平均房價 = 424,500 ÷ 265 = 1,601.89 港元｜每間可銷售房收入 = 424,500 ÷ 310 = 1,369.35 港元

## 3.5 管家部

- 負責清潔及保養客房、公共地方、辦公室及後勤區域；**潔淨程度是顧客挑選酒店的首要因素**；往往是酒店內**規模最大**的部門；屬==支援中心==
- 責任：清潔客房樓層｜清潔公共地方（大堂、洗手間、泳池、健身室、會議室）｜清潔員工區域｜洗衣服務、制服及布草房、園藝、蟲害防治、花店

| 崗位 | 主要職責 |
|---|---|
| ==行政管家== | 招聘培訓、調配人手、制訂工作程序及輪值表、訂購及管理設備布草、處理投訴、管理鎖匙 |
| 助理行政管家 | 協助及代行行政管家職責；檢查清潔；與前堂部協調 |
| 助理管家 | 指派房務員至樓層；檢查設備；盤點 |
| ==樓層主管== | 檢查員工工作及客房；培訓；分發清潔材料；與款接部聯絡抵離 |
| ==房務員== | 清潔客房、浴室；整理布草；==開床服務==；報告故障及不尋常狀況 |
| 公共地方主管／清潔員 | 監督及清潔公共地方、走廊、辦公室 |
| 裁縫師 | 修補布草、制服、窗簾；修補顧客衣物 |
| 制服及布草房服務員 | 分類、點算、分發布草及制服 |

### 管家部與其他部門的關係

前堂部（交換客房狀況；翻新安排在入住率低時）｜工程部（輕微維修、預防性保養、節約水電）｜保安部（房務員鎖好門窗）｜餐飲部（餐廳布草制服、宴會布草計劃、客房餐飲餐盤、迷你酒吧）｜營業及市場推廣部（會議團體房間）｜採購部（清潔及顧客用品）｜會計部

### 客房清潔

**清潔次序**：1 顧客要求「優先服務」的客房 → 2 禁止來賓進入的已退房客房 → 3 已退房客房 → 4 有顧客入住的客房

- 早會告知清潔數量、團體提前到達、特別要求；每人清潔 10–15 間；標準退房客房約 30 分鐘

| 客房清潔程序 | 要點 |
|---|---|
| 1 進入客房 | 敲門並告知三次；房務車停在門前 |
| 2 初次檢查 | 打開燈、電視、空調、冰箱檢查；檢查冰箱物品；確認沒有遺留物品 |
| 3 鋪床 | 換上乾淨布草 |
| 4 清理垃圾 | 清空垃圾及煙灰缸 |
| 5 清潔浴室 | 消毒、換毛巾、補充用品 |
| 6 吸塵 | 由內側至外側 |
| 7 最後檢查 | 以房內電話將客房回復待售狀態；更新客房分配表 |

- **公共地方清潔**：大堂深入清潔在夜班進行；白天只作輕微例行清潔
- ==客人用品==（必需品，如衛生紙、衣架）與==客人設施==（非必需品，如房內保險箱、迷你酒吧）；租借用品如熨斗、幼兒床、變壓器（摺疊床或收費）

### ==客房狀況代碼==（必背）

| 代碼 | 意思 |
|---|---|
| ==OC== | 已清潔的入住房 |
| ==OD== | 未清潔的入住房 |
| ==VC== / VR | 已清潔待售房間 |
| ==VD== | 未清潔待售房間 |
| ==DND== | 請勿打擾 |
| ==OOO== | 待修（維修、翻新或全面清潔） |
| ==NNS== | 不需服務 |
| LB | 少量行李 |
| NB | 沒有行李 |
| XB | 加床 |
| SO | 外宿（床上無使用痕跡） |
| CO | 結帳退房 |
| ED | 預定離開 |
| I | 已檢查房間（房務督導重覆檢查） |
| DNCO | 未退房（已付款但未完成退房程序或離開時無通知） |

- 退房後系統自動改為 VD → 清潔後改為 VC 或 I
- 須特別留神 DND、LB／NB、SO、反鎖房（可能變為**逃帳住客**），影響收入及名譽

### 保安程序

- 不得向訪客洩露顧客姓名及房號
- **發現貴重物品**：報告管家部寫字樓，在大堂副經理、樓層主管及保安主任到達前留在客房；詳細記錄；客房雙重緊鎖
- **鎖匙管理**：上鎖鎖匙櫃；簽入及簽走記錄；不得懸掛在手推車或門鎖上；不得帶出酒店；遺失須立即報告
- **可疑人士**：報告寫字樓，再通知保安主任
- ==失物認領處==：所有物品記錄於失物認領記錄簿；保管**三個月**，無人認領歸發現者；易壞物品保管較短
