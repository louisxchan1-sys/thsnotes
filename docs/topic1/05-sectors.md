# 5. 旅遊業中的不同界別及其角色

<p class="freq">出題頻率：政府在旅遊業發展中的角色 ⭐⭐⭐⭐（2026 考評報告點名弱項）｜旅發局、旅監局職能 ⭐⭐⭐｜中介機構、分銷途徑 ⭐⭐⭐｜交通模式 ⭐⭐｜郵輪 ⭐⭐（2024 MC 多題）｜外遊警示 ⭐⭐（2026 MC 易錯）</p>

## 5.1 界別的分類及連繫

| ==私營機構==（以賺取盈利為首要目標） | ==公營機構== |
|---|---|
| 款待業、運輸業、景點、中介機構、其他協助之私營機構 | 政府、旅遊組織、其他協助之公營機構 |

註：部分景點、運輸及款待機構亦可由政府擁有及管理。

| 旅遊體驗階段 | 涉及界別 |
|---|---|
| 策劃安排 | 旅行團經營商、旅行代理商 |
| 送抵目的地 | 運輸業經營商 |
| 在目的地 | 款待業（住宿、餐飲）、旅遊服務（外幣兌換、零售）、景點、商務設施 |

各界別緊密連繫，如旅行代理商作中間人，與酒店、航空公司合作安排行程。

## 5.2 私營機構

### 款待業

- ==款待業==：向顧客提供食物、飲料及／或住宿的公司或機構，分==住宿業==及==餐飲業==
- 住宿業：酒店、汽車酒店、度假酒店、營地、宿舍、賓館；按**位置**（風景區、市中心、機場、市郊、公路旁）或**評級**分類；內地用星級，香港用「香港酒店分類制度」
- 餐飲業：高級餐廳、休閒餐廳、快餐店、咖啡室、酒吧；特色餐廳本身可成為旅客必到景點

### 運輸業

| 模式 | 細分 |
|---|---|
| 航空 | 國內／國際；==傳統航空公司==（全面服務）及==低成本航空公司== |
| 水路 | 渡輪、郵輪 |
| 陸路（汽車） | 旅遊巴士、私家車 |
| 陸路（鐵路） | 國內／國際；高速鐵路及普通鐵路 |

**航空**

- 四種客位：頭等、商務（空間大、可平卧）、特選經濟（座位及腿部空間較大，服務膳食同經濟）、經濟
- ==定期航班==：按預設時間及班次運作，不論人數多寡都按時開出
- ==不定期航班==（包機）：無固定時間表及價目表；不受時間及目的地限制，增補定期航班於繁忙時段的服務

**水路**

- ==郵輪==：度假形式的水上旅程（不包括以運輸為主要目的）；本身是「==自給自足的目的地==」，可膳宿、娛樂、旅遊；多在同一地方開始及結束；全包費用包括往返登船地點的交通（或住宿）、船上活動、岸上觀光團
- ==渡輪==：港口之間短距離旅程（港澳渡輪部分被港珠澳大橋穿梭巴士取代）

**公路**：最具彈性、最經濟的集體運輸；旅遊巴士（本地、國內、國際快線、觀光、機場接駁）；汽車服務（租車、計程車、房車）。商務客租車求方便可靠；觀光客求舒適及到達公共交通不易到的地方。

**鐵路**：重要性曾因私家車及航空而下降，後因觀景及豪華列車改善（東方快車、印度洋—太平洋號、西伯利亞鐵路、藍色火車）；另有地鐵、機場快線。

| 模式 | 優點 | 缺點 | 對旅遊業的影響 |
|---|---|---|---|
| 航空 | 速度快、可達遠程，適合長途 | 燃料用量高；安全管制嚴緊令價格高昂 | 縮短行程時間；可達世界每個角落，促進大規模國際旅遊 |
| 水路 | 適合長／短途；高度舒適；度假放鬆 | 速度慢；暈船浪；勞工成本高；活動範圍以船上為主 | 郵輪自八十年代起成流行休閒旅遊模式 |
| 陸路（汽車） | 彈性大，直達目的地；適合短途；可攜帶度假器材 | 道路共用易擠塞 | 旅客更有彈性計劃行程；連接目的地及車站 |
| 陸路（鐵路） | 車站多位於市中心，方便快捷；適合中／長途；較環保；載客量大 | 固定成本高昂 | 十九世紀令偏遠地方得以發展；觀景鐵路 |

### ==中介機構==

- 顧客與供應商之間的「中間人」：==旅行代理商==及==旅行團經營商==（各分入口及外遊）
- 供應商：航空公司、郵輪及渡輪、旅遊巴士、鐵路、酒店、汽車租賃

**分銷途徑**

| | 傳統 | 二十一世紀 |
|---|---|---|
| 流程 | 供應商「製造」產品 → ==旅遊批發商==整合成整套產品 → 旅行代理商代售賺取佣金 → 消費者 | 供應商透過互聯網**直接**聯繫消費者，無須中介 |

| 分銷級別 | 做法 | 好處／壞處 |
|---|---|---|
| ==單向== | 供應商直接賣給消費者 | 不必付佣金，可給忠誠顧客優惠 |
| ==雙向== | 經一層中介機構 | 分銷更廣；但須付佣金（可高達零售價 25%） |
| ==多向== | 供應商 → 旅遊批發商（捆綁機票、住宿等）→ 旅遊零售商 → 消費者 | — |

- 中介層級越多，供應商對產品的**控制越少**；中介的零售價不能高於供應商自行出售的價格，故供應商須以折扣價供貨；佣金傳統 5%–10%，現可達 25%

**旅行代理商的功能**

1. 提供==一站式==旅遊產品：把多次性購買變成一次性購買，打破地區局限
2. 旅遊產品主要的==分銷途徑==：協助供應商分銷產品
3. 促進顧客旅遊活動及旅遊業發展：預訂、確認、提供資訊及專業意見

- 趨勢：==線上旅行社==及供應商自設應用程式，繞過傳統中介及旅行團經營商（例：Trip.com 一站式平台；Tripadvisor 提供評論及直接預訂）

**旅行社從業員所需的產品知識**：目的地（氣候、政治、節日、習俗、景點、衛生風險、匯率、簽證）｜航空公司（預訂系統、航班時間、票價、機艙服務）｜機場（設施、海關保安、稅項）｜陸路及水路運輸｜主要供應商（形象、服務質素、佣金）｜旅遊套票等。其他技能：客戶服務、地理、銷售和營銷、英語、文書。

**旅遊規劃者策劃旅程的考慮**：按酒店、交通、食物、行程四方面，考慮客人的傾向／需要、興趣、預算、安全；另考慮天氣、淡旺季及節慶、供應量、社會及政治穩定性、匯率、恐怖活動及天災。

### 其他協助之私營機構

| 機構 | 要點 |
|---|---|
| ==旅行保險== | 保障醫療住院、意外傷亡、遺失行李、行李延誤超過 12 小時、取消或縮短行程、手機、個人責任；只在投保時限內生效，有最高年齡限額 |
| 外匯服務 | 銀行、酒店、外幣兌換店；仍需少量當地貨幣 |
| 信用卡 | 簡單、快捷、安全、方便 |
| 零售商店及餐廳 | 購物是旅客在香港的首選活動 |
| 旅遊刊物 | 旅遊指南、旅遊雜誌；趨勢是**電子化**，建立雙向溝通渠道 |

## 5.3 公營機構

- 分==政府部門==及==法定組織==：負責規劃、開發審批、入境事務、目的地推廣；或擁有機場、郵輪碼頭、景點

### ==政府在旅遊業發展中的四個主要角色==（必背）

| 角色 | 內容 |
|---|---|
| 1 ==計劃及促進旅遊業== | 制定長短期政策及計劃、目標及策略；評估需求、分配資源；透過酒店及旅遊學校提供培訓；可交國家旅遊局負責 |
| 2 ==管制及監察旅遊業== | 防止不良發展、維持質素、平衡供求、保障旅客：**拒絕或批准計劃**；**外匯管制**；**監察旅遊業務**（發牌給航空公司、旅行社；酒店註冊及評級） |
| 3 ==直接經營與旅遊業有關的項目== | 擁有公園、航空公司、機場、博物館、古蹟、鐵路、隧道、酒店度假區、高爾夫球場等 |
| 4 ==向本地及海外市場推廣旅遊業== | 印製地圖及書刊、經營資訊中心、廣告、推廣及公關活動；推廣冷門景點、淡季多宣傳 |

**其他工作**：積極參與（為投資者提供資料、保證、立法吸引外資）｜協助及促進投資（低於市價土地、低息貸款）｜實際運作支援（資助培訓、批准輸入技術勞工、簽證安排、磋商航權）｜研究和策劃

!!! trap "易錯"
    2026 考評報告點名考生對**政府在旅遊業發展中的角色**掌握不足。作答須寫出四個角色的**名稱**，再以資料中的政府措施逐一配對（例：發牌給旅行社 → 管制及監察；旅發局海外推廣 → 推廣；擁有博物館 → 直接經營）。

### 相關政府部門

國家旅遊機構（文化和旅遊部）｜地區性旅遊機構｜大都會市旅遊機構（香港旅遊發展局）｜政策部門（文化體育及旅遊局、旅遊事務署）｜海事處｜入境事務處｜香港海關｜運輸署｜規劃署｜環境保護署｜民航處｜漁農自然護理署｜衞生署旅遊健康服務

### 旅行手續

| 手續 | 要點 |
|---|---|
| ==護照== | 公民身分官方證明；有效期通常五至十年；大部分國家要求**不少於 6 個月**有效期 |
| ==簽證== | 目的地賦予入境允許，列明逗留時間、入境次數、可否工作；可出發前簽發、抵達時授予、或==豁免簽證==；重視旅遊得益的政府採較靈活簽證（香港約 170 個國家及地區免簽證，最長 180 天），重視安全的較嚴格（北韓、美國） |
| 拒發簽證原因（部分） | 欺詐或虛假陳述、犯罪記錄、威脅國家安全、曾違反簽證規定、與原居國聯繫不牢固、打算永久居留或工作、未能證明維生能力、敵對國家公民、傳染病、護照即將過期 |
| ==檢疫規定== | 來自疫區須出示防疫注射證明；否則可能被拒入境、醫療觀察、隔離或即時注射；由衞生署港口衞生科主理 |
| ==關稅規定== | 違禁品（危險藥物、槍械）；徵稅品（煙酒）限量；寵物須批准；部分國家設==退稅==吸引購物；貨幣攜帶限額 |
| 公眾安全 | 機場安檢；保安局==外遊警示制度== |

| 外遊警示 | 意思 |
|---|---|
| ==黃色== 有威脅跡象 | 留意局勢、提高警惕 |
| ==紅色== 有明顯威脅 | 調整行程、如非必要避免前赴 |
| ==黑色== 有嚴重威脅 | **不應前赴** |

!!! trap "易錯"
    2026 MC 有 52% 考生答錯：**黑色外遊警示**表示目的地存在**嚴重威脅，不應前赴**。

## 5.4 香港特別行政區政府的角色和本地主要旅遊機構

| 機構 | 性質 | 主要職能 |
|---|---|---|
| ==旅遊事務署== | 政府部門（1999 年成立，隸屬文化體育及旅遊局） | **制定和統籌落實**促進旅遊業發展的政策、策略和計劃；領導和協調其他決策局及部門 |
| ==香港旅遊發展局== | 政府資助的**法定機構** | 在世界各地**宣傳和推廣**香港；提升旅客在港體驗；就旅遊設施向政府提供建議 |
| ==香港旅遊業議會== | 行業總商會（2022 年完成自律監管任務） | 推動行業發展和專業化；提升服務水平；維護會員權益；協助拓展商機 |
| ==旅遊業監管局== | 新法定監管機構（《旅遊業條例》第 634 章） | 旅行代理商、導遊和領隊的**發牌和規管**；規管入境團光顧的商店；管理==旅遊業賠償基金== |
| ==香港酒店業協會== | 業界協會（1961 年成立） | 保障酒店業合法權益；提供統計資料；協助政府檢討政策；培訓；確保服務標準 |

**旅發局六項工作目標**：擴大旅遊業對香港的貢獻｜推廣香港為世界級旅遊目的地｜提倡改善旅客設施｜支持政府推廣旅遊業重要性｜支持為旅客提供服務的人士｜向行政長官提供建議

**旅遊業賠償基金**

- 保障：持牌旅行代理商**倒閉**損失外遊費的 **90%**；外遊旅行服務期間**意外**傷亡，最高 **300,000 港元**
- 外遊旅客：向持牌旅行代理商購買**兩項或以上**服務（交通、境外住宿、活動安排）
- 不保障：疾病醫療開支；活動非由持牌旅行代理商舉辦；團員行程結束後自行逗留期間的意外
- 旅客須：光顧持牌旅行代理商；取得及保留印花收據

| 機構 | 要點 |
|---|---|
