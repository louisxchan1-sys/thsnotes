## 1.2 ==旅遊業整合模式==

概括旅遊業主要持分者的互動，以及他們如何回應外在因素的轉變。

| 元素 | 要點 |
|---|---|
| ==旅客== | 整個模型的**核心**；沒有旅客便沒有旅遊業 |
| ==旅遊推廣者==（第一層） | 與旅客保持密切聯繫：旅遊局、直接推銷商、會議策劃者、旅行代理商（傳統及線上）、旅行團經營商 |
| ==旅遊服務供應商== | 航空公司、旅遊巴營運商、鐵路、郵輪、酒店、汽車出租公司；獨立提供服務，亦互相合作組成旅行團套票 |
| ==外在因素== | 社會及文化、政治、環境、經濟、科技 |

### 外在因素：推動或阻礙旅遊業發展

| 因素 | 要點 | 例子 |
|---|---|---|
| ==社會因素== | 人口趨勢（壽命長、遲婚、出生率低）改變所需產品；本地人對旅客的態度影響旅客感受 | 人口老齡化 → 郵輪、水療需求增加，傳統主題公園需求減少；旅發局「好客之道」運動 |
| ==文化因素== | 居民願分享本地文化 → 吸引旅客；文化旅遊成最受歡迎形式之一；過多旅客威脅文化保育 | — |
| ==政治因素== | 政府投資基建、鼓勵外資、開放簽證；政局穩定與否；外交關係 | CEPA 下的「==個人遊==」計劃帶來超過 15 年增長；埃及政局不穩及恐襲，旅客由 2012 年 1,150 萬跌至 2016 年 540 萬 |
| ==經濟因素== | 可支配收入、目的地負擔能力、匯率；經濟好 → 多去、去遠、留長；經濟差 → 不去、去近、縮短 | 盧布 2013–2016 急速貶值，俄羅斯訪港旅客減少近 40% |
| ==環境因素== | 過度城市化及旅遊發展擾亂生態；環保意識提高 → 生態旅遊、綠色主題酒店、可持續旅遊 | — |
| ==科技因素== | 鐵路 → 飛機促成大規模國際旅遊；手機應用程式搜索、預訂；==共享經濟==應用程式；==中央預訂系統== | 內地高鐵、改良飛機設計開闢新長途路線 |

## 1.3 「旅遊」的歷史

| 時期 | 特點 |
|---|---|
| 羅馬帝國（公元前 27 年至公元 476 年） | 源於軍事、貿易、政治及通訊需要；古希臘奧運觀眾要求住宿膳食；富有羅馬人到希臘、埃及海邊度假 |
| 中古時期（約 5–15 世紀） | ==宗教旅遊==增長，朝聖成有組織活動（麥加、耶路撒冷、羅馬） |
| 16 世紀 | 英國貿易興盛，出現為增加知識、擴闊體驗的新類型旅客 |
| 17 世紀 | 英國貴族子女遊歷歐洲兩至三年：==大旅遊==（遊學旅行），培育行政及政治人才 |
| 工業革命（約 18–19 世紀） | 為==大眾旅遊==奠基；中產階級財富、教育、休閒時間增加；溫泉市鎮及海邊度假勝地 → ==保健旅遊==盛極一時 |
| 19 及 20 世紀 | 鐵路、載客航機；二戰改良通訊及航空；1970 年波音 747 令長途旅行大眾化；汽車普及帶動汽車旅館 |
| 21 世紀 | 互聯網令供應商直銷；==網上旅行社==興起；社交媒體推廣；9/11 令人關注航空保安；2020 年新冠疫情令國際旅遊接近停滯；未來朝==碳中和==發展 |

## 1.4 旅遊業出路

- 世界旅遊觀光協會估計：旅遊業直接提供超過 1 億個職位、間接近 3 億個，約佔全球就業**十分之一**
- 香港：直接約 189,000 個職位（5%）；連間接超過 559,900 個（14.7%）

| 旅遊服務 | 旅遊運輸 | 住宿 | 餐飲 |
|---|---|---|---|
| 導遊、領隊、旅遊顧問、獎勵旅遊顧問、企業旅遊顧問、會議策劃人 | 飛機師、機艙服務員、地勤、空中交通管制員、郵輪員工 | 款接員、禮賓司、管家、訂房部員工、康樂部指導員、行李員 | 侍應、宴會部服務員、廚師、調酒員、收銀員、接待員 |
