## 2.1 旅行、旅遊及旅客的定義

### 基本定義

| 用語 | 定義 |
|---|---|
| ==旅行== | 所有從一個地方到另一個地方的旅程（消閒、工作、居住、學習、過境） |
| ==旅行者== | 為任何目的、於某段時間內在不同地理位置間穿梭的人 |
| ==旅遊== | 暫時離開生活及工作的地方，到另一地方短期逗留，包括逗留期間的活動；**所有旅遊都包括旅行，但並非所有旅行都屬旅遊** |
| ==旅客==（過夜旅客） | 前往居住及工作地點以外的目的地，停留**至少 24 小時但不到一年**；目的為消閒、公幹及其他個人目的，**不是以居民身份受僱於到訪地** |
| ==短程旅遊== | 到目的地作短暫旅行，逗留**少於 24 小時**；不包括沒有進入該地經濟和法律領域的過境旅程 |
| ==短程旅客==（不過夜／即日來回旅客） | 沒有在國營或私營旅館過夜的旅客 |

!!! note "聯合國世界旅遊組織的旅遊定義"
    離開==慣常生活環境空間==前往某地，逗留**少於一年**的一切活動；目的包括消閒、公幹及其他，**不包括在當地幹活賺取金錢**。加入「慣常生活環境空間」是為排除日常往返居住及工作兩地的行程。

### 旅遊的分類

| 類別 | 定義 | 例子 |
|---|---|---|
| ==國內／本地旅遊== | 居民到本國境內其他地方旅遊；國內旅客須在旅館住宿最少一晚 | 紐約居民到洛杉磯公幹 |
| ==入境旅遊== | 境外人士到訪當地 | 對美國而言，加拿大旅客前往美國 |
| ==出境旅遊== | 居民離開原居地跨境旅遊 | 對加拿大而言，加拿大旅客前往美國 |
| ==國內／本地短程旅客== | 在本國境內到訪而沒有過夜 | 香港居民即日來回深圳購物、澳門觀光 |
| ==國際短程旅客== | 到訪他國而沒有過夜 | 加拿大居民即日來回美國 |

- ==國際旅遊==：兩國之間的旅遊；同一旅程，對==旅客來源地==是出境，對==旅遊目的地==是入境
- 國際旅客：在他國旅館住宿最少一晚

### 不被視為旅客的人士

| 人士 | 原因 |
|---|---|
| ==跨境工人== | 頻繁跨境工作（如住深圳、往返香港工作） |
| 季節工人及其他短期工人 | 按短期合約在居住地以外工作 |
| 流浪者及難民 | 到訪／逗留的地方被視為其慣常生活環境空間 |
| 公共交通工具工作人員 | 如機組人員，被視為在慣常生活環境空間內 |
| 外交官、派駐海外的軍隊 | 按==國際收支平衡原則==，被視為沒有進入駐紮國經濟領土 |

**視乎逗留時間**：學生（短期課程不到一年 → 旅客；一年或以上 → 非旅客）；病人（住院不到一年 → 旅客；一年或以上 → 非旅客）。

### 旅遊目的（聯合國世界旅遊組織）

1. **個人**：度假、閒暇及娛樂｜探訪親友｜教育及培訓｜健康及醫療｜宗教／朝聖｜購物｜過境｜其他
2. **商業及專業**

- 香港等地的問卷只分商務、度假、探訪親友、過境（及其他）
- 大多數旅客因**多種原因**旅行；越來越多調查要求指出主要及次要目的

## 2.2 旅遊的形式（按外遊目的）

| 形式 | 要點 |
|---|---|
| ==閒暇／度假式旅遊== | **輕鬆式**：迷人風景、陽光、海、沙灘（沿海、郊區、山區）；**觀光式**：探索、增廣見聞、提升自尊感，拍很多照片，喜歡市中心 |
| ==公幹旅遊／商務旅遊== | 貿易、會議、獎勵旅遊、大型會議、展覽（見下） |
| ==文化旅遊== | 藉旅遊獲取目的地或東道社群的知識及理念；參觀博物館、遺蹟，觀賞文化表演 |
| ==環保旅遊== | 到自然環境旅遊，盡力減低對環境的影響；管理機構以旅客收益（入場費、捐款）作保育，導覽員教育旅客 |
| ==學習旅遊== | 學生到海外參加短期或假期課程；本地遊學團 |
| ==宗教朝聖== | 受宗教信仰感召；需求頗穩定（如麥加、耶路撒冷） |
| ==保健旅遊== | 如溫泉區醫療旅遊（內地及日本溫泉） |
| ==探訪親友== | 多住親友家，較少光顧旅館；但仍光顧超市、增加家庭消費，主人家常安排觀光 |
| ==運動旅遊== | 參與運動（滑雪、登山）或觀看賽事（奧運、世界盃、香港國際七人欖球賽） |

### 會議、獎勵旅遊、大型會議及展覽

- ==會議==：通常指企業會議
- ==獎勵旅遊==：以旅遊獎勵業務達標的員工；通常包括會議或商務元素及休閒元素
- ==大型會議==：參加協會組織的會議，討論共同關注議題（如專業機構、學術團體）
- ==展覽==：向潛在顧客或買家展示新產品、服務及資訊

### 商務旅客的特色（必背）

1. 常到**大城市或工業中心**（倫敦、法蘭克福、紐約、東京、香港；深圳、東莞）
2. 與**旅遊價格沒有必然關係**：減價不會令他們更頻密出行，加價亦不會減少出門
3. **季節性因素**（氣候、假期）影響不大
4. 行程**短而頻密**
5. 要求不同服務，如**通訊或秘書服務**
6. 時間許可會在工餘進行閒暇觀光
7. 期望**較高質素服務**並願多付費用（頭等艙、商務艙、高級酒店）

!!! trap "易錯"
    2026 考評報告指出考生對**商務旅客特徵**掌握不足。作答須用課本特徵（價格彈性低、不受季節影響、行程短而頻密、要求商務服務），並以資料內容逐點對應。

## 2.3 旅客的分類

### ==高恆的分類模式==

**分類基礎**：旅客對尋求新體驗的==好奇心==，與希望如置身家鄉以滿足==安全感==的需要。

**核心概念：==環境泡泡==**

- 一種熟悉的環境氛圍及體驗，把旅程中的環境變化降至可接受水平；是降低風險的「安全網」
- 環境變化太大 → 旅客感到不快，或另覓方案，甚至取消旅行
- 酒店提供環境泡泡的方法：多國語言員工｜不同種類食物（特別是早餐）｜旅遊櫃台安排導遊一日團｜安全舒適的房間｜不同國家的電視頻道
- 同一旅客不同旅程可選擇不同程度的環境泡泡，取決於當時的動機

| 角色 | 類別 | 特性 |
|---|---|---|
| ==旅行團群體旅客== | ==制度化旅遊== | 光顧旅遊機構（旅行代理商、旅遊公司、連鎖式酒店） |
| ==個別的群體旅客== | 制度化旅遊 | 同上 |
| ==探險式旅客== | ==非制度化旅遊== | 與旅遊機構甚少聯繫；擔當群體旅客的先鋒，對目的地低下階層居民起==示範作用== |
| ==漫遊式旅客== | 非制度化旅遊 | 同上 |

| 類型 | 行為特徵 | 與環境泡泡的關係 |
|---|---|---|
| 旅行團群體旅客 | **最不冒險**；路線預先決定，由導遊帶領到固定景點及購物點（如空調巴士郊遊團）；幾乎不能作任何決定 | 大部分時間處身其中 |
| 個別的群體旅客 | 行程並非完全固定，對時間和行程有相當控制，不受限於群體活動；仍預先透過旅行代理商或旅遊應用程式安排主要行程；去的地方不比旅行團更遠更深入 | 仍受其限制 |
| 探險式旅客 | **自行安排**行程，去非一般的地方；仍尋求舒適住宿及可靠交通，保留基本常規；嘗試融入當地、說當地語言 | 勇於離開，但**謹慎地**探險 |
| 漫遊式旅客 | 斷絕與旅遊機構（酒店、旅遊車）的連繫；無固定行程；與當地人同吃同住，找零工賺取旅費 | 遠離 |

### ==蒲樂的分類模式==

**分類基礎**：目的地受歡迎程度與旅客**與生俱來的性格**密切相關。

| | ==保守型== | ==中庸型== | ==探奇型== |
|---|---|---|---|
| 性格 | 不喜歡冒險；傾向抑制 | 並非特別喜歡冒險；不抗拒嘗試新體驗 | 喜歡探索新體驗、尋求冒險；外向、充滿自信 |
| 目的地 | 熟悉的目的地、旅遊熱點；悠閒的陽光及玩樂景點 | 到熟悉的目的地發掘特別景點；新鮮獨特、沒有過多旅客但**已發展**的目的地 | 冷門、非一般、**發展未成熟**的目的地；發掘不為人知的地方 |
| 活動 | 靜態活動；放鬆及娛樂，與親友相聚 | 在可控環境下了解不同文化；與當地人有一定接觸 | 動態活動；享受與不同文化人士交往 |
| 住宿及膳食 | 熟悉、有規模但廉價的**連鎖式酒店**；家庭式餐廳、家鄉風味 | 對新鮮酒店持開放態度，但仍追求舒適；優質酒店、知名餐廳 | 簡單服務即可（良好以至僅達水平）；不一定入住連鎖式酒店 |
| 交通及安排 | 喜歡**駕車**；全包、行程預先完全編排的旅行團；**安全和保安非常重要** | 可自由行，亦可參加旅行團 | 喜歡**坐飛機**；自由度高的旅行團（只安排交通及住宿） |

- **大部分旅客屬中庸型**
- 再細分為五類：保守型、==接近保守型==、中庸型、==接近探奇型==、探奇型
    - 接近探奇型：與探奇型相似但相對謹慎，不偏向極端之旅；喜歡舒適住宿及值得信賴的膳食
    - 接近保守型：不愛冒險，偏向熟悉的地方，往往是**重複到訪**的旅客

!!! score "拿分要訣"
    - 辨識類型時，先寫**分類基礎**（高恆：好奇心與安全感／環境泡泡；蒲樂：性格），再引資料中的**行為證據**逐點對應課本特徵
    - 高恆題要提及「環境泡泡」及「制度化／非制度化」等詞彙
    - 兩套理論分清用詞：高恆是「旅行團群體、個別的群體、探險式、漫遊式」；蒲樂是「保守型、中庸型、探奇型」

!!! trap "易錯"
    - 2025 考評報告：不少考生**混淆中庸型與保守型**。分辨關鍵：中庸型不抗拒新體驗、可自由行、找已發展但不太多旅客的地方；保守型只去熟悉熱點、全包旅行團、重視安全
    - 個別的群體旅客雖然自由行，但**仍在環境泡泡內**，不等於探險式旅客

## 2.4 旅客行為守則及旅遊時的關注事項

### ==旅客行為守則==（聯合國世界旅遊組織「全球旅遊業道德標準」）

1. 對其他文化和傳統持開放態度；保持寬容，尊重多樣性
2. 尊重人權（任何形式的剝削都違反旅遊業根本目的）
3. 協助保護自然環境（不購買瀕危動植物製品）
4. 尊重文化資源（藝術、古蹟、文化遺產）
5. 促進經濟和社會發展：購買當地手工藝品，遵守==公平貿易==原則；討價還價應體現對公平工資的理解
6. 出發前了解目的地健康衛生狀況、緊急及領事服務聯絡方法
7. 了解目的地的習俗、規範和傳統，避免冒犯當地居民
8. 熟悉法例，避免販運毒品、武器、古董、受保護物種

### 旅遊時的關注事項（風險）

| 風險 | 降低風險的方法 |
|---|---|
| 發生罪行 | 避免前往罪案率高、戰爭或恐怖威脅地區；知道聯繫旅遊警察方法；保留緊急電話；了解酒店走火通道 |
| 人身安全 | 購買旅遊保險；使用經測試的安全設備；不偏離行人路或有標記的山路 |
| 財務風險 | 信用卡、銀行卡及現金分開存放；貴重物品存酒店保險箱；保管證件並備影印本；留意街頭推銷；向持牌經營者購買；行動裝置設高強度密碼 |
| 健康 | 攜帶藥物；預先接種疫苗；了解是否疫區及衛生情況；身體欠佳避免劇烈活動；注意飲食；瀏覽衞生署旅遊健康服務網 |

### ==有特殊需要的旅客==

| 旅客 | 交通 | 住宿 | 餐飲 | 景點／旅行社 |
|---|---|---|---|---|
| 高齡旅客 | 直航、旅遊巴；輪椅或專人協助登機 | 低樓層或近電梯的無障礙客房 | 家庭式或家鄉美食餐廳 | ==軟性探險==、觀光、歷史文化；悠閒行程、無隱藏收費 |
| 宗教信徒 | 祈禱室；向穆斯林顯示麥加方向 | 客房貼聖城方向箭頭；提供聖經及可蘭經 | 清真食品（不提供豬肉、酒精）；不向印度教徒提供牛肉 | 宗教景點提供禮儀提示；按需要分隔不同性別座位 |
| 懷孕旅客 | 航空公司一般接納不超過 28 星期孕婦；37 周前乘機或需醫療證明 | 鄰近醫療設施 | 特別餐單 | 體力要求低的活動；短程、較少人的景點 |
| 兒童及嬰兒 | 玩具、嬰兒搖籃、尿布、嬰兒食品；無成人同行兒童由職員照顧 | 額外嬰兒床、主題房間 | 兒童餐 | 主題公園、遊樂場 |
| 殘障旅客 | 專屬座椅和輪椅；聽障旅客個別通知廣播 | 無障礙客房、淋浴間；視覺警報設備 | 特別醫療餐單 | 自動電梯、斜道、凸字標記；懂手語的導遊 |
