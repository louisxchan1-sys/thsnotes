## 8.1 會議、獎勵及展覽業務

- ==會議、獎勵及展覽業務==：涵蓋商務盛事或活動的一種旅遊；具共同利益的參與者聚集於**預先安排**的場所
- 商務旅客除觀光外有商業考慮，亦需要當地的食物、購物、娛樂、交通、住宿等服務

| 類別 | 要點 |
|---|---|
| ==會議==（企業） | 分享資訊、討論、解決問題；董事會會議、管理層會議、股東大會、培訓研討會、與夥伴客戶會面（通知時間較短）、產品發佈會、策略性規畫、集思會 |
| ==獎勵旅遊== | 回饋及鼓勵達標員工（甚至顧客）的**管理工具**；通常三天行程，包酒店、旅行團及晚宴派對；歐美成熟，亞洲發展中 |
| ==大型會議==（協會） | 由協會（專業、志願機構、政黨）舉辦，參加者登記繳費；**為期數天、包括社交節目、通常每年一次、是協會主要收入來源、選址需大量時間**；分國際性、全國性、地區性 |
| ==展覽== | 向潛在顧客或買家展示新產品、服務及資訊；參展商租攤位；目的：促銷、介紹新產品、建立關係、收集對手資訊、建立形象 |

**影響獎勵旅遊決定的因素**：經濟狀況｜購買力（匯率較低）｜政治氣候（旅遊警示）｜安全和保安｜價值（設施服務比較）｜獨特體驗

| 展覽類別 | 例子 |
|---|---|
| 向公眾（商業對零售） | 展覽會（車展）、產品展（書展）、博覽會（美食博覽） |
| 向業界買家（商業對商業） | 貿易展銷會、交易會、貿易博覽會 |
| 綜合／混合展覽 | 為業界及公眾分設開放時間（香港國際旅遊展） |

- 香港主要場地：灣仔**香港會議展覽中心**、大嶼山**亞洲國際博覽館**；旺季面積緊絀 → 「==一展兩館==」並提供免費穿梭巴士
- 旅發局 2008 年成立==香港會議及展覽拓展部==，提供一站式專業支援

## 8.2 會議、獎勵及展覽業務的價值

| 價值 | 要點 |
|---|---|
| ==高消費== | 商務旅客住較好酒店、高級餐廳；人均消費比一般旅客高約 40%–80% |
| ==平衡旅遊的需求== | 活動不一定在旺季，助目的地在**淡季**充分利用酒店房間 |
| ==預先的安排== | 一至兩年前規畫（國際活動三至五年）；週期性活動有穩定預訂模式 |
| ==規模較大== | 國際會議需約 500 房晚及大型會議廳多天 |
| ==標準化服務== | 參加者對服務要求相似，節目程序相近 |
| ==促進輔助行業== | 攤位搭建、娛樂機構等供應商 |
| ==提升主辦城市的形象== | 留下專業形象 |
| ==不受旅遊景點的影響== | 觀光是次要，交通便捷等也可獲選 |
| ==無特定目的地== | 擁有足夠場地設施便可舉辦 |
| ==可彈性選擇地點== | 可用大學等非傳統場地 |

- 2016 年展覽業為香港帶來約 529 億港元收入（GDP 2.1%），提供約 77,000 個職位；CEPA《服務貿易協議》讓香港服務提供者可在內地獨資提供會展服務

## 8.3 與會議、獎勵及展覽相關的行業

- 參與者：**活動籌辦機構**（最重要的服務提供者）、**場地營運商**、**市場營銷商**（參展商、贊助商）、**出席者**

### 酒店

- 主要供應商及受益者：出席者逾 **65%** 開支用於酒店住宿及酒店餐廳
- 角色：全套住宿及會議服務｜為接待酒會、宴會提供設施｜只提供住宿及部分膳食
- 提供場地設施、住宿（代表及隨行人士）、餐飲、科技基礎配套（登記系統、電郵資訊亭、在線網絡會議）

| 酒店類型 | 特色 |
|---|---|
| 大型商務酒店（商業中心） | 高水準商務服務、大型宴會廳、交通便利 |
| 近郊酒店 | 25–100 人會議室、方便泊車 |
| 大型度假酒店及綜合度假村 | 鄰近景點、大量會議室及休閒設施 |
| 機場酒店 | 連接機場、中小型多功能廳、隔音設備 |
| 精品度假村 | 地點偏遠、小型會議室、高質素服務 |

- 大型酒店多主辦國際活動；小型酒店多主辦當地活動，或在會展中心附近提供餐飲及輔助會議場地
- **對酒店業的貢獻**：佔主要酒店銷售額 65%｜使用其他服務｜隨行人士消費｜可估計預訂、**增加淡季收入**｜極可能成為**回頭客**

### 交通及旅遊景點

- 國際交通（鄰近交通樞紐的城市吸引更多出席者）及當地交通（機場、酒店、場地、景點之間）
- 會後旅行團由指定旅行社籌組；獎勵旅遊以景點為行程重點；出席者是景點的潛在遊客

## 8.4 會議、獎勵及展覽活動的規畫

**規畫過程**：確立目標 → 可行性研究 → 辨識持份者 → 內外因素分析 → 風險和挑戰 → 策略及營運方案 → 角色及責任 → 監控 → 評估與回饋

| 目標的 ==SMART== 條件 | 意思 |
|---|---|
| 明確（Specific） | 以目標及目的為中心 |
| 可衡量（Measurable） | 以可量化方式陳述 |
| 一致（Agreeable） | 經所有持份者同意 |
| 實際（Realistic） | 有充足資源實現 |
| 有時限（Time specific） | 在特定時間內進行 |
