## 3.1 旅遊的動機

- ==動機==：激發人們採取行動、努力實現目標、滿足某種需要的意願（如肚餓 → 充飢需要 → 覓食動機）
- 旅遊動機解釋：為甚麼要外遊？為甚麼選某地方？為甚麼參與某項活動？
- **旅遊動機的形成**：旅行者清楚何種東西能滿足所需，同時明瞭目的地有何吸引之處、能否滿足其需要 → 產生到該地一遊的意欲

### 旅遊動機影響旅遊行為的三方面

| 方面 | 例子 |
|---|---|
| ==啟動==旅遊行為 | 想減壓 → 外出旅遊 |
| ==規範==旅遊行為 | 為避寒出遊 → 選擇有陽光與海灘的目的地 |
| 動機的==變化==影響旅遊行為 | 以往喜歡冒險旅遊，年紀漸長傾向休閒活動 |

### 影響旅遊動機的因素

| 因素 | 要點 |
|---|---|
| ==個人收入== | 收入僅夠維持基本生活，便不會產生旅遊動機 |
| ==餘暇時間== | 工作、學習及必需時間以外可自由支配的時間；是實現旅遊的重要條件；年長者餘暇時間較多 |
| 性別、年齡及身體狀況 | 女性在文化學習、聲望、家庭親屬方面動機較強；男性在體育參與和冒險方面較強；年齡與求新動機成反比；長者對目的地及環境要求較多 |
| ==心理因素== | 興趣、愛好、專業、生活態度、教育程度 |
| 旅遊業的整體發展水平 | 經濟發達才能改善旅遊設施、景點及交通；交通、住宿餐飲、服務水準是選擇目的地的重要因素 |
| 團體、家庭及社會風氣 | 企業組織旅遊、獎勵旅遊；親友的旅遊經歷相互感染或比較 → ==仿效的旅遊行為== |
| 世界局勢 | 地緣政治不穩、恐怖襲擊損害旅遊形象；全球疫症減低旅遊意欲 |
| 文化差異 | 目的地與自身文化是否相同 |

## 3.2 旅遊動機的理論

### ==馬斯勞的需要層次理論==

**要點**：心理需要分五層；**滿足了基本需要是滿足更高層次需要的先決條件**；所有行為都由心理需要驅動。

| 層次 | 定義 | 旅遊應用 |
|---|---|---|
| 5 ==自我實現需要==（最高） | 充分發揮潛能、實現理想和抱負；求知、審美、創造、成就 | 參與遊學團、學習團；攀登喜馬拉雅山以證實自己的能力 |
| 4 ==尊重需要== | 得到別人尊重；地位、名譽、威望、社會地位 | 忠誠客戶獎賞計劃分金、銀、銅級別，給予尊貴地位；特別日子送鮮花或香檳 |
| 3 ==社交需要==（歸屬感和愛的需要） | 愛別人及被愛；得到群體承認、容納、重視及關心 | 航空公司、酒店、餐廳的常客計劃令會員有歸屬感；與志趣相投者同遊；尋根 |
| 2 ==安全需要== | 保護肉體和精神不受傷害；健康、安全有序的環境、穩定職業 | 遊覽不熟識地點時提供導遊；選用政府認可的旅行代理商 |
| 1 ==生理需要==（最低） | 維持生存的基本需要：食物、水、氧氣、睡眠、住所、避寒 | 行程安排頻密休息點；飲食場所位於方便地區；公路旁汽車旅館 |

### ==赫曼的九個旅遊動機==

| 動機 | 要點 | 吸引元素／例子 |
|---|---|---|
| ==健康== | 為促進身心健康而休閒放鬆、度假療養；分**身體護理**及**心靈健康** | 溫泉、水療度假村、海濱；洗滌心靈的假期 |
| ==好奇心== | 滿足好奇心、求知慾或探險精神 | 不同政治及文化、公眾人物、自然景觀以至天災人禍 |
| ==運動== | 減輕生活壓力、滿足成為運動員的幻想；觀賽有社交意義 | 親臨觀看賽事 |
| ==快樂== | 假期打破刻板生活規律，嘗試新事物 | 美術館、音樂劇、購物 |
| ==宗教信仰及精神審美== | 滿足心靈需要 | 前往宗教聖地；欣賞自然美景、藝術表演、博物館、古蹟 |
| ==專業及公商務== | 公務出行 | 科學考察、會議、大型會議、教育 |
| ==親友交往== | 探訪親友，顯示關心 | — |
| ==尋根== | 認識自己國家的文化 | 研究族譜、探索故鄉 |
| ==尊重== | 透過旅遊得到別人尊重和社會地位 | 經常外遊、見識廣博而被人羨慕崇敬 |

### ==推拉理論==（丹恩，1977）

旅遊行為受==推動因素==（內在、心理）及==拉動因素==（目的地特性等外在因素）影響。

| | 推動因素 | 拉動因素 |
|---|---|---|
| 性質 | 令潛在遊客形成旅行慾望的**內部或無形因素** | 與目的地的**屬性及吸引力**相關，影響旅客**到哪裡**旅遊 |
| 特點 | 可以是**特定**的（如探望住在別城的祖父母）或**一般**的（如想休息一下）；**越具體，可滿足的目的地越少** | 在拉動因素影響下，旅客往往有**明確的目的地** |

**課本列舉的例子**

| 推動因素 | 拉動因素 |
|---|---|
| 參觀文化歷史、觀賞風景或享受天氣｜增加知識｜體驗不同生活方式｜實現旅遊夢想｜探訪親友｜和家人朋友一起｜建立友誼｜逃避日常生活｜休息和放鬆身心｜緩解工作壓力｜尋求刺激和興奮｜挑戰體能｜親近及了解大自然｜觀看不同事物 | 旅遊產品、旅遊費用｜目的地獨特的生活方式｜有趣的夜生活｜各種美食｜交通便利｜住宿、運動設施、信息｜服務質量｜豐富的歷史文化資源、美麗風景、怡人天氣｜安全｜國際大都市｜安靜、衛生、舒適｜熟悉｜了解自然的好地方 |

**應用例子（西九文化區）**：渴望逃離日常生活 ↔ 美麗的風景（海濱長廊看日落）｜探索／增加知識 ↔ 學習機會（香港故宮文化博物館）｜與家人朋友更親近 ↔ 交通便利、可達度高｜好奇心 ↔ 新景點

!!! score "拿分要訣"
    - 推拉題要**配對作答**：一個推動因素 → 對應的拉動因素（引資料）→ 解釋兩者如何相互搭配滿足需要

## 3.3 旅客流量的概念

- ==旅客流量==：量度某段時間內進入或離開某目的地的旅客人數和流向，或其趨勢
- 是==旅客來源地==與==旅遊目的地==之間==空間互動==的一種形式：目的地擁有**過剩**的商品（如景點，拉動因素），來源地**缺乏**或有需求（推動因素）

### 行程模式（必背）

| 模式 | 目的地 | 特點 | 例子 |
|---|---|---|---|
| ==雙向往返模式== | 單一目的地，有或沒有附帶支線行程 | 用**同一路線**往返原居地及目的地 | 香港旅客乘火車往返廣州 |
| ==中轉圓形往返模式== | 以一個主要目的地為**中轉站** | 從中轉站以圓形方式遊覽區內其他地方並過夜，最後返回中轉站，再返原居地 | 倫敦飛香港，由香港到內地圓形遊覽，經香港飛返倫敦 |
| ==圓形往返模式== | 多個目的地，**沒有核心停留目的地** | 以**不同路線**往返；由首個目的地開始走訪各地，從最後一個目的地直接返回原居地 | 香港沿海前往上海，以不同內陸路線返港 |
| ==輻射往返模式== | 利用主要目的地的地理優勢 | 以主要目的地為**基地及集散中心**，作周邊短程過夜旅遊，再返回基地 | 長途旅客抵港 → 澳門過夜回港 → 深圳主題公園留宿 → 回港，再返原居地 |

!!! trap "易錯"
    2026 考評報告點名考生對**行程模式**掌握不足。分辨關鍵：**中轉圓形**是以中轉站為起點和終點繞一圈；**輻射**是由基地多次「出去再回來」；**圓形往返**沒有核心目的地，去程與回程路線不同。

### 影響旅客流量的因素

=== "與旅遊目的地相關（拉動）"
    - **天然及人造景點**：提供另一地方缺乏的景點
    - **氣候**：較溫暖、陽光充沛或乾爽
    - **政治、文化及商業聯繫**：友好邦交、相同制度、共同語言及宗教
    - **相對費用**（生活指數、外幣兌換率）：由生活指數高的地方流向低的地方
    - **新的文化體驗**：東道群體的文化往往是主要吸引
    - **東道群體的態度**：持正面態度可增加流量
    - **旅遊潮流**
    - **政府管控**：外匯管制、入境簽證
    - **交通**：無需轉乘、單一交通工具可達
    - **旅遊地點的位置**：位於國際交通航線上（如香港處於內地、歐洲和北美洲的主要航線）

=== "與旅客來源地相關（推動）"
    - **收入**：收入越多，旅行頻率越高
    - **就業**：工作穩定者較多出國；工作不穩定者多在本地度假
    - **應享有薪假期**：假期較長可到較遠地方
    - **教育程度**：影響接受新經驗的意願；高教育者收入及地位較高，較常外遊
    - 推動因素：逃避日常生活、休息及鬆弛身心、社交需要、優越感、尋求刺激
