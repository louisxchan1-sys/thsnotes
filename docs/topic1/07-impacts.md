## 7.1 旅遊業對社會及文化的影響

| | 正面 | 負面 |
|---|---|---|
| **社會** | **改善生活方式**：創造就業、收入重新分配、扶助貧窮；開發原本不會有的社區設施（基建、衛生、交通、運動娛樂設施、餐廳）<br>**減少負面理解和成見**：提升東道社區聲譽及知名度；增加社會交往、新思路、新價值觀 | **生活方式**：==擠塞==（用水短缺、共用設施衝突、社區服務需求增加、土地衝突令當地人被分隔）；==職業形式及種類的轉型==（工人離開農業；女性及年輕人財政獨立，階級結構轉變）；==健康問題==（傳播疾病；污水設施過度使用）<br>**道德議題**：娼妓及性旅遊（未有足夠證據證明旅遊業助長）；罪案（旅遊季人口密度上升、邊界人流複雜、主客收入差距大） |
| **文化** | ==鼓勵文化交流==：學習對方習俗；培育尊重和接納彼此文化的態度；傳統娛樂、藝術、手工藝需求帶動發展<br>==加強文化保育==：保育及傳承傳統文化、復興土著文化；旅客仰慕令居民重新欣賞本地文化（例：峇里島）；旅遊收入資助修復歷史建築 | ==示範效應==：年輕人模仿旅客服飾、飲食及消費模式 → 挫折感、敵意、憤慨；長者矛盾心情<br>==文化變得商業化==：手工藝品大量生產，失去原有文化意義；為迎合旅客改變傳統文化和價值觀 |

### 量度社會及文化影響：==多克西的旅客情緒指標==

| 階段 | 居民情緒 |
|---|---|
| 1 ==興奮愉快== | 熱衷發展旅遊業，歡迎旅客，雙方滿足，帶來機會及金錢流入 |
| 2 ==理所當然== | 對旅客出現感到理所當然；旅客淪為賺錢目標；交往形式化 |
| 3 ==煩厭不快== | 旅遊業接近飽和或設施不足以應付旅客數目（如泊車問題） |
| 4 ==敵對感覺== | 視旅客為所有問題的始作俑者；互相尊重轉為敵對，旅客成為受欺詐的一群 |
| 5 ==得不償失== | 忘記所珍愛的東西正是吸引旅客的源頭；環境轉變且無法復原 |

- 原因：旅客數量最終超越居民能容忍的限度
- 總結：旅遊業發展急促、主客經濟文化差距過大時，社會文化轉變尤其重大；但旅遊只是社會轉變的其中一個因素，難以評估

## 7.2 旅遊業對經濟的影響

### 正面影響

| 影響 | 要點 |
|---|---|
| ==製造就業== | 高度==勞工密集==；**直接職位**（直接為旅客服務）及**間接職位**（服務本地人和旅客，或為服務旅客的機構供應貨品及服務）；聘用最多：飲食、旅館、運輸、娛樂、旅行社 |
| ==提供稅收== | **直接稅**：入息稅、利得稅；**間接稅**：銷售稅、離境稅、酒店房間稅、應課稅品稅項 |
| 改善==收支差額== | 入境旅遊是「==無形出口==」賺取外匯；出境旅遊是「==無形進口==」；入境消費高於出境 → 盈餘（2019 年美國盈餘 620 億美元，全球第一） |
| 經濟增長及生活水平 | 為發展中國家賺取外匯；與建築、運輸、食物製造業等聯繫，帶動==經濟多元化==；比傳統農漁業薪酬高；設施及選擇增加 |
| ==收入及聯繫效應== | 收入來自工資、利息、租金、盈利；為其他行業創造生意；旅客消費高或逗留長 → 收入增加 |

### 負面影響

| 影響 | 要點 |
|---|---|
| ==高消費價格及高地價== | 有限資源（土地、運輸、電力、食水、食物）需求增加 → 通貨膨脹 |
| ==過分依賴旅遊業== | 依賴外在需求（少數已發展國家的經濟）；旅客口味善變；旅客流量下降時經濟受重創 |
| ==流失== | 旅遊收益在經濟體系中受損：旅客及業界消費進口貨品服務；外國員工匯款回國；外資公司利潤花在海外 |

- 包團團費約 8 成由來源國的私營機構賺取；發展中國家旅客每消費 100 美元只有約 5 美元留在當地
- **進口貨品所引致的流失**：東道國未能供應或產品未達國際級酒店水準，須進口器材、食物飲品
- **出口貨品所引致的流失**：跨國及外資企業投資旅遊設施，把收益帶返投資國

### 量度經濟影響：==旅遊業乘數效應==

| 階段 | 內容 |
|---|---|
| ==第一重效應== | 旅客直接或間接購買產品服務（目的地內：住宿、食物；經旅行團承辦商訂房。目的地以外：免稅品、機票）；若承辦商開支比重大，承辦商可議價令流入資金減少 |
| ==第二重效應== | 業界把收入用於購買投入資源，及支付生產要素成本：工資、利息、利潤 |
| ==第三重效應== | 生產要素擁有者以消費、儲蓄或繳稅用去收入；購買進口產品 → 進口流失 |
| 週期完結 | 每次循環都有流失，回流資金越來越少，直至效應消失；初期開支多次循環的**累積效應** = 乘數效應 |

- 例：旅客在餐廳消費 → 東主交稅、儲蓄、向本地供應商購貨、付工資、利息、租金 → 收款人再消費……連鎖消費遠超最初款額
- 稅項、儲蓄、購買進口貨品會**減低**乘數效果
- **經濟活動之間聯繫越強、貨品服務越多由本地提供 → 乘數效果越大**
- 總結：旅遊業對目的地經濟的**淨額貢獻主要視乎資金流失**

!!! trap "易錯"
    2026 考評報告點名考生對**量度經濟影響**掌握不足。作答須寫出乘數效應的運作（初始消費 → 多輪再消費 → 每輪有流失）及影響乘數大小的因素，不能只寫「帶動經濟」。

## 7.3 旅遊業對環境的影響

### 正面影響

1. ==環境的保存及復原==：為保存古蹟、保育自然資源提供動力和金錢（例：肯尼雅、坦桑尼亞建自然公園及狩獵保護區）
2. ==環境的改善==：種植花草、發展美化設施；控制空氣、水質、噪音、垃圾
3. ==加強環保意識==：政府執行反污染、改善土地利用分區

### 負面影響

| 類別 | 內容 |
|---|---|
| ==環境污染==（非生物環境影響） | **水質**：機動船隻、郵輪油污；度假村未經處理污水<br>**空氣**：過度使用交通工具；食肆冷氣廢氣<br>**土壤**：不可生物降解垃圾釋放有害化學物<br>**噪音**：旅客、車輛、飛機、遊樂場<br>**視覺**：與本地風格不符的建築、巨大廣告招牌、架空電線、阻礙景觀、失修建築 |
| ==擾亂生態==（生物環境影響） | **植物**：採集花草、踐踏、砍樹生火、遠足損害土壤<br>**野生動物**：興建設施令動物失去棲息地；覓食及繁殖模式改變 |

### 量度環境影響

- ==環境影響評估==：評估新旅遊項目對環境影響及嚴重程度；**及早預防勝於日後補救**
- 環境影響分三方面（Romeril）：地理、生物、社會經濟（包括文化）
- 評估要點：先了解評估動機（如著重整治成本）｜比較不同發展計劃以有效分配資源｜提高人們對環境保護的關注

### ==經濟合作及發展組織評估旅遊業與環境壓力的架構==

| 引致壓力的相關活動 | 問題／困擾 | 初步反應（環境方面） | 深層反應（人類方面） |
|---|---|---|---|
| 1 **永久性的環境變動**：主要建築活動（城市擴建、交通網絡、旅遊設施、遊艇停泊港、滑雪裝置、海堤）；土地用途改變 | 當地環境重建：擴大人造環境；取用初級生產用地 | 自然環境改變；生物種類數量改變；人類健康和福祉改變；外觀質素改變 | 個人：影響美學價值；集體：改善環境及環保管理開支、規劃野生生物保護區及郊野公園、管制康樂用地人流 |
| 2 **製造殘餘廢物**：城市化、交通 | 大量污染：排洩物、污水、固體廢物、噪音 | 空氣、水、土壤質素改變；生物及人類健康 | 個人：本地人使用空調、循環再用、抗議；旅客改變態度、旅遊收益減少；集體：減低污染開支、清潔河流海灘 |
| 3 **旅客活動**：滑雪、散步、狩獵、越野單車、採集 | 踐踏植物和土地；摧毀生物 | 改變棲息地；改變生物種類數量 | 集體：環保管理開支、規劃保護區、管制人流 |
| 4 **對人口的影響**：人口增長 | 季節性人口密度 | 擠迫；對土地、水、能源的需求 | 個人：對擠迫的態度；集體：增加供水、供電等支援服務 |
