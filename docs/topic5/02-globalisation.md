## 2.1 全球化

- ==全球化==：日呈緊湊的關係網絡**跨越政治國界**，將不同國家聚合成單一、互相依靠的整體；各地差異逐漸被蠶食（Mowforth 及 Mundt）
- 驅動：人口、資訊、金錢和思想在世界各地快速流動

### 從旅遊業角度看全球化（旅遊業全球化的特徵）

| 特徵 | 例子 |
|---|---|
| 當地文化==商品化==、變得沒有價值 | 一切從商業角度考慮 |
| ==美國化== | 麥當勞、肯德基、星巴克灌輸美式思想（斐濟也有麥當勞） |
| ==標準化== | 世界各地機場、酒店、城市大同小異，降低旅遊樂趣 |
| 資金全球自由流動 | 追求最高投資回報 |
| 生產轉移至勞工成本最低的地方 | 澳洲樹熊玩具在中國生產；馬爾代夫椰子紀念品在峇里島生產 |
| 小型企業被大公司收購 | Peregrine Adventures → First Choice → TUI |
| 經濟重組著重大企業利益 | 希爾頓被投資基金收購，著重股東回報而非顧客、居民、僱員 |
| 跨國媒體影響旅遊選擇 | CNN 告訴我們去哪裡旅遊；國家地理令人成為「梳化遊客」 |

**對發展中國家的影響**：為建基建負上巨債；當地居民負擔不起使用設施；外國發展商獲**稅項寬減（免稅期）**，當地無法分享收益；須進口建材、食物、飲品 → ==資金流失==

### 全球化的推動力

1. **技術發展**：交通運輸（==低成本航空公司==令普羅大眾可外遊）；互聯網（全球網上預訂系統，無需旅行社）
2. **經濟驅動因素**：西方國家可支配收入高、年假多
3. **對自己國家認識提高**：已遊遍熟悉地方，嚮往新奇遙遠的目的地（北極、冰島）

!!! trap "易錯"
    2026 考評報告：不少考生**混淆「全球化」與「旅遊業全球化」的特徵**。全球化是國家之間日趨緊密、互相依靠的整體過程；旅遊業全球化的特徵要寫旅遊業的具體表現（標準化的酒店機場、跨國連鎖、全球網上預訂、低成本航空、資金流失等）。

## 2.2 ==文化同質化==

**定義**：強國（尤其美國）的思想、價值及生活方式被輸送至世界其他國家；旅遊勝地與發達國家使用同類產品、相似食物及生活方式（例：麥加開設星巴克；巴黎迪士尼初期不供應酒精飲品被冷落）。

### 為何是問題

1. 「多樣性」是活力及創新的關鍵，同質化令多樣性減少；《世界文化多樣性宣言》：文化多樣性對人類如生物多樣性一樣必不可少
2. 旅遊勝地與遊客原籍國日益相似，遊客**失去旅遊的興趣**

### 造成文化同質化的三個因素

1. ==示範效應==：當地人（尤其發展中國家）模仿遊客的生活方式（泰國山村小孩穿 T 恤、戴棒球帽），與其他輩份產生衝突
2. **旅遊勝地引入西方產品滿足遊客需要**：西式傢俬、電視、西式食物；當地人學習相關服務，生活方式隨之改變
3. **跨國公司擴展至全球**：麥當勞、星巴克、可口可樂改變飲食文化

- 巴伯（Benjamin Barber）：快餐的意義在於「快」，衝擊家庭聚餐、咖啡室閒坐等生活方式及宗教家庭價值觀

### 反對觀點：全球文化變得多元化

1. 高雲（Tyler Cowen）：社會之間聯繫後雖更相似，但各社會變得**更多元化**，消費者有更多選擇（古巴音樂、波斯地氈）
2. 全球化**不是單向過程**：其他國家的文化亦蔓延全球（印度瑜伽冥想、日本壽司）

## 2.3 大眾化旅遊及可持續發展

- ==大眾化旅遊==：二戰後流行的標準全包式旅行團；最普遍是大眾化海灘旅遊及冬運旅遊
- 問題：大量旅客**同一時間（旺季）遊覽同一地點**，為環境帶來極大壓力

| 例子 | 問題 |
|---|---|
| 肯尼亞 | 未經規劃在脆弱沿海及海洋生態系統大規模興建度假設施；野生動物生境內住宿過多；珊瑚礁、海龜受破壞 → 失去吸引力 |
| 阿爾卑斯山、張家界、泰山 | 興建酒店、纜車、扶手電梯破壞自然觀景；山上垃圾及排泄物處理困難 |
| 西班牙、意大利沿海 | 瘋狂建設破壞自然風貌，永久視覺污染；噪音、廢氣、擠迫 |
| 威尼斯、巴塞隆納 | 全年人滿之患 |

- 全球化令遊客有大量選擇 → 目的地質素一下降，遊客改往其他國家，只剩退化的資源及閒置設施

## 2.4 剝削及公平貿易

### ==剝削==：發展中國家受跨國公司剝削的原因

| 原因 | 內容 |
|---|---|
| 1 對跨國公司提供==稅項寬減== | 發展商首五年或更久無需繳稅；東加勒比貨幣聯盟稅收損失佔每年本地生產總值 9.5%–16%，收益甚微 |
| 2 提供==低薪工作職位== | 當地人缺乏外語等資格；高薪職位由發達國家經理擔任，當地人只得低技術、待遇差或季節性工作 |
| 3 ==苛索當地自然資源== | 發展中國家談判籌碼有限；投資者要求在潟湖、珊瑚礁、野生生物生境興建度假村 |
| 4 ==經濟流失== | 國際公司提供全方位服務組合，遊客開支多由國際公司收取；須進口消費品（牙買加三分之二的蝦進口）；極端例子每 100 美元只有約 5 美元留在當地 |

### ==公平貿易==

**定義（世界公平貿易組織）**：以對話、透明及尊重為基礎的貿易合作夥伴關係，從國際貿易中尋求更大權益；通過更好的交易條件促進南方國家可持續發展，確保發展中國家被邊緣化的生產者和工人的權利。

- **意義**：確保當地人能把土地、自然資源、勞動力、知識及文化應用在可獲利的旅遊活動；本土與國際營運者互利平等合作
- **重要性**：旅遊業由總部設於發達國家的跨國公司主導，利潤回流發達國家，提供資源的貧困社區得益很少；若關注不公平貿易條件、讓當地社區掌握發展，旅遊業便能支持當地生計
- 例：雲南咖啡（公平貿易改善農民生活，並成為著名旅遊目的地）

| 公平貿易旅遊的六個目標 | 意思 |
|---|---|
| ==公平比例== | 按貢獻公平分享收入 |
| ==自由度== | 僱員有權參與與他們有關的決定 |
| ==尊重== | 尊重人權、文化和環境；安全工作環境、性別平等 |
| ==可靠性== | 服務可靠穩定，保障員工及訪客安全 |
| ==透明度== | 業權明確，盈利、利益及虧損透明 |
| ==可持續性== | 本地採購及本地就業，**減少漏損效應** |

**實踐方法**：與當地持份者平等協商｜環境和社會評估｜僱用當地居民及原居民｜公私民夥伴關係培訓當地管理人才｜遵守當地規劃及環境法規｜與當地供應商協商公平價格｜外國與當地投資者公平競爭｜共享旅遊收入｜使用當地產品及物料｜外國投資者遵守稅收法規

**對旅遊企業的好處**：**滿意的客人**（知道錢受益於合適的人，沒有內疚）｜**高質素的旅遊產品**（保護資源）｜**良好信譽**，吸引消費者信任
