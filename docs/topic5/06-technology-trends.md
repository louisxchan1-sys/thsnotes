## 6.1 旅遊業

### 資訊科技的應用

| 界別 | 例子 |
|---|---|
| 住宿 | 自助入住登記終端機 |
| 交通 | 旅遊代理透過==全球分銷系統==查看航班及預留機位 |
| 中介機構 | 網上旅行代理商查閱旅遊套票 |
| 旅遊相關服務 | 網上簽證、社交媒體、流動裝置旅遊資訊應用程式 |

- 旅客在出發前、渡假期間及回程時都需要資訊 → 社交媒體（Facebook、Instagram、TripAdvisor、Groupon）及流動裝置是主要顧客服務工具

### 科技帶來的好處

| 對企業 | 對顧客 |
|---|---|
| **改善成本效益**：減少官僚及文件工作，省下時間服務顧客；整合部門功能降低成本 | **方便購買**：互聯網取代傳統分銷，直接與中介打交道 |
| **加強預報技術**：營收管理、路線規劃；獲取更準確的市場研究數據 | **加快購買決定**：一站式購物；容易獲取資訊；自動化登記 |
| **整合分散的旅遊產品**：透過 CRS／GDS 提供一站式購物 | **提供更多產品訊息**：大量網站提供選擇；緊迫時仍享特別優惠；機場自助登記 |

### ==全球分銷系統==（GDS）

- 前身是航空公司開發的==電腦預訂系統==（CRS）；擴展至集合不同航空公司資訊，故稱 GDS
- 連繫航空公司、酒店、旅行代理商、租車公司、郵輪；四大系統：AMADEUS、GALILEO、Sabre、Worldspan
- 可預訂：機票、酒店、租車、旅行團、郵輪、火車票、保險、接送、門票、餐飲訂座、複雜路線
- **效用**：任何時候訪問｜每秒處理多達 17,000 個訊息｜回應少於一秒｜可最後一刻更改｜自動計算票價更改｜比較票價及貨存量｜安全儲存旅客資料
- 消費者現可在互聯網直接預訂，許多航空公司已減持 GDS

## 6.2 住宿業

### 資訊科技應用的分類

| 前線部門之應用 | 後勤部門之應用 | 餐廳及宴會管理系統 | 顧客相關的界面應用 |
|---|---|---|---|
| 訂房、登記入住／結帳退房、入住顧客資訊、顧客記帳、客房狀況及管家部管理 | 管家部、人力資源、會計、存貨及採購、銷售及市場推廣、財務及業績報告 | 電子銷售點系統、食譜成本計算、宴會管理、飲料控制 | 通話計算、電子門鎖、能源管理、顧客操作裝置、顧客配套服務 |

**前線部門應用（以==酒店資產管理系統==為例）**

- **訂房**：多人同時處理；超額預訂自動警告；等待名單
- **登記入住／退房**：列印抵達及離開名單；信用卡驗證縮短時間；退房即時更新客房狀況；特快結帳
- **顧客記帳**：各銷售點更新消費；信用額問題發警告，甚至鎖房
- **客房狀況**：退房後自動由 OD 更新為 VD，管家部即時得知

**顧客相關的界面應用**

| 應用 | 好處 |
|---|---|
| ==通話計算系統== | 自動計費，減少帳單爭執；阻截待售客房撥出電話，杜絕員工濫用 |
| ==電子門鎖系統== | 遺失鎖匙只需重辦，舊卡失效；記錄出入，減少盜竊；錯誤鎖匙試開即通知保安；RFID 免匙進房 |
| ==能源管理系統== | 照明按日照調節；中央空調；感應扶手電梯；房內電力自動切斷 |
| ==顧客操作裝置==（自助式服務科技） | 電視服務系統：看電影、上網、查帳、自助退房、點客房餐飲 |
| ==顧客配套服務== | 用戶是員工：語音訊息、自動來電喚醒 |

### 應用資訊科技的好處

| 對企業 | 對顧客 |
|---|---|
| 降低營運成本（電腦夜間核數）｜減輕員工工作量（閉路電視）｜提高效率（信用卡驗證十秒）｜增加收入（房內娛樂系統）｜取得及分享資訊（VD → VC 即時更新）｜優化規劃及管理（顧客資料庫） | 方便使用服務（網上訂房不受辦公時間限制）｜保持服務水平（減少人為偏差）｜改善服務體驗（酒店流動電話）｜提供更多服務選擇（傳統或自助退房） |

### 應用資訊科技的問題及不確定性

| 企業的擔憂 | 顧客的擔憂 |
|---|---|
| **高層管理人員知識不足**，趨向保守 | ==科技焦慮症==：使用不熟悉科技感到不安（長者） |
| **巨額投資成本**；技術很快過時 | ==社交焦慮症==：使用自助科技時被人注視感到不安 |
| **員工壓力**：不願改變；擔心被取代 → 士氣低落、流失 | **私隱及保安**：個人資料或被洩漏；隱藏攝錄機 |
| | **科技與個人化服務**：「溫暖的」人手服務比「冰冷的」科技更令人滿足 |

### 酒店資產管理系統（PMS）

- 綜合電腦系統，是酒店營運的**核心／資訊樞紐**；連接前線、後勤、餐廳宴會系統及顧客界面（例：餐廳 POS 消費自動計入房帳）；香港常用 Micros Opera 及 HIS
- **好處**：減少工作重疊，提高效率｜管理人員輕易取得資料作決策｜及時準確資料完善服務｜內部運作標準化，易於監控

| 系統 | 範圍 |
|---|---|
| ==酒店資產管理系統== | **單一酒店**內存貨控制及訂房 |
| ==電腦化訂位系統==（中央訂房系統） | 統一**同一企業旗下所有酒店**的訂房（例：半島集團九間酒店只有一個設於香港的中央訂房部，節省開支、統一服務、可轉介至同集團其他酒店） |
| ==全球分銷系統== | **策略夥伴聯盟**集中各企業存貨，單一系統分銷各種旅遊產品 |

### ==自助式服務科技==（SST）

**定義**：利用科技介面，使客人在使用服務過程中成為**生產者**，不需服務員協助（如 ATM）。

| 形態 | 例子 |
|---|---|
| 終端機 | 自助入住登記；大堂旅遊資訊終端機 |
| 互聯網介面 | 網上預訂；虛擬導覽；房價及推廣與 CRS／PMS 實時更新 |
| 流動裝置 | 希爾頓應用程式：預先登記入住、預留餐館座位、電子菜單點菜；租借 iPad |

- **客人看法**：在**不犧牲個人化服務**的前提下，喜歡 SST 作為**額外選擇**；不用排隊、更能控制時間地點
- 須注意不善用科技的客人（長者）；若只有 SST 而無其他選擇，客人未必滿意
- **結論**：個人化服務是住宿業最重要的元素；科技的角色是**支援，而非取代**

### 應用資訊科技的建議

1. **方便使用**：資料清晰、操作簡單、設於當眼處、即時技術支援
2. **直接惠及用家**：如 PMS 禮賓部功能；以獎賞（列印優惠券）鼓勵使用終端機
3. **為顧客提供更多選擇**：電視系統或傳統電話點客房餐飲
4. **培訓及技術支援**

    科技趨勢題要**兩面**分析：對企業（成本、效率、收入）及對顧客（方便、選擇）的好處，同時指出擔憂（投資成本、員工壓力、科技焦慮症、私隱、失去個人化服務），最後以「科技作支援而非取代」作平衡結論。

## 6.3 飲食業

### 餐廳及宴會管理系統

| 系統 | 功能 |
|---|---|
| ==電子銷售點系統==（POS） | 取代收銀機；輕觸式屏幕落單直接傳送至廚房、酒吧；顯示訂餐時間，避免字跡模糊；全面管理報告；電子菜單及便攜裝置從餐桌直接傳送 |
| ==食譜成本計算系統== | 食材價格浮動時自動更新成本，按標準食譜及份量計算，控制邊際利潤 |
| ==宴會管理== | 宴會預訂系統及預訂日誌，整合房間、設備、套餐、佈置及付款資訊 |
| ==飲料控制系統== | 預設份量，電子流量計量度用量，對比銷售記錄找出浪費或欺騙 |

- ==電子餐牌==／二維碼選餐：資料直接連結廚房及收銀處

### 科技轉變對餐飲消費模式的影響

| 方面 | 影響 | 疑慮 |
|---|---|---|
| **食品生產與運輸** | 食品開發、貯藏、防腐發展；24 小時內「新鮮」運到全球 | 加工食物多：添加劑、色素、防腐劑影響健康；營養價值低；進口食物增加碳足跡 |
| **資訊科技和食物預訂** | 電話、網上預訂外賣，方便省錢 | 鈉、脂肪、糖分較高；邊看電視邊吃不健康；強化「宅男」行為 |
| **媒體和網絡宣傳** | 名廚效應（「Delia 效應」）；Web 2.0 社交網站及評論網站（TripAdvisor、OpenRice），讀者認為較可信 | 匿名評論或失實，用以自我宣傳或攻擊對手 |
