# 4. 旅遊業與款待業的趨勢：社會文化方面

<p class="freq">出題頻率：顧客群趨勢（老化人口、多代同遊等） ⭐⭐⭐｜世代特點 ⭐⭐</p>

---

## 4.1 旅遊業與款待業的社會文化方面

世代及生活方式越來越常用作預測社會文化趨勢的依據。

| 趨勢 | 對業界的影響及對策 |
|---|---|
| ==老化人口== | 65 歲以上人口由 2000 年 6.9% 增至 2050 年約 16%（發達國家 26.9%）；**營銷**須平鋪直述、提供大量資訊，準備回答詳細問題；**酒店設計**方便長者（體力限制、少樓梯）；**餐廳**提供熟悉、營養豐富的食物；**價格**提供可負擔或實惠的方案 |
| ==多代同遊== | 祖輩與孫兒同遊作家庭聚會；設計祖輩同遊套餐及折扣，按孫子女年齡安排活動；郵輪及國家公園探險受歡迎；酒店提供多種選擇（不同款式早餐），保健套餐融入刺激、減壓元素 |
| ==單親家庭遊== | 收入較低；酒店多按成人人數收費令單親家庭多付；可以一位成人一位小童收費，專為單親家庭而設的旅行團 |
| ==獨生子女家庭增多== | 孩子對父母旅遊計劃影響力重大；兒童泳池、遊樂場、親子活動（烹飪課、篝火晚會）；同房兒童額外早餐券或免費膳食 |
| ==受過良好教育的顧客增多== | 對住宿要求提高；搜集大量資料後才訂購；透過網上旅行社及酒店網站比較價格 |
| ==遊客品味和消費力分化== | 有人要求豪華，有人選經濟方案；商務遊客轉選**精品酒店**；文化及冒險地區**民宿**需求增長；經濟型酒店增加 |
| ==移民和探親遊== | 移民後趁假期回原居地探訪親朋 |

- 嬰兒潮一代壽命較長、較富有，視旅遊為**必需品而非奢侈品**，要求高質素體驗（景致、美食、服務、水療）

## 4.2 四個世代的特點及趨勢

| 世代 | 特點 | 旅遊業 | 住宿業 | 飲食業 |
|---|---|---|---|---|
| ==老一輩==（大蕭條至二戰期間長大） | 務實、有耐性、保守；注重儲蓄；重視**安全及保安**、忠誠度 | 財政保守，需要別人照顧；很少用互聯網；喜歡長途及海外旅行、賭場 | 首先考慮**安全及保安**；很可能再次光顧同一酒店；**通用設計**（較矮的床、較亮照明、大字體、步入式淋浴間） | 喜歡熟悉及健康食物；價廉物美的家庭式餐館；長者折扣、分量較小 |
| ==嬰兒潮出生的一代==（1946–1964） | 重視物質及金錢；不相信簡單廣告，要求詳盡資料；人數眾多且富有；開始退休，旅遊時間更多 | 富裕，多屬商務旅客；重視健康，喜歡**醫療及健康旅遊**；亦喜歡刺激活動及博物館 | 國內外旅遊次數最多；注重舒適度、價值及質素；喜歡能欣賞當地文化的住宿；停留較長；關心品牌形象 | 喜歡高級餐飲體驗（品酒）；酒類消費最大 |
| ==X 世代==（1965–1979） | 專注物質及購物；注重**工作與生活平衡**；善於適應轉變 | 較喜歡與孩子旅行；用互聯網搜索；尋找獨特體驗（主題公園、體育比賽、高爾夫）；對定價過高敏感，追求物有所值 | 休閒旅遊花費最高；喜歡時尚雅致的地方；未必重複光顧同一集團；要求名牌床褥、高清電視、無線上網 | 喜歡快餐；注重食物及酒類品牌；物超所值的自助餐 |
| ==Y 世代==（1980–1995／2000） | 樂觀、自信、樂意改變，但缺乏耐性；擅長科技；重視休閒；引領潮流；需要即時回應；多重任務 | 較活躍；用互聯網搜索及購買；追求新穎時尚體驗（主題公園、夜總會、購物）；願為高品質付費 | **品牌忠誠度最低**，願嘗試非傳統品牌；要求廉價快餐、上網、平面電視、方便購物；希望感到受尊重及奢華；**互聯網推廣尤其有效** | 較在意價錢；喜歡快餐亦喜歡健康食品；較少傾向特定品牌 |

!!! note "樂活社群（LOHAS）"
    「健康和可持續性的生活方式」；消費者關注健康、環境、社會正義、個人正義和可持續發展；被視為旅遊業**新的優質客群**。
