## 5.1 旅遊業

- 氣候是影響旅客流量的**宏觀因素**；高山、島嶼和沿海目的地對氣候變化特別敏感
- ==溫室氣體==中二氧化碳最顯著（燃燒石化燃料、砍伐森林）

### 旅遊是氣候變化的==載體==及==受害者==

| | 內容 |
|---|---|
| **載體** | 旅遊價值鏈有明確、高度可見且上升的==碳足印==；**運輸（特別是航空）**是主要因素；旅客運輸約佔旅遊業二氧化碳排放 75%；其他營運大量消耗水和能源、產生廢物及破壞臭氧層的物質（製冷、空調、溶劑、氣霧劑） |
| **受害者** | 《達沃斯宣言》：氣候是旅遊的重要資源；極端天氣、缺水、生物多樣性消失；**環境條件**（洪水、山火、乾旱更頻密）；**環境資源**（冬季活動日子減少、山火影響遠足、海灘被侵蝕）；**旅遊營運**（社區及公司經濟受影響；景點質素下降遊客不來） |

| 氣候變化 | 對目的地的影響 |
|---|---|
| 溫度上升、降雪減少 | 高山滑雪季節縮短 |
| 溫度上升、降雨減少 | 炎熱地區遊客因酷熱、疾病、缺水而避開，酒店入住率下降；珊瑚礁白化 |
| 冰川融化、海平面上升 | 低窪國家及島嶼洪水、沿岸土地流失；海灘及島嶼被浸沒 |
| 極端天氣增多 | 颶風（2005 年卡塔理娜重創新奧爾良及加勒比海）；亞洲超強颱風（菲律賓） |

### 減緩二氧化碳排放的趨勢

- ==綠色飛機==：節省燃料的引擎、較輕機身；更多**不停站直航**長途航班；**可持續替代燃料**（液化氫、生物燃料）
- 政府政策：徵收較高離境稅減少短途航班；提高公眾對飛行環境成本的關注

### 環境保育與==負責任旅遊==

旅遊業既是載體亦是受害者 → 比其他行業更需要保護環境。**負責任**指減少對環境的負面影響、為當地社區帶來經濟效益、保存文化及自然資源。

| 類型 | 要點 |
|---|---|
| ==生態旅遊== | 尊重大自然，保育環境及改善當地居民福祉 |
| ==地質旅遊== | 維持或提升地點的地理特色（環境、遺產、審美、文化、居民福祉） |
| ==負責任旅遊== | 以當地社區利益為大前提，減少社會或環境負面影響，協助保育文化及棲息地 |
| ==可持續發展旅遊== | 考慮目前和未來經濟、社會和環境影響；適用於所有類型旅遊 |
| ==道德旅遊== | 以道德議題（社會不公、人權、動物福利、環境）為主要推動力 |

- ==良心旅客==驅動負責任旅遊需求：嬰兒潮（退休、富有、關注環保）、X 世代（環保消費）、Y 世代（熱衷環境及社會公義）

## 5.2 住宿業

- 旅遊業製造約 5% 溫室氣體排放；住宿業亦產生大量廢棄物、消耗大量能源及水

| 酒店服務 | 對環境的主要影響 |
|---|---|
| 行政、接待 | 能源、水、紙；有害廢棄物（碳粉盒） |
| 專業技術服務（熱水、空調、照明、泳池、綠化） | 能源及水消耗；有害物品；廢水；農藥 |
| 餐廳、廚房 | 能源、水、原材料；包裝廢棄物；廢油；有機廢棄物 |
| 客房使用 | 能源、水；有害清潔物品；包裝廢棄物；廢水 |
| 洗衣 | 能源及水；有害清潔物品；廢水 |

### ==環保酒店==（綠色酒店、可持續發展酒店）

- **定義（Green Hotels Association）**：環境友善的物業，經理熱切推行**節約用水、節約能源及減少固體廢棄物**的計劃，以節省金錢及保護地球
- International Tourism Partnership：「環保」包括可持續發展及企業社會責任，各級決策須有可持續思維：政策和框架｜員工培訓｜環境管理｜採購｜人民和社區｜目的地保護
- 認證項目眾多，**未有統一標準**；共同標準：減少碳排放｜減少耗用能源｜減少用水｜減少廢棄物

**對酒店管理層的三個好處**

1. 符合==注重生態意識==客人的期望 → 提升市場形象
2. 住宿設施屬資源密集，可持續發展可為下一代保護環境
3. 減少用水和能源 → **節約成本、改善盈利**

## 5.3 飲食業

### 消耗資源的趨勢

| 趨勢 | 要點 |
|---|---|
| **減少紅肉** | 牲畜排放佔人為溫室氣體約 14.5%；飼料生產佔 45%、腸道發酵甲烷 39%；牛肉及牛奶排放最多（41%、20%）；一公斤牛肉 ≈ 36.4 公斤二氧化碳；**白肉**排放較少 → 餐單多提供白肉選擇（減少排放、森林不被取代、減少灌溉用水、土地可種農作物） |
| ==採購本地食品== | 運輸業佔總排放 13%；好處：保存農地景觀｜有利土地和水資源｜有利野生動物棲息地｜減少運輸、分發、儲存的碳排放 |
| ==可持續採購== | 採購不單考慮成本和質量，亦考慮社會和環境因素；選購環保產品；誘使供應商提供更多環保食品；例：世界自然基金會**海鮮選擇指引**（防止過度捕撈） |
| **節約能源良好守則** | 升級至最節能設備（能源星級）｜適當大小的設備｜節水設備｜定期保養清洗｜只在必要時打開雪櫃｜關閉不必需設備｜教導員工 |

### 生產廢棄物

- 香港 2011 年每天約 3,600 公噸廚餘棄於堆填區，佔都市固體廢物約 40%
- 兩類：==廚餘==；與準備食物及飲品有關的廢棄物（紙張、紙板、玻璃、塑膠、金屬、有機廢棄物）
- 食物浪費出現在食物鏈每個階段：生產 → 處理及儲存 → 加工和包裝 → 分發和市場營銷 → **食用（飲食業主要來源）**
- 食用階段浪費原因：**任食餐單**（自助餐供應過量）｜對剩餘食物的文化態度｜**非選擇性餐單**（份量過多或不合口味）
- 對環境的影響：**土地**（全球 28% 農地用於生產被浪費的糧食）｜**水**｜**空氣**（每年約 33 億噸二氧化碳當量）

### 減少廚餘的守則

| 程序 | 做法 |
|---|---|
| 採購 | 適量採購；向認可供應商採購 |
| 收貨及貯存 | 檢查品質、退回劣貨；最小存貨；溫度控制；**先入先出** |
| 烹調 | 每日生產計劃；善用剩餘食物（早餐香腸做熱狗）；捐贈剩料予惜食堂（半島酒店） |
| 食用 | 提醒顧客避免過量點菜；自助餐提供**小份量**；提供環保外賣容器 |

**減少包裝廢棄物**：避免獨立包裝｜可重複使用的容器｜設回收箱｜以重複充裝皂液取代即棄品｜大量少包裝採購｜製成有機肥料或動物飼料｜選擇有生態效益措施的供應商
